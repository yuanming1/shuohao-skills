# 站位宫格交接包

`grid-input.json` 是本技能内部可携带、可重新导出的交接包，不替换或扩展上游 storyboard schema。
只包含导出提示词和复核说明实际消费的内容；每个对象最多五个字段。

## 顶层

| 字段 | 消费位置 |
|---|---|
| `mode` | 固定 `locked-blocking-grid`，导出器检查输入类型 |
| `segment` | 原段号，决定文件夹和图页标题 |
| `layout` | `columns`、`rows`、`aspect`；决定右侧布局和单格画幅 |
| `panels` | 按原切序的关键帧描述及可选参考图片 |
| `planning` | `opening` 为正式 `blocking`，包括原开场事实、人偶颜色图例、逐镜路径和参考用途；`shots` 为逐镜空间与动作依据 |

## 每格 panels 条目

| 字段 | 消费位置 |
|---|---|
| `shot` | 原镜号，如 E01-02-f1 |
| `time` | 起止秒数的十进制字符串数组，累加保留精度 |
| `size` | 原景别 |
| `frame` | 原切点画面描述，逐字进入提示词 |
| `reference` | 可选图片路径，没有图片为 null；重导出时相对路径按交接包目录解析 |

## 每镜 planning.shots 条目

| 字段 | 消费位置 |
|---|---|
| `shot` | 与 panels 同位置镜号一一对应 |
| `view` | `position`、`composition`、`eyeline`，对应上游机位、构图和视线 |
| `continuity` | 原 `cut.note`，供状态说明与接镜复核 |
| `action` | 原 `cut.shot`，供布局路径标注及视频同步复核，不能当作静帧终态 |

右侧列数按镜头数平方根向上取整，最多四列；多余格子留空。时间从零开始连续累加。
导出器检查镜号、时间轴、布局、材料缺项、参考文件唯一性与非空，不判断正文空间语义。
从 `--plan` 重导出时没有上游文件可比对，不声称该包一定是分镜最新版；修订项目后应重新从 `--storyboard` 导出。

## 调度约定复用 opening 文本

不增加对象字段。原开场事实保持在前，后面追加以下文本区块：

- `【调度人偶对应】`：每行格式为 `- C01 角色名：蓝色人偶`，角色 ID 沿用分镜，颜色使用中文色名；同段 ID 与颜色均唯一。无人段写 `本段无人出场。`。
- `【调度路径参考】`：有人移动时，使用本段原镜号逐镜说明谁从哪里沿什么通路走到哪里，以及其他人物是否保持；没有位移时写 `本段无人物位移。`。路径图、逐镜 action 与 continuity 的一致性仍由 Agent 判断。
- `【调度参考用途】`：说明已附图时参考相应颜色人偶与原镜号路径，颜色只标识角色，演员外貌来自角色设定，未提交图片时仅依据文字安排。

旧交接包缺少颜色或路径时先补齐，导出为待补状态，不自动猜测。导出器检查角色映射、镜号覆盖和源分镜角色引用；从正式分镜导出时另核对已有各段的颜色对应。只有 `--plan` 时无法检查整个项目的颜色分配。

`sync-dispatch --storyboard ... --plan ...` 将交接包中的调度约定写回正式段级 `blocking`，由视频导出器直接带入【人物关系与构图逻辑】。写回前检查原开场事实、镜头数、顺序、时长、景别、画面、机位、动作与承接不变，核对分镜角色覆盖和跨段颜色；未知字段与其他段保持。工具统一更新用途说明，不重复追加。未通过时分镜保持原内容；成功后仍需从正式分镜重导出宫格与视频正文。
