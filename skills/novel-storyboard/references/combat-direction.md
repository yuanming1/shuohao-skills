# 打戏编排分支

用于分镜初稿中的连续攻防。先根据剧本锁定故事，再设计具体交锋；规划发生在分段之前，提示词仍写入统一分镜。资料已经内化在本目录，运行时不读取其他技能。

## 进入与退出

| 剧本中的实际内容 | 处理路径 | 判断依据 |
| --- | --- | --- |
| 争吵、对峙、拔刀威胁 | 常规分镜 | 尚未发生连续攻防，不能为了进入分支安排出手 |
| 单次推开、扇耳光、突然一拳 | 常规动作与承接 | 交代接触、受击和结果即可；后续形成连续反击时再进入分支 |
| 连续攻击与格挡、追击与反击、摔投与脱身 | 打戏分支 | 下一动作取决于上一动作造成的姿态、距离或破绽 |
| 兵器交锋、法术攻防、御剑对战 | 打戏分支 | 需要处理攻击轨迹、防御范围与双方应对，不只是展示法术 |
| 没有交锋的奔跑、攀爬或追逐 | 常规移动与承接 | 速度高不等于打戏；借力路线需要时参考兵器资料中的轻功部分 |

识别以动作因果为准，避免仅按“打、剑、追”等词触发。只处理交锋覆盖的节拍，交锋停止后回到对白、反应或移动分镜。同一场次可以多次进入和退出；不增加分支标记或新的 JSON 字段，不要求用户重复调用技能。

## 按内容读取

进入分支后读取本文，再按场面选择资料；不要整套加载。

| 本场需要处理的内容 | 读取资料 | 消费方式 |
| --- | --- | --- |
| 拳脚、短打、腿法、擒拿与摔投 | [徒手与身法技法](combat-techniques.md) 对应章节 | 选择符合人物能力和当前距离的具体攻防 |
| 刀剑、长柄兵器、轻功、御剑与法术 | [兵器与仙侠攻防](combat-weapons.md) 对应章节 | 展开握持、轨迹、借力、拦截与回收 |
| 打斗摄影、受击反馈或既定特效 | [打戏镜头与反馈](combat-camera-effects.md) | 把观察目的映射到已有摄影、动作与声音字段 |
| 需要理解分支写法 | 先读 [盐仓脱围故事](../examples/盐仓脱围-story.md)，再读 [编排示例](../examples/盐仓脱围-combat.md) | 查看故事如何约束动作与跨段承接，不套用示例情节 |

## 先确定交锋事实

从剧本、角色及相关资产材料中确认：双方本场目的、事件顺序、攻击与防守结果、能力和兵器、空间条件、动作时长预算。已有 `staging.json` 或空间说明时沿用；没有时，只在已确认场景范围内安排可行路线。

将事实与表现选择区分开。例如“守方挡开兵器后脱身”允许细化格挡部位、偏转方向和出路；不授权改成折断兵器、重伤敌人或新增一轮围攻。剧本明确写有数次交锋时才编排对应的连续招式，不能把一个推开动作扩成完整决斗。

角色没有武学流派时按已知体能、习惯和兵器编排功能动作，不强行绑定武学、建立角色卡或添加招式名称。缺少能力依据时不添加瞬移、御剑、元素攻击或变身；影响胜负或事件结果的缺口返回剧本处理，其余已知部分继续。

## 规划完整交锋

1. **目的与优势变化。** 明确人物是在压制、拖延、逃离、护人还是争夺物件，哪些变化已由剧本确定。阶段可以是接触、压制、破招、脱离或决胜，不要求全部出现。
2. **逐次攻防。** 对重要接触写清“谁以哪个部位或兵器从哪里攻向哪里 → 对方怎样应对 → 哪个姿态、位置或防线改变 → 下一动作为什么成立”。短链可以是两三次攻防，不用抽象攻击频率替代实际过程。
3. **角色动作签名。** 根据角色材料选择直线压迫、绕侧换位、短桥封控、腿法控距或兵器变线等主导方式。主导打法可以贯穿全场，不要求三种以上武学，也不要求每次更换招式。
4. **空间与占用。** 先算攻击距离、退路、接触支点与落点。手中有物件、扶墙或锁住对手时，该手不能同时完成另一动作；需要释放或换手就先有过程与剧情依据。狭窄场景不塞入完整旋踢或大弧长兵横扫。
5. **节奏与结果。** 用攻击、受阻、观察、再行动的变化呈现节奏。停顿对应犹豫、受力或判断，不能为了模板让双方停手。终结、认输、追击、收招和静止余韵只在故事需要时出现。

防守要继承上一动作的结果：护架完整时可以正式格挡；被带偏或崩开后，先用尚能完成的撤步、偏头、单臂拍挡等应对，恢复护架需要可见过程。小幅闪避与大幅腾挪按攻击轨迹和角色选择，不统一要求空翻。摔投先有抓控和失衡，再有翻转与落地；落地后的追击、脱身或降服以剧本为准。

## 再拆生成段与切镜

先规划完整交锋，再按剧情单元、动作预算与场次拆成生成段；使用 `schema.md` 当前的段上限和单切时长。默认上限 15 秒、每切 2–5 秒；不为了打戏改时长合同，也不固定填满 15 秒。

同一剧本节拍仍只由一切认领。不要为了展示同一击的起手、命中和反馈而重复认领或虚构节拍；可在一切内完成，或在剧本已有连续节拍之间选择动作阶段切点。预算不足时先减少装饰性动作；仍无法表现既定事件则列出需要调整的剧本节拍或时长，不自行改写上游。

一切围绕一个主动作或能完成的短攻防链，只有一个主运镜。0.2 秒的命中停顿只是该切内部的速度变化，不新增小于时长下限的独立特写切。不能用多次隐藏剪切绕过切数与关键帧合同。

同场跨段时，下一段 `blocking` 从上一段末态建立，并在首切继续位置、朝向、持物、防守、动势、已确认伤势与环境变化。攻击已经落下就不重新起手，防线已经破开就不自动重置。新段可以从半途接招开始，不要求重新接触、制造逆转或安排终结。

## 合回正式分镜

| 既有字段 | 打戏内容如何进入 | 注意事项 |
| --- | --- | --- |
| `cut.note` | 保留原备注，写起始、动作、结束、接镜；必要时注明采用哪种技法及其故事依据 | 备注供提示词编写和人工复核，不代替正文 |
| `cut.frame` | 切点当下的位置、握持、支撑、攻击或防御阶段 | 中文、角色姓名、单一状态，不提前画出之后的命中 |
| `cut.shot` | 从切点继续，落实攻防、接触、终态与主运镜 | 中文、通用身份；不写时间码、镜号、图片引用、台词或协议符号 |
| 摄影字段与 `segment.blocking` | 用既有景别、运镜、机位、焦点等字段表达观察目的与段初站位 | 枚举以 `schema.md` 为准，不新增近景或运镜枚举 |
| `segment.h3Prompt`、`cut.sfx`、`segment.soundscape` | H3 对应镜头与 `shot` 保持同一动作，声音与接触阶段同步 | 保留推导的对齐行、切点、原台词与协议结构；Seedance 仍由程序拼装 |

全局视觉风格继续由调用方附加；分支不启动默认风格、场景选择或角色创建向导。招式资料中的色彩和效果不是项目设定，只有已确认能力与特效才可写入。

## 交付复核

正式分镜先执行统一结构校验，再按 [打戏检查标准](combat-review.md) 的 C01–C12 逐项核对全部打戏镜头、连续时间中的跨段边界及进入／退出处的承接。标准明确了故事与能力依据、攻防因果、空间距离、占用归属、受力支撑、防守恢复、时长节奏、状态承接、提示词对齐、摄影可读性及声音特效反馈的通过条件与退回例子。

结合 `continuity.md` 的语义复核，以正文中的动作与上下游事实作为证据。出现矛盾或必要过程漏写时退回修改；真正缺少上游判断依据时标为待核实，不把未知判成通过。修订后连读前后切、跨段边界及受到同一状态影响的后文。

交付说明记录范围、结论与未解决项，按检查标准使用“通过／退回修改／待核实／不适用”；不新增字段或日志。只有结构校验和适用的文本项目全部通过，才能声明该范围文本复核通过。没有实际生成时，成图与成片尚未验证。

## 方法来源与改写范围

学习来源为本仓库 `seedance-combat-prompt`，作者标注“飞驰影漫社+废话军师联合改造”：学习其动作指导、近景招式序列、镜头目的、空气与受击反馈、防守三态、特效轨迹，以及剑法、长柄镰刀、梦想一心太刀、绯雪单太刀、高级轻功、修仙高级剑招六份专项资料。这里只记录来源名称，不将来源文件作为运行依赖；本分支实际需要的规则和动作摘要已经写入本目录。

保留动作因果与可见反馈，按 novel 剧情及协议重新组织。来源中的固定角色、默认配色、游戏形态和数值不作为新项目设定；武学条目作为影视编排参考，不宣称历史、正统套路或游戏官方资料已经考证。

没有继承固定 15 秒五阶段、开局强碰撞、每段必有肘击／三种武学／两次空间变化、每两秒换镜、高潮截断收尾、同一组合招式零重复、统一气爆或爆血等硬性要求。完播率公式及未经核实的效果百分比不作为制作证据。运镜、景别、语言、参考图与台词规则以本技能现有合同为准。
