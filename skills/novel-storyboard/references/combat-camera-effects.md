# 打戏镜头与反馈

用于已经规划的攻防，解决观众应该看什么、怎样看清以及接触如何反馈。故事、动作顺序与结果先确定，再安排摄影和既定特效。协议与枚举以本目录 `schema.md`、`shot-writing.md`、`h3-prompt.md` 和 `seedance-prompt.md` 为准。

## 根据观察目的选择镜头

| 观察目的 | 景别与机位 | 主运镜参考 | 必须看清的内容 |
| --- | --- | --- | --- |
| 连续手部攻防 | 双人中景，按需要收紧为上半身构图，侧面或斜侧 | `Static Shot` 或 `Tracking Shot` | 来臂、接挡手和下一动作，避免前景身体遮住接触点 |
| 横向追击与绕侧 | 中景／全景，斜侧保留纵深 | `Tracking Shot`、`Truck Left` 或 `Truck Right` 中选一项 | 双方距离怎样改变、出口与障碍在哪里 |
| 腾空、翻转或摔投 | 全景，能看到支撑与落点的斜侧或俯视 | 固定或单一跟拍 | 从支撑到离地、翻转和落地的完整阶段 |
| 破绽与关键接触 | 特写，正面微侧或斜侧 | `Static Shot` 或 `Push In` | 一个关键部位或兵器接触，不同时要求全身运动 |
| 高低位换位 | 中景／全景，斜俯或根据已知高度取景 | `Pedestal Up`、`Pedestal Down` 或 `Tracking Shot` 中选一项 | 起跳、借力、移动方向与回落位置 |
| 受压、判断或蓄势 | 中景或面部特写，按角色与对手关系取景 | 固定或单一推近 | 触发判断的事件、已有压力与接下来的行动准备 |

“近景对招”是观察需求，不新增枚举。需要双人上半身时，在现有 `medium` 中景的 `frame` 与构图字段写清腰部以上的取景；需要局部时选择 `close` 特写或 `extreme-close` 大特写。字段实际取值和中文景别词继续按 `schema.md` 对应。

侧面可以帮助看清双方接触，斜侧可以交代进退纵深；按遮挡、轴线和空间任务选择，不把中景90°侧拍一概判错。低仰不自动代表强者，俯拍也不自动代表弱者，镜头目的应来自本场。

## 运镜写入现有合同

来源中的15种运镜作为观察方法参考，统一映射到已有 `camera` 词表。不得把“急速后拉跟镜”“定格定镜”等新名称直接写成枚举，也不把多种运镜塞进同一切。

| 表现意图 | 现有字段如何表达 | 同步要求 |
| --- | --- | --- |
| 贴身跟拍 | `camera` 选择 `Tracking Shot`，正文说明跟随角色、双臂或兵器路线 | H3 对应镜头以 `promptLang` 指定语言写相同主运镜与目标 |
| 推向关键接触 | `camera` 选择 `Push In`，正文说明推向哪个已经发生的接触点 | `focus`、`lens`、`cameraPosition` 与正文保持一致 |
| 拉开看清落点 | `camera` 选择 `Pull Out`，起始关键帧呈现原景别，正文说明逐渐显露的落点 | 不提前在起始帧画出之后的全景终态 |
| 升降观察 | 选择 `Pedestal Up` 或 `Pedestal Down`，正文说明机位移动范围 | 不误写成角色自己升降；角色运动另外交代 |
| 命中震动／慢放 | 以当前主运镜为准，按需要在 `stability` 或正文描述短促震颤、速度变化 | 不另造独立切、不叠加第二主运镜，不让停顿改变接触结果 |
| 环绕展示关系 | 只有观察任务需要时选择 `Arc Shot`，写清起止机位与轴线关系 | 不照搬360°旋转或螺旋组合；旋转方向仍可辨识，不能用镜头旋转掩盖动作缺失 |

每切的景别、视角、角度、主运镜与跟随目标通过既有字段和自然正文共同表达。无需把所有规格机械拼成一条固定句式；跟随镜头必须知道跟随谁，固定镜头不必编造跟随目标。

景别变化需要让观众理解距离和方向，既可以镜内拉开，也可以在剧本已有节拍边界切换。近景不强制经中景才能切全景，决定依据是空间是否已经建立；切换后攻击与身体的运动方向要能接上。

## 受击与防守反馈

先区分攻击落空、接触格挡、命中身体与命中环境，再选择反馈。

| 实际事件 | 可见反馈 | 不应凭空增加 |
| --- | --- | --- |
| 攻击落空 | 肢体沿原动势经过，衣摆或附近松动物体受到气流影响 | 身体受伤、接触火花和命中闷响 |
| 格挡成功 | 接触肢体受压、脚步调节、兵器改变方向 | 防线一定崩溃、人物一定倒飞 |
| 格挡被破开 | 双臂或兵器离开防线，身体偏转，之后以剩余条件应对 | 下一切自动恢复完整护架 |
| 身体被击中 | 与落点和力度对应的偏转、屈身、后退或失衡 | 骨折、流血、昏迷或固定击飞距离，除非剧本已经确定 |
| 环境被击中 | 与材质对应的振动、摩擦、声响和已确认的损坏 | 木棍碰柱就必定炸裂、所有地面都产生深坑 |

微表情选当前景别能看见的反应，例如下颌绷紧、视线追随来臂或护架受压后的迟疑。情绪必须有触发，不强制每击增加汗珠或血雾。短暂停顿可以突出判断或接触，但不设置与单切时长冲突的小于下限的独立镜头。

## 特效服从已确认设定

只有本场已经存在的气劲、元素、剑气或其他能力才进入提示词。普通写实交锋可以只有脚步、衣料、兵器与环境反馈，不默认添加空气波纹、音爆锥或发光拖尾。

对已有特效，按需要写明四个部分：**起源位置 → 沿动作经过的路径 → 接触或受阻方式 → 持续或消散状态**。例如已设定的火焰附着刀刃，随横斩沿弧线经过，在既定碰撞点散出火星，残火是否继续取决于原设定与场景材质。

蓄力、增强与爆发是可选表现顺序，不能每次从零重新生长。连续攻击可以减少装饰以看清接触；重要重击按故事需要加强反馈，不要求轻击无特效、重击必爆炸。主色、材质、能力形态沿用项目；冰雾不等于硬冰，残影不等于分身。

`cut.sfx` 记录本切接触与动作音，`segment.soundscape` 延续环境和非语言人声，`music` 处理配乐。画面动作或碰撞阶段改变时同步声音；相邻切持续声源不能无故重启或消失。正文不写全局画风，不启动五种风格或二十场景的选择流程。

方法来源与改写范围见 [打戏编排分支](combat-direction.md) 末尾；本文件已经按 novel 的镜头与协议合同整理，不读取来源技能。
