# 从结构通过到允许投产

## 边界

`validate` 只证明结构；`export` 默认还要求当前版本的逐切审核记录。程序核对文件版本、完整性、段序、提交秒数和审核状态，**不自动理解图片或证明自由文本真实**。不得机械批量把 `pending` 改成 `pass`。

当前导出器交付 H3 契约。实际使用其他模型时，先做该模型的提示词/参考图适配和小样验收；不能把 H3 格式的标注当成其他模型已经接受的硬约束。没有适配器时只能交草稿，明确下一步阻塞原因，不宣称其他模型必然不支持某语法。

## 审核前固定三件事

1. 确认实际模型、可提交时长和是否能按该参考图契约生成。不要等提示词写完才把 11.4 秒改成 10 秒。
2. 将分镜图放在 `--out` 指定目录的 `<段号>/f<切序>.png`；默认当前目录。命令不会自动复制其他目录中的图片。
3. 带齐同一组 `--script / --outline / --cast / --art` 输入；生成审核底稿与最终导出使用相同参数。任何输入或图片改变都要重新审核。

## 生成底稿，实际审核，再导出

```bash
node scripts/novel-storyboard.mjs review-template storyboard.json --script script.json --out . --model h3 > review.json
node scripts/novel-storyboard.mjs export storyboard.json --script script.json --out . --review review.json
```

底稿默认全部 `pending`。`review.json` 是单独的投产记录，不扩充已有剧本或分镜对象；顶层只有四个字段：

```json
{
  "fingerprint": "由脚本计算，禁止手改",
  "model": "h3",
  "segments": [{"id": "E01-01", "seconds": 3}],
  "cuts": [{"id": "E01-01/f1", "verdict": "pending", "evidence": ""}]
}
```

- `fingerprint` 绑定分镜、剧本、传入的上游资料和当前分镜图字节；它不包含视频文件，不是成片验收证明。
- `model` 填实际目标；当前投产导出只放行 `h3`。换模型走适配，不篡改字段来绕过。
- `segments` 预填计划清单，审核时必须对照实际将提交的顺序与秒数；不能把预填值当成已检查设置。任何增删、重排或取整都先回到分镜修正。
- `cuts` 按切序逐一留记录，`verdict` 用 `pending / fail / pass`，`evidence` 写具体观察和承接依据。每切记录同时负责与前一切的入镜边界，包括跨段、换场与有意时间省略。

每切逐项做完才能填写 `pass`：

1. 对照剧本与对应 `[Shot k]`，确认认领动作实际进入视频词，没有被下一切的“已完成”偷渡。
2. 比较上一切结束、本切起始图、本切动作与结束，确认动作阶段不重演，关键状态变化有依据；时间跳转在剧本中有观众可感知的入口/出口。
3. 实际并排查看本图与前后相关图，检查人物高度、姿态、接触、视线、道具外观、空间和环境状态。单张漂亮不是通过理由。
4. 在 `evidence` 写可复查事实，例如“与 E01-03/f3 并排确认两人仍低位坐/跪，师尊未起身，苏晴视线平向其脸，左手接触点延续”；有矛盾填 `fail`，看不到图片填 `pending`。

失败后修图或修改文本，重新生成审核底稿，再核对受影响内容。不要把旧版通过记录直接复制到新版；程序会拒绝旧指纹，也会拒绝缺图、漏评、空依据、乱序、改短秒数和非 H3 目标。

## 只交文字的合法路径

```bash
node scripts/novel-storyboard.mjs export storyboard.json --script script.json --out . --draft
```

草稿仍需结构通过，提示词文件会标记“未验收、不可直接投产”，允许缺图，不代表完成审核。`--draft` 与 `--review` 互斥。

## 生成后与合成前再查实际结果

- 取每个生成视频的真实时长和实际切点，对照末尾台词、动作与参考图；任务成功不等于按时间表执行。
- 根据确认后的段号清单合成，核对缺段、重复和排序；样片允许只选部分段，但应单独确认选段的叙事承接，不能把生成完成顺序当剪辑顺序。
- 抽取每个剪辑点前后帧；有声音时另听对白与声景。字幕或声音承担时间转场时，确认它们真的加入了成片。
- 报告分开列结构、语义/成图审核、投产设置核对、成片验收；没有查看或听到的项明确写未验收。
