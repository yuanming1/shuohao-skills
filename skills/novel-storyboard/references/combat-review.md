# 打戏检查标准

进入过 [打戏编排分支](combat-direction.md) 的动作范围，在交付前执行本标准。先完成正式分镜的结构校验，再核对实际动作内容；这份清单不增加自动质量门，不以评分、招式数量或标签齐全替代判断。

## 检查范围与证据

检查分支内全部镜头、同场连续时间中的全部跨段边界，以及进入和退出分支时相接的镜头；不只抽查重击和终结。对白或反应切如果夹在连续动作中，同样追查画外的持物、接触和防守状态。剧本明确换场或省略时间时，按既定叙事关系检查，不强行补成实时动作。

核对顺序是：认领的剧本节拍与角色／资产设定 → `cut.note` 的安排 → `frame` 的切点状态 → `shot` 和 H3 对应镜头的实际动作 → 下一切起始及下一段 `blocking`。已有空间安排时一并对照。备注称“已经松开”而正文没有释放过程，不能算作证据；节拍编号被认领也不代表其中动作已经落实。

只检查影响本次交锋的事实，不要求每切复述全部环境或添加精确坐标。距离、握持手、落点等只要会决定动作是否成立，就必须在相关镜头或连续安排中明确到可判断的程度。

## 判定方式

| 判定 | 使用条件 | 后续处理 |
| --- | --- | --- |
| 通过 | 有可定位的文本依据，适用条件均满足，且与上下游状态一致 | 保留依据，继续检查下一项 |
| 退回修改 | 已知事实矛盾、必要动作漏写、结果无依据或违反既有合同 | 修正对应镜头；涉及故事结果或能力设定时退回上游，不擅自补戏 |
| 待核实 | 判断确实依赖尚未提供或互相冲突的上游事实，例如场景通路是否存在 | 写明缺少什么、影响哪些镜头；继续处理不依赖该事实的部分，该范围暂不判通过 |
| 不适用 | 本场没有这一项的适用对象，例如普通交锋不涉及元素能力 | 写明原因；不能把正文漏写、接触画外或证据缺失当作不适用 |

已知缺少接触、释放或恢复动作属于退回修改，不能降为待核实。无法确认能力时不先添加能力；缺少证据也不能按主观印象判通过。每项有多个适用条件时，必须全部满足才能通过；局部不适用不能豁免同项其余条件。

## 逐项通过条件

| 编号与检查对象 | 通过条件 | 退回修改的例子 |
| --- | --- | --- |
| C01 范围与故事结果 | 根据既有连续攻防进入分支，交锋结束后退出；目的、事件顺序、胜负、对白及重要结果与剧本一致，招式细化只服务既定事件 | 将一次推开扩成围攻；逃离改成杀敌；每段额外安排一次逆转或终结 |
| C02 能力与兵器依据 | 人物使用已确认的体能、能力和资产，兵器类型、实体数量与攻击方式一致；已有动作习惯得到延续，没有流派设定时采用功能动作 | 普通人突然踏空；单刀无过程变成双刀；拖尾被当成第二把实体兵器 |
| C03 攻防因果 | 每次影响后续的攻击能定位攻方、参与部位或兵器、路径、目标、应对及结果；命中、格挡或落空能够解释下一动作为何成立 | 只写“快速连招、双方激战”；未见破防就直接倒飞；脱身前没有可利用的机会 |
| C04 距离与空间 | 重要攻击可到达目标，躲避、绕侧、追击及脱身有可达路线；障碍、通路与既有空间一致，兵器长度和挥动范围得到容纳 | 隔着柱子直接抓到人；没有移动就绕到背后；狭窄通道完整挥出大弧长兵 |
| C05 占用与归属 | 相关手脚、武器和道具的占用关系明确；接触、换手、释放、脱手和回收有过程，画外仍能追查归属 | 左臂夹账册却同时参与双手抱摔；未松手就奔离；武器落地后凭空回到手中 |
| C06 受力与支撑 | 推拉、碰撞、抓控、摔投和借力有对应接触、受力方向与支撑条件，身体变化与其相符；腾空及落地按已确认能力衔接 | 未接触就把对手摔翻；双手持械时又徒手撑地；普通跳跃在空中无依据折返 |
| C07 防守与恢复 | 完整护架、受压、被带偏或破开后的应对符合当前姿态；回收、重新站稳、重建护架及既定伤势影响有延续，不要求每场出现全部状态 | 上切双臂被崩开，下切直接完整格挡；落地尚未回稳就以双脚扎根发力 |
| C08 时长与节奏 | 单切和段时长符合实际 `params`；起手、接触、应对、回收与位移能在分配时长中表达，停顿有判断或受力依据；预算不足时先减少装饰，再指出上游缺口 | 用“瞬间完成”压进多轮换位；添加低于下限的独立命中特写；为模板填满十五秒或强迫停手 |
| C09 相邻切与跨段状态 | 下一切从最近可见终态继续，下一段 `blocking` 对应上一段末态；位置、朝向、握持、接触、防守、动势、伤势和环境变化按相关性承接，时间省略有剧本依据 | 第二段重回追逐起点；已落下的攻击重新起手；断裂道具或破损环境随切镜复原 |
| C10 三种提示词对齐 | `frame` 是切点当下单一状态；`shot` 与 H3 从此继续相同动作与结果，并落实所认领节拍；备注、关键帧和视频正文没有互相抵消 | 首帧已经压住兵器，正文却从伸手开始；备注写躲开，H3 写身体被击中；动作只存在于备注 |
| C11 摄影可读性 | 景别、机位、构图、视线、焦点和稳定性支持本切观察目的；每切一个主运镜，关键接触或路线能看清，切换后空间方向可理解；枚举使用现有合同 | 特写同时要求展示全身摔投与落点；身体遮住关键接触又无可理解依据；一个镜头叠加多个主运镜 |
| C12 声音与特效反馈 | 落空、格挡、身体命中和环境命中的反馈分别对应实际接触与材质；已有特效的起源、路径、受阻及残留可追踪，声画阶段一致，色彩和能力形态沿用设定 | 落空仍有身体命中声；木棍碰柱自动爆裂；冰雾突然承重；跨段把仍持续的能力重新从零生成 |

上表判定的是文本安排是否有依据、可理解且前后一致，不证明碰撞几何、力学精度或视频模型一定能实现。摄影不必遵守固定侧拍角度、景别过渡套路或武学组合；只要能完成本切观察任务并保持合同即可。

## 结构校验与修改复查

正式数据照 `SKILL.md` 的校验步骤执行现有 18 道结构门，包括节拍恰好一次、时长、台词、引用、提示词语言和协议等；可选门沿用原有适用条件。`schema.md`、`h3-prompt.md` 与 `seedance-prompt.md` 是相应合同依据，本表不重新定义这些规则或增设分支字段。

检查出问题后，先区分应修哪一层：

- 事件、胜负、能力或关键空间事实缺失：返回对应上游材料处理，不用新动作、道具、对白或特效掩盖缺口。
- 已有事件的动作过程、机位或表达有误：修订该切的安排，同步 `frame`、`shot`、H3 和声音，以及受影响的摄影字段与 `blocking`；Seedance 继续由程序拼装。
- 改动时长、认领、对白、引用或提示词：重新运行结构校验，再复核受影响的语义项目；不能沿用修改前的通过结论。

修一切后至少连读前后切与相关跨段边界；状态仍继续影响后文时，追到该状态被合理改变或重新建立的位置。不要为满足清单而重复认领节拍或新增镜头外的隐含事件。

## 交付结论与记录

只有现有结构校验通过，并且检查范围内所有适用项目通过、没有退回修改或待核实项，才能写“本范围打戏文本复核通过”。不采用“多数通过”“总分达标”来抵消剧情、持物或连续性错误。局部通过不能扩写为整集通过。

在现有 Markdown 交付说明中记录范围和结论，不新增 JSON 字段或独立日志。发现问题时使用以下五列；通过依据可以合并写出代表镜头与已覆盖范围，无需为每个镜头复制十二行清单。

| 镜头或边界 | 标准编号 | 判定 | 可定位的证据或缺口 | 修订或核实事项 |
| --- | --- | --- | --- | --- |
| 段号与切序，跨段时列出两端 | C01–C12 中适用项 | 通过／退回修改／待核实／不适用 | 指明认领节拍及具体字段、动作阶段或缺少的上游事实 | 修改位置、需要补充的依据或不适用原因 |

未出图时可以通过文本复核，但成图和成片应写“尚未验证”；没有完整 JSON 时，结构校验写“未执行”，不能称整份交付已经通过。下游实际生成后，可复用本标准对照画面中是否发生了预定接触、持物与承接；文本合规不能代替实际画面检查，本技能也不因此自动出图或生成视频。

判定写法见 [盐仓脱围的复核演示](../examples/盐仓脱围-combat.md#检查标准的使用示例)。本标准由本分支的动作、连续性和协议规则整理而成，方法来源见 [编排分支](combat-direction.md) 末尾，不读取其他技能。
