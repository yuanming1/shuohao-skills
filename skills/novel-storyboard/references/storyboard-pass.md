# 切镜：一集怎么分段、怎么切

一次任务切一集。你拿到 seedScenes 工作底稿（每场的节拍清单：编号、动作/台词、逐拍估时、说话人）、场景卡、角色卡。产出：把这一集的 `segments` 从空切满，然后删掉 `seedScenes`。

## 先明确场面目的与行动因果

确定镜号和秒数前，结合剧本及已提供的故事说明，在现有制作说明中简记：本场要让观众理解或感受到什么，人物为何采取下一步行动，观众起初知道什么，结束时应确认哪项变化或继续等待什么。简单场面几句话即可，不要求每场都有对抗、反转或悬念，也不另建文件。

检查关键原因能否从既有画面或声音读出，再选择观察对象与切换时机。若取景和声画安排就能呈现已有事实，在分镜中解决；若必须新增事件、改变人物知情状态或重排故事先后，明确对应节拍、缺失依据与具体修订建议，回到剧本处理后再据此分镜。原文中已被改编删去的铺垫不能自动恢复，也不能为了说明人物没有反应而自行编造原因。

## 先设计移动与省略的观看过程

剧本中的“走到”“稍后已在”“省略路程”交代事件与时间安排，分镜仍须决定怎样让观众理解位置变化。先判断移动是否承担接近、察觉、关系变化或后续对白的触发，再选择连续呈现、压缩中途或直接跳至后来状态。具体判断与正反例见 [镜间移动与时间省略](continuity.md#镜间移动与时间省略)。不因剧本写了省略就直接放行，也不要求每次移动都拍完整路程或固定安排出发、抵达两镜。

展开既定移动的起步、接近与停步属于分镜呈现，不因原句写了“省略”就按新增事件退回剧本；新增行动目的、途中遭遇或改变人物知情先后仍须先处理剧本。用户明确锁定必须省略的范围则遵守，并在允许的前后镜中解决可读性。

把必要的接近、停步与有依据的回应纳入本场观看过程，再分配镜长。不能先锁定每段等长、原有切数或总秒数，再删去连接位置与关系的动作。优先在项目预算内调整切点、镜长和分段；用户锁定的预算确实无法满足时，说明缺口。移动跨切呈现时同步节拍认领，必要时先细分上游动作节拍，不让同一节拍在前后镜重复认领。

## 先识别场面，再分段切镜

先根据剧本识别需要连续攻防的动作范围。连续交锋、追击反击、摔投脱身或兵器／法术攻防，先读取本目录 [打戏编排分支](combat-direction.md)，规划完整交锋再分段；只有对峙、威胁、单次接触或普通移动时，直接执行常规切镜。追逐但没有攻防时按常规移动处理。交锋结束后回到常规叙事，同场可以包含两种处理范围，不为触发分支新增事件。

分支只改变动作和镜头的编排方法；以下时长、节拍认领、参考图和提示词合同仍然适用。

1. **段 = 一次生成调用**，默认上限 15 秒，不跨场次。按剧情单元分组并遵守项目单段上限，不固定段长或切数。
2. **段内切分镜**，先确定每切需要看清的动作、反应或结果，再分配时长并认领连续节拍。一次完整的行动与应对可以在同镜发生，不按动作动词或节拍数量机械切镜。seed 中的动作估时统一采用项目 `actionSeconds`（默认 2.5 秒），只是预算参考，不决定独立镜长或切数。镜长按实际动作、对白与信息辨认需要分配，默认不设固定区间；程序检查正有限时长、单段上限及项目显式设置的 `minCutSeconds` / `maxCutSeconds`。一段不预设必须包含几切。
3. **每切一张分镜图**：第 1 切的是主分镜图（钉 0.00 秒），其余子分镜图钉在各自切点。生成时全套喂给 H3，段内每一格的构图都由图控制，不靠文字赌。

## 硬规则

1. **认领是地基。** 每个分镜声明 `beats:[起,止]`，全场连续区间、不重不漏；一个镜头可以覆盖连续多拍。先按观看任务确定镜头，再对账节拍，不能根据节拍条数直接确定切数。切完在心里过一遍：每场第 1 拍到最后一拍都有主吗？
2. **秒数是下单不是估算。** 分镜秒数直接决定切点时刻和对齐指令——改秒数必须同步改 `h3Prompt`，validate 逐字对账，改一边必被拦。
3. **台词装得下。** 认领节拍的台词秒数 ≤ 分镜秒数。4.4 秒的台词就给 5 秒的切。
4. **景别短语进分镜图提示词，运镜词进这一切自己的镜头正文里。** 一切一个运镜，写成自然的动作句。**用哪种语言的运镜词，跟着这份分镜的 `promptLang` 走**：英文模式用官方英文词（Push In / Pan Left / Tracking Shot…，`a slow push in toward…`），中文模式用 `schema.md` 词表的中文词（推 / 摇 / 跟拍…，「镜头小幅缓推向掐白的指节」）。门按 `promptLang` 逐切对账，写错语言当场拦——别把一种协议的语言当成所有分镜的默认。
5. **分镜图提示词直呼角色名；视频正文一律用通用身份。** 两半的规矩相反，因为定规矩的不是同一个人：
   - **分镜图提示词（frame）写名字**（张三、王五）。它是唯一带着设定图一起生成的那张——场景图、角色设定图、道具图都挂在提示词上并按名字列出，名字因此是**指向某张参考图的地址**，不是省略了外貌描写。同框两个年轻男子时，通用身份说不清哪张脸配哪句动作。
   - **视频正文（`h3Prompt` 的镜头行、Seedance 的 `shot`）不写名字**，用通用身份（an old ferryman、一名铁灰袍中年男子）。**这是 MiniMax H3 和 Seedance 官方提示词规范的硬性要求**，不是我们能放宽的。姓名只许出现在台词原文里。
   角色设定图、场景图、道具图的提示词同样禁名字——那几张是**从文字长出来的**，没有参考图可指，名字在那里就是一个本该写外貌的空洞。
6. **构图量化进字段，段有走位。** 每镜填 `lens` / `cameraPosition` / `composition` / `eyeline` / `focus` / `stability`；每段填 `blocking`（开场谁在左谁在右、朝向、间距）。写法见 `shot-writing.md`「构图要量化」。这是替代分镜图的那部分信息：不出分镜图时它们就是构图的全部来源，出分镜图时它们让图和正文说的是同一个镜头。

## 按观看过程选择镜头（不设自动质量门）

将场面目的落实为连续事件、对话或情绪变化中的观看过程：观众从什么已知信息出发，随后需要观察谁或什么，最后确认哪项变化。这个过程可以跨生成段，不能每到新的生成段就重做进场、蓄势或高潮。各切的主要任务与切换理由简记在既有 `note` 中，再安排具体摄影与动作承接；不新增字段，不把制作判断复制到生成正文。

- **切点跟随可读的变化。** 新信息、动作转折、听者反应或结果确认都可以成为切换依据；持续等待也可能需要同一构图。按信息辨认、对白与动作所需时间分配切长，不机械交替远近、动静或长短。参考片的短切不自动成为生成能力保证；现有范围容纳不了必要节奏时说明缺口，由项目确定是否调整已有参数，再同步时长和提示词。
- **对话先选择观察对象。** 需要看双方关系时可以保持双人镜头，需要看信息造成的影响时考虑听者反应，发声细节重要时观察说话者。正反打、带肩部前景与独立近景都是候选，不按每句问答强制切换；画内发声与画外音按剧本安排，不能为构图任意移走对白。
- **开场先给当前最有用的信息。** 运动主体、环境关系或关键静物都可以开场，取决于故事需要先建立什么。局部开场后在观众需要辨认空间时补足关系，不强制“运动主体—远景—特写”的顺序，也不为避免静止增加行动。
- **一镜集中承担一个主要观察任务。** 任务具体到观众需要辨认的一项行动、反应或关系变化，相关动作与应对围绕它展开。当前构图能清楚承载连续变化时可以持续观察；观察重点转移或关键过程需要不同观察范围时，再判断切换。不按动词数拆镜，也不以宽泛的场面目的把多个独立任务挤入同镜。
- **反应有触发与时间。** 反应可在双人构图中发生，也可由已有节拍支持独立镜头。观察是否延续原反应、是否需要面部可见；不为补齐反应镜头新增情绪事件或重演同一次惊讶。
- **动接动或结果接反应都可成立。** 动作中切换时明确前镜结束与后镜起始处于哪个阶段，保持方向、接触与结果连续；动作完成后再切可以让观众确认后果。模型生成不代替逐镜与跨段的连续性核对。
- **生成段边界服从事件。** 剧本有悬念时让它可见；连续事件尚未完成时，把实际动势和持物状态交给下一段。不为每个生成段额外制造钩子、终结动作或重新蓄势。
- **运动由观察收益决定。** 固定摄影能通过主体掠过、距离变化和遮挡产生动感；跟拍可以保持主体可读，同时让既有环境提供速度参照。逐镜说明为什么需要移动或保持固定，不使用每段运镜种类的配额。具体关系写法见 [镜头正文](shot-writing.md)。

## 整组复核与重新编排

提示词完成后，连读同一连续事件的镜头及跨段边界，对照原定观看过程检查：人物行动的原因、关键反应和结果是否可读；每次切换补足了什么；持续等待或重复构图是否有具体的强调与观察收益。移动和省略另按 `continuity.md` 做观众视角复核，判断实际声画是否足以连接前后位置、时间与人物回应；写有“已到达”或“有剧本依据”不能代替这项判断。动作、接触与位置清楚只能证明局部可读，不能单独证明镜头数量与切换合理。

修订使某镜任务提前完成、转移或消失时，重新判断相关镜头是否还需要独立存在。可以在故事事实与项目参数内合并镜头、重新分配时长或调整分段；合并镜头仍完整认领其连续节拍，不删去必要事件。同步受影响的关键帧、累计切点、H3、声音与图片绑定，重新校验。若需要改变剧情或项目参数，写明具体缺口与调整依据，不能通过添加无收益的动作或停顿填满原镜长。

## 参考图纪律（分镜图质量的一半在这）

分镜图生成 = 提示词 + 参考图。切镜时就想好每格要挂哪些参考：

- 场景设定图（该段场景 + 光照状态）——必挂
- 画内每个角色的设定图——有几个挂几个
- 画内叙事道具的设定图——有就挂

提示词与参考图冲突时，模型听参考图的——所以提示词专心写构图、**此刻的位置状态**（已上船 / 在舱内 / 在桥头）和姿态，长相材质交给参考图。画面里出现的大资产（船、车、宅门）也要挂它自己的设定图，不挂就每帧长得不一样。

## 常见病

| 病 | 症状 | 治法 |
| --- | --- | --- |
| 观察重点不清 | 关键反应或动作结果始终无法辨认 | 按信息缺口调整机位、构图或切点；同镜已能看清时可以持续观察 |
| 机械重复 | 连续镜头以相同方式重复同一信息，缺少等待或强调的理由 | 检查各切新增的观察任务，再决定保留、调整取景或重新分配时长 |
| 秒数漂移 | 改了分镜秒数忘改提示词 | validate 会拦：对齐指令和切点时刻逐字对账 |
| 台词爆仓 | 4.4 秒的台词塞 3 秒的切 | 加秒或拆切 |
| 声景漏改 | 画面改成搭手卸担，环境音还写着铜铃撞击 | **声景也是动作指令**——剧本动作一改，描述、声景、中文对照三处一起改（踩过：视频真把撞击演出来了） |
| 特写失忆 | 大特写的道具和设定图长得不一样 | 挂道具设定图当参考，提示词提锚点特征 |
| 换景不换段 | 一段里从栈桥切进船舱 | 换景必开新段——一段一个环境锚 |
| 省略只在备注成立 | 前镜人物仍在远处静止，后镜已贴近他人，对话缺少接近或察觉的触发 | 重新判断省略范围，将必要的走近、抵达或有依据的时间识别落实到实际正文，并重分时长 |
| 改切不读邻切 | 第 1 切改成岸路奔跑，第 2 切还写着栈桥才露出来，图却画在栈桥上 | 改一切连读前后切，分镜图和文字逐格对照——位置是连续状态 |
