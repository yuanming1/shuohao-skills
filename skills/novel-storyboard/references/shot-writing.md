# 镜头正文 · 写法规范（协议无关）

本文件规定关键帧与视频正文的内容取舍。`frame` 描述切点当下的单一画面；`shot` 与 H3 对应镜头描述从这里开始的动作与结果。视频协议分别见 `h3-prompt.md` 与 `seedance-prompt.md`，两份协议规范均以本文为前提。

## 镜头重点与正文取舍

按 `storyboard-pass.md` 确定的主要观察任务选择构图和细节，让动作、对白与配角反应共同服务这一重点。必要的协同动作可以同镜完成；环境与道具按理解当前变化的需要入画。

`frame` 写清中文景别、角色名、当前姿态与视线，以及理解画面所需的位置、持物、接触和遮挡。`shot` 与 H3 从该状态推进，保留关键因果、表演和承接。身份与外观沿实际参考；完整布局、修改原因和待核实事项留在 `blocking`、`note` 或制作说明中。

修订时将调整融入原句，删除被替代的描述，合并同义说明，交付重新整理的正文；不在旧正文后连续追加“摄影补充”“表演补充”或纠错清单。参考职责说明一次，只保留当前镜头需要的例外，不复制其他镜头的模板内容。

按画面需要保留细节，不设统一字数上限或自动截断。整理后核对：能否一遍读懂主体与当前状态，必要的情绪、接触和连续性是否仍然清楚。去重限于同一份生成输入；独立关键帧和独立视频段仍须各自具备必要说明与真实参考，不能依赖另一节点或上次生成的记忆。

## 每一切只有一个主运镜

从 `schema.md` 的 camera 词表里选一个主运镜，写进这一切自己的正文里，写成自然的动作句（「镜头小幅缓推向掐白的指节」），可加幅度（小幅/大幅）与速度（缓/快）。一个观察目标和一条主要路径优先，避免在短镜头里堆叠环绕、急推、后拉等互相竞争的阶段；这是本技能的编排约束，不是对模型必然行为的保证。
为持续跟随同一对象而作的小幅视向修正可以作为主运动的辅助描述，前提是不改变观察任务、主路径与已有字段含义。需要先跟随人物、再独立摇向另一对象时，应明确为新的观察阶段，按当前切数和时长安排，不能藏在“跟拍”里。

## 把运动写成可观察的关系

需要表达移动、速度、尺度或揭示时，在已有字段与正文中说明以下关系；固定对话等简单镜头不必机械逐项填写，不新增字段：

- 主体正在做什么、向哪个既有场景位置移动；摄影机的移动另写，不把主体后退写成镜头后拉。
- 摄影机从什么位置观察、跟随哪个部位，运动中维持什么范围或距离关系；相对位置足够时不编造测量值。
- 哪个已有前景或背景提供参照，移动时怎样经过或遮挡；不能为了“电影感”新增柱子、车辆或烟尘。
- 终点仍要看清什么：反应、接触、到达位置或环境结果；主体出画也需说明画面留下的观察对象。

固定摄影中的身体掠过、近处遮挡或距离缩短，同样可以产生动感。跟拍使主体相对稳定时，可由环境的相对位移体现速度，不必同时放大主体、剧烈抖动和增加模糊。遮挡可以帮助转移注意，但关键接触与结果要在所需时刻可读。

同一镜后拉显露环境，与切到另一个全景机位，是两种安排：前者起始关键帧保持较近构图，后者起始关键帧直接使用新的景别。字幕中的“盘旋、升空”也要辨认属于主体还是摄影机，不能直接作为 `camera` 取值。参考观察来源见 [切镜规则](storyboard-pass.md) 的来源说明；实际生成速度与效果仍需成片复核。

## 动作要能在这几秒内做完

这一切有几秒，动作就只能是几秒能做完的事。普通叙事沿用常见动作原则，按人物目的、紧迫程度与实际过程选择动作强度，保留决定观众理解的变化；不堆叠对当前剧情没有作用的细小操作。动作估时用于预算，不能把每个动词都写成必须单独完成、单独停住的一镜。

**打戏按需进入本目录的 [打戏编排分支](combat-direction.md)。** 剧本已经要求的追击、腾空、碰撞和摔投保留其动作强度，按可见的接触、受力和应对展开，不能统一降成慢走与轻抬手。短攻防可以在一切内连续完成，复杂换位或摔投按动作阶段拆切，仍遵守时长与节拍认领合同；无法容纳时返回分段安排，不能靠“快速连招”省略过程。

**动作怎么写**（学自 Seedance 官方指南，对 H3 同样成立）：

- **肢体细化 + 程度量化**：具体到手、腿、头、肩背，并带幅度与速度——「缓慢抬手」「快速转头」「用力蹬地」「微微低头」
- **速度与力量服从剧情**：日常交流可以低缓，既定的急救、阻拦、逃离也应保留必要的快速反应与受力；单次急促行动仍可按普通叙事处理，连续攻防再按打戏分支编排。生成时长不足时调整分镜安排，不把急冲改成慢走，也不为填满镜长延迟应对或添加停顿
- **写出前后动作的承接**：「借着转身惯性顺势抬手」「从停顿状态自然过渡到举手」，动作才连贯
- **情绪外化与人物意图结合**：先明确人物此刻的意图与情绪，再选择当前景别可见、符合人物性格与反应强度的少量表现，避免套用固定动作清单或堆叠微表情

## 人物此刻在哪，要和分镜图一致

正文里人物的**位置状态**（已上船 / 还在岸上 / 在舱内）必须和这一切的分镜图一致。图与文对不上时模型听图的，动作就乱。分镜图钉的是这一切开始的那一瞬，正文从那一瞬往后写。

镜间移动与时间省略先按 [动作承接规则](continuity.md#镜间移动与时间省略) 设计。后镜承担最后几步抵达时，关键帧保留尚未站定的状态，正文再完成走近与停步；直接从到达后开场时，应已有足够的叙事与声画依据。`note` 中的“按剧本省略”不会进入观众看到的画面，不能代替必要的行动、抵达或回应。前后镜与 H3 同步修改，声音不能把已省略的整段移动误写为连续实时过程。

## 台词逐字保留，身份写在台词外面

认领的台词**一个标点都不许动**，逐字进正文。说话人的身份、年龄段、音色、语气、是否画外音写在台词**外面**，不塞进台词里。怎么标记台词（`<d>` 标签还是中文引号）由协议规范决定，这里只管「原文不许变」。

## 不写角色姓名，用通用身份

正文里写「一名铁灰袍中年男子抬头看向门口」，不写「张三抬头看向门口」。

**这是视频服务自己的规范，不是我们的偏好**：MiniMax H3 和 Seedance 的官方提示词规范都要求
用通用身份指代人物。姓名只许出现在台词原文里（怎么包住由协议规范决定），台词逐字保留，
里面的称呼是剧本的事。

注意跟**分镜图提示词**区分开：那一侧恰好相反，要直呼其名——分镜图是带着角色设定图一起生成的，
名字在那里指的是挂上去的那张参考图。两侧的规矩不一样，因为两侧的规范不是同一个人定的。

## 构图要量化，不能只写景别

分镜图一直在悄悄替正文干一件事：说清**多近、多满、谁在哪、眼睛看哪**。纯参考图出片时没有那张图，
这些信息要么写成字，要么就地消失——实测消失的正是它们：景别偏远、动作偏小、人物摆位随意。

所以每一镜除了正文，还要填这几个字段（`schema.md`）：

- **焦距 + 景深**（`lens`）：`50mm 标准，中浅景深`、`85mm 长焦，极浅景深`。焦距决定"多近"，景深决定"背景虚不虚"
- **机位**（`cameraPosition`）：对着谁 + 什么角度。`李四 + 平视正面`、`双人 + 俯视 30°`
- **构图**（`composition`）：三分法 / 中心构图 / 对角线 / 对称——一镜一个
- **视线落点**（`eyeline`）：对方面部 / 手中之物 / 闭眼。视线是表演的一半
- **焦点**（`focus`）：锁定什么。跟视线落点常常不同：眼睛看对方，焦点在手里的刀
- **稳定性**（`stability`）：稳定 / 微晃 / 手持。它跟运镜是两件事——固定机位也可以微晃

段级再加一条**人物关系与构图逻辑**（`blocking`）：开场那一瞬谁在画面左、谁在右、面朝哪、
相距多远（用厘米或步数）。它是整段的空间地基，各镜从它出发；只写一次。

上述字段继续完整填写，供程序和拍摄复核使用。`frame` 仍须包含中文景别及形成当前画面所需的构图事实，因为独立出图不会自动读取其他字段；`shot` 按动作顺序组织，不把字段清单再次逐项抄入正文。两者与摄影字段保持一致，重复表达在各自最终生成输入中合并。

## 参考图只锁身份，不锁构图

人物、场景、道具的参考图用来锁定**身份、脸型、服装、场景结构、道具造型**。正文不要照搬参考图的构图、排版、视角——这一切的构图由这一切的分镜图和正文决定。怎么在正文里引用参考图（`<Picture k>` 还是 `@图片N`，还是由程序加）由协议规范决定。

## 声音分三层，各归各

- **台词、歌声、剧内音乐**（角色听得见的）→ 写在镜头正文里
- **环境声、动作声、非语言人声**（喘气、脚步、铜铃）→ 声景字段，不复述台词
- **配乐**（角色听不见、只有观众听得见）→ 配乐字段，写配器与速度；没有就按协议规范写「无」

**声景也是动作指令**：画面动作改了，声景必须一起改。声景里写「铜铃在撞击时炸响」，视频就真会把撞击演出来。

## 不写的东西

- **不新增剧本没有的**人物、道具、故事事件、对白、画面上的可见文字。可以展开既定动作的必要过程，例如将“挡开后脱身”细化为接触、偏转与离线；不能扩写成打伤、缴械或觉醒。分镜是资产合成，不是凭空画。
- **不写画风**。「电影感」「冷灰绿色调」「半写实」这类是渲染层的事，由调用方在出图/出片时统一附加；写进正文只会跟当时选的画风打架。
- **不写朝代之外的年代词**。「古代」「古装」不是画面；服制、器物、建筑形制才是，而这些已经在设定图里定了。
