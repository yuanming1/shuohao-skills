# 动作承接：先规划，再写提示词

在分段切镜后、编写 `frame`、`shot` 与 `h3Prompt` 前执行。这一步是规划与语义复核，不是 18 道结构门能自动证明的能力；只交文字也不能跳过。

## 每切留一份可核对的安排

复用已有 `cut.note`，按下面四个标签写短句；不用新增 JSON 字段。该备注进入 Markdown / HTML 报告，供写提示词与人工复核共同使用。原有拆解说明或配方备注可以追加，不能被承接内容覆盖。

> 起始：人物位置、姿态与接触关系；关键道具由谁持有；环境当前状态。
> 动作：本切认领的剧本动作，以及动作发生的顺序。
> 结束：动作之后哪些状态改变，哪些保持。
> 接镜：如何承接上一切；第一切写开场位置，换场或有意时间省略写明剧本依据。

只记录影响连续性的事实，不罗列无关细节。移动与交接涉及哪只手时才锁定持握手；静态场景无需每切复述全部布景。

## 先检查状态，再选择构图

先把每一对相邻切当成一道实际推理题：上一切**真正写进镜头正文并可见完成**的结束状态，能否推出下一切起始？不能用下一切备注中的「已坐起」「已站稳」反向补造上一切没有发生的动作。逐条对照认领的剧本动作是否进入 `shot` 与 `h3Prompt`，节拍编号覆盖不等于动作内容覆盖。

跨场也检查叙事关系：上一切看手机，下一切却悬空施法，必须能在剧本中找到时间跳转和观众可见的识别方式；不能由 `note` 自行宣布这是回溯。剧本缺时序出入口时退回剧本，不靠外景、切黑或新旁白擅自补戏。

1. **相邻切共用同一空间。** 先明确阵台、殿柱、出口等关键位置关系，再选机位。换景别、正反打可以改变画面左右，不等于人物必须换位；没有剧本动作，不得为了构图把正在搀扶的两人分开。
2. **接触关系要有过程。** 扶住、松手、站稳、转身等变化必须在对应动作中发生；只改视线就只改视线，不额外编造走位。需要过渡而剧本未提供时，优先调整构图保持原状态；无法保持且会新增剧情时，指出上游缺口，不私自改戏。
3. **道具持续存在，但不必持续入画。** 明确仍持有但被遮挡、暂时在画外、收起、放下或交接。画外不等于消失；禁止在交付前让接收者拿到道具。`cut.props` 仍只列画内道具，画外持物在备注中承接。
4. **环境变化不能随切镜重置。** 区分变暗、间歇闪烁、完全熄灭和恢复。变暗后继续残光不算恢复；完全熄灭后重新亮起需要对应动作或剧情依据。art 的光照变体只提供基础气氛，不能覆盖当前剧情状态。
5. **跨段也要接。** 同场连续时间的下一段首切承接上一段末切；换场、插入镜头、反应镜头或有意时间省略按叙事关系核对，不强求所有镜头具有相同构图。

## 同一份安排喂给三种提示词

- `frame`（中文，直呼角色名）描述切点当下的单一状态，可以是动作中途，但必须明确所处阶段。不要用一条提示词同时描述起身、走近、递交、退开的完整过程。
- `shot`（镜头正文）先承接这一状态，再写接下来发生的动作与结束状态；`frame` 已经画出的动作不要重演。
- `h3Prompt` 的对应 `[Shot k]` 段落与 `shot` 说同一件事：起始一致、动作一致、结束一致。
- 保留剧本台词与节拍，不为接镜改写对白。角色设定只锁外貌与服装；其中的持物、姿势、伤势或表情不自动成为所有镜头的当前状态。
- 只写对本镜有用的动作与延续条件，不把整份计划机械粘贴进提示词。

## 正反例：只转头，不把扶持拆开

剧本：男主失衡扶柱 → 弟子扶住他 → 男主看向殿外，再看弟子说话 → 下一段才递袋子。

| 切 | 起始 | 动作与结束 | 接镜要求 |
| --- | --- | --- | --- |
| 失衡与搀扶 | 男主在阵眼旁的殿柱近处，手机仍握在右手；弟子在身侧，尚未接住 | 阵纹骤暗；男主左手扶柱，弟子扶住其左上臂，结束时仍搀扶 | 用已建立的近邻位置完成动作，不突然换到远处柱子 |
| 交代撤离 | 延续搀扶和手机持握，阵纹保持残光 | 男主望向殿外再转头说话，两人不移动 | 可切近景，但不能新增「阵盘隔在两人之间」；弟子尚无袋子 |

以下都要解释或返修：扶人后无松手过程就站开、交袋前接收者已拿袋、灯全灭后无故复亮、手中手机无交代地消失。以下本身不是错误：正反打的画面左右变化、特写裁掉持物手、道具被身体遮挡、剧本明确的换场或时间省略。

## 结构与语义分开

- **结构校验**：18 道门核对节拍编号、时长、台词、引用与格式；不能证明动作连贯。
- **承接语义复核**：逐切对照剧本、备注、`frame` 与 `shot` / `h3Prompt`，检查动作落实与前后状态，不以备注存在或标签齐全替代判断。
- 成图连续性在下游：外部出图后拿这份备注当核对清单，是使用者的判断，不是本 skill 的流程。

修一切后连读前后切及跨段边界；状态变化影响更远处时继续追到再次建立状态的镜头。

## 反例驱动复核

| 表面上写齐了 | 实际仍不成立 | 应如何修 |
| --- | --- | --- |
| 上切结束睁眼；下切起始已坐起 | 起身动作没有进入任何镜头正文 | 在认领该动作的镜头落实坐起，或保持原姿态取景 |
| frame 写跪扶；正文再跑来跪扶 | 同一切点同时是起点和终点 | 改成尚未接触的起始状态，或保留终态并把走近动作放到此前 |
| 备注保持坐地；近景构图却让另一人仰望高处 | 构图违背人物高度和接触关系 | 保持坐地/跪扶的视线高度，改该镜机位与构图字段 |
| 两镜都写黑色手机 | 摄像头模组、厚度、边框已经换款 | 在两镜 `frame` 里统一可识别的道具锚点，挂同一张道具设定图 |
| 备注称回到此前 | 剧本与画面没有时间识别方式 | 回到剧本解决，不能以备注代替观众看到的转场 |
