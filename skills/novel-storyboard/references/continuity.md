# 动作承接：先规划，再写提示词

在分段切镜后、编写 `frame`、`shot` 与 `h3Prompt` 前执行。这一步是规划与语义复核，不是 18 道结构门能自动证明的能力；只交文字也不能跳过。

连续攻防的完整编排先按 [打戏分支](combat-direction.md) 在分段前完成；本文件继续负责逐切落实与跨段承接。格挡被破开、兵器被带偏或人物失衡后，下一切从这一状态继续，不因切镜恢复完整护架或重新持有已经失去的兵器。

## 每切留一份可核对的安排

复用已有 `cut.note`，按下面四个标签写短句；不用新增 JSON 字段。该备注进入 Markdown / HTML 报告，供写提示词与人工复核共同使用。原有拆解说明或配方备注可以追加，不能被承接内容覆盖。

> 起始：人物位置、姿态与接触关系；关键道具由谁持有；环境当前状态。
> 动作：本切认领的剧本动作，以及动作发生的顺序。
> 结束：动作之后哪些状态改变，哪些保持。
> 接镜：如何承接上一切；第一切写开场位置，换场或有意时间省略写明剧本依据，以及观众从哪些实际画面或声音理解变化。

只记录影响连续性的事实，不罗列无关细节。移动与交接涉及哪只手时才锁定持握手；静态场景无需每切复述全部布景。

## 先检查状态，再选择构图

先把每一对相邻切当成一道实际推理题：上一切**真正写进镜头正文并可见完成**的结束状态，能否推出下一切起始？不能用下一切备注中的「已坐起」「已站稳」反向补造上一切没有发生的动作。逐条对照认领的剧本动作是否进入 `shot` 与 `h3Prompt`，节拍编号覆盖不等于动作内容覆盖。

跨场也检查叙事关系：上一切看手机，下一切却悬空施法，必须能在剧本中找到时间跳转和观众可见的识别方式；不能由 `note` 自行宣布这是回溯。剧本缺时序出入口时退回剧本，不靠外景、切黑或新旁白擅自补戏。

1. **同场相邻切共用空间关系。** 先明确阵台、殿柱、出口等关键位置关系，再选机位。换景别、正反打可以改变画面左右，不等于人物必须换位；没有剧本动作，不得为了构图把正在搀扶的两人分开。
2. **接触关系要有过程。** 扶住、松手、站稳、转身等变化必须在对应动作中发生；只改视线就只改视线，不额外编造走位。需要过渡而剧本未提供时，优先调整构图保持原状态；无法保持且会新增剧情时，指出上游缺口，不私自改戏。
3. **道具持续存在，但不必持续入画。** 明确仍持有但被遮挡、暂时在画外、收起、放下或交接。画外不等于消失；禁止在交付前让接收者拿到道具。`cut.props` 仍只列画内道具，画外持物在备注中承接。
4. **环境变化不能随切镜重置。** 区分变暗、间歇闪烁、完全熄灭和恢复。变暗后继续残光不算恢复；完全熄灭后重新亮起需要对应动作或剧情依据。art 的光照变体只提供基础气氛，不能覆盖当前剧情状态。
5. **跨段也要接。** 同场连续时间的下一段首切承接上一段末切；换场、插入镜头、反应镜头或有意时间省略按叙事关系核对，不强求所有镜头具有相同构图。

## 镜间移动与时间省略

人物从一处到另一处、远处走近他人、进出房间或换段后出现在新位置，均在分镜初稿处理。剧本明确省略路程，只说明可以压缩时间；分镜仍须判断被略去的过程是否影响观众理解。移动承载的接近方式、察觉、停步或既有对白的触发，需要落实到实际画面，不能全部藏进“稍后已到达”。

- **先区分连续动作与时间省略。** 连续动作继承前镜的方向、阶段和动势；省略可以跨过中途，但要有足够的声画关系，让观众理解同一人物为何出现在新位置。场景锚点、已建立的目标、人物动作及剧本已有的时间变化都可参与判断；不靠备注宣告，也不擅加字幕、旁白或新事件解释。
- **按表达需要选择保留范围。** 可在一镜内看清走近，也可呈现开始行动后切到最后几步抵达，或依据已建立的叙事关系直接进入后来状态。选择能交代本场必要因果的安排，不把“出发加抵达”变成每段移动的固定模板；没有信息变化的中途可以压缩。
- **接近他人时检查回应的触发。** 对方何时能看见或听见来人，后面的目光、退让或质问是否有既有故事依据与发生时间。故事需要的察觉与回应应可见；不为了补衔接新增戒备、惊讶、让路或其他情绪事件。
- **把衔接写进实际消费端。** `frame` 描述后镜切点的单一状态；后镜需要继续走近时，不能把起始帧提前画成已经站定。移动、抵达及回应进入 `shot` 和 H3 对应镜头；声音与实际行动阶段同步，`blocking`、`note` 记录依据，不能代替正文。不能只在正文写“稍后”而仍让画面缺少必要过程。
- **为必要过程重新安排时长。** 加入走近或停步后，复核移动、对白与反应能否自然容纳；需要时重新分配镜长、切点或生成段，连同节拍认领和提示词一起更新。不能以“快速走完”掩盖距离，也不能保留原镜长再把所有动作挤进去。

### 自有短例：修鞋铺取件

故事先确定：傍晚修鞋铺即将关门，顾客在门口询问能否取回已经修好的鞋，店主在柜台后答应；顾客随后走到柜台前，店主才交还鞋子。门口与柜台的关系已在场景中建立，剧本允许省略中间步行。本例只讨论交还前的接近，不新增对白或人物态度。

| 安排 | 实际呈现与判断 |
| --- | --- |
| 只解释到达状态 | 前镜顾客仍静止在门口，后镜已贴近柜台并开始交还，备注写“按剧本省略”；若观众仍需猜测接近与交还如何衔接，就须退回，不能以备注有依据判通过 |
| 压缩中途、保留必要抵达 | 前镜答复后顾客向柜台迈步；后镜从靠近柜台的最后几步开始，停妥后再交还。起始帧仍在行走，正文完成停步，不重演出发；按实际过程分配时长 |
| 同镜完成接近 | 构图与预算足够时，让顾客走到柜台前再进行后续交还；不为遵守模板额外切镜 |

直接进入后来状态也可能成立：若剧本本来明确安排次日再取，前后场已有可辨认的时间和场景关系，可以直接从次日柜台前开场，不必补拍跨日的全部过程。是否省略取决于实际声画和叙事关系，不能只按位移大小判定。

## 同一份安排喂给三种提示词

- `frame`（中文，直呼角色名）描述切点当下的单一状态，可以是动作中途，但必须明确所处阶段。不要用一条提示词同时描述起身、走近、递交、退开的完整过程。
- `shot`（镜头正文）先承接这一状态，再写接下来发生的动作与结束状态；`frame` 已经画出的动作不要重演。
- `h3Prompt` 的对应 `[Shot k]` 段落与 `shot` 说同一件事：起始一致、动作一致、结束一致。
- 保留剧本台词与节拍，不为接镜改写对白。角色设定只锁外貌与服装；其中的持物、姿势、伤势或表情不自动成为所有镜头的当前状态。
- 只写对本镜有用的动作与延续条件，不把整份计划机械粘贴进提示词。

## 正反例：只转头，不把扶持拆开

剧本：男主失衡扶柱 → 弟子扶住他 → 男主看向殿外，再看弟子说话 → 下一段才递袋子。

| 切 | 起始 | 动作与结束 | 接镜要求 |
| --- | --- | --- | --- |
| 失衡与搀扶 | 男主在阵眼旁的殿柱近处，手机仍握在右手；弟子在身侧，尚未接住 | 阵纹骤暗；男主左手扶柱，弟子扶住其左上臂，结束时仍搀扶 | 用已建立的近邻位置完成动作，不突然换到远处柱子 |
| 交代撤离 | 延续搀扶和手机持握，阵纹保持残光 | 男主望向殿外再转头说话，两人不移动 | 可切近景，但不能新增「阵盘隔在两人之间」；弟子尚无袋子 |

以下都要解释或返修：扶人后无松手过程就站开、交袋前接收者已拿袋、灯全灭后无故复亮、手中手机无交代地消失。正反打的画面左右变化、特写裁掉持物手、道具被身体遮挡本身不是错误；换场或时间省略有剧本依据后，仍须按上述规则核对观众能否理解，不能自动放行。

## 结构与语义分开

- **结构校验**：18 道门核对节拍编号、时长、台词、引用与格式；不能证明动作连贯。
- **承接语义复核**：逐切对照剧本、备注、`frame` 与 `shot` / `h3Prompt`，检查动作落实与前后状态，不以备注存在或标签齐全替代判断。再暂时遮住备注与制作说明，只连读实际画面、视频正文和声音：观众能否理解人物为何换位、何时接近、对白为何在此触发，以及切换属于连续动作还是时间省略？只有作者知道的解释不能算通过；必要过程漏写须在初稿解决，不留待增强补救。
- 成图连续性在下游：外部出图后拿这份备注当核对清单，是使用者的判断，不是本 skill 的流程。

修一切后连读前后切及跨段边界；状态变化影响更远处时继续追到再次建立状态的镜头。

## 反例驱动复核

| 表面上写齐了 | 实际仍不成立 | 应如何修 |
| --- | --- | --- |
| 上切结束睁眼；下切起始已坐起 | 起身动作没有进入任何镜头正文 | 在认领该动作的镜头落实坐起，或保持原姿态取景 |
| frame 写跪扶；正文再跑来跪扶 | 同一切点同时是起点和终点 | 改成尚未接触的起始状态，或保留终态并把走近动作放到此前 |
| 备注保持坐地；近景构图却让另一人仰望高处 | 构图违背人物高度和接触关系 | 保持坐地/跪扶的视线高度，改该镜机位与构图字段 |
| 两镜都写黑色手机 | 摄像头模组、厚度、边框已经换款 | 在两镜 `frame` 里统一可识别的道具锚点，挂同一张道具设定图 |
| 备注称回到此前 | 剧本与画面没有时间识别方式 | 回到剧本解决，不能以备注代替观众看到的转场 |
| 剧本和备注都写省略路程；下一镜人物已在身旁 | 到达后的站位明确，但实际画面没有交代必要的接近或后续回应的触发 | 重新选择省略范围，将必要的行动与抵达写入正文，调整起始帧和时长，再连读前后镜 |
