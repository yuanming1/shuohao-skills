# Novel Infinite Canvas

使用本技能把已经完成的短剧分镜打成原生 Infinite Canvas 项目包。脚本完全使用 Node 标准库，不依赖画布应用、npm 包或其他技能。

## 输入要求

必须提供同一批项目的四份 JSON：

- `storyboard.json`：每段必须有 `id`、`sceneIndex`、`cuts`、`h3Prompt`、`blocking`。
- `script.json`：用于按 `sceneIndex` 找到正确场次、道具和逐字台词。
- `art.json`：用于生成场景/道具参考节点及其连线。带可选顶层块 `palette`（novel-art 2.1 起的全局色卡）时会额外生成一个全局色卡节点，连到每个关键帧组合节点。
- `cast.json`：用于生成角色主参考和独立多视角节点。

使用已经完成本次空间安排、表现增强和动作修订的最终 `storyboard.json`；这些处理沿用原结构，不增加专属动作字段。`frame`、`shot`、摄影字段、H3 与声音应在上游同步完成。对比报告、`plan.json`、`staging.json` 不是正式分镜的替代输入，导出器不会从报告重建动作。详细字段去向及兼容规则见 [输入交接](references/input-contract.md)。

角色卡没有 `id`、而分镜使用 `C01` 等编号时，必须另给 `--outline <outline.json>`，按大纲角色姓名匹配角色卡的姓名或别名。旧角色卡已有明确 `id` 时可直接导出；缺失、重复或冲突的角色映射会报错，不按角色数组顺序猜测。`art.props` 可以省略，无道具时按空表处理。

可选 `images` 目录放已确认可用的场景、道具图片，写实与动画风格均可；目录会递归读取，场景光照图可以放在子目录。人物图片另用 `--character-images` 指定已经裁好的主参考与视图。脚本只嵌入能够对应 `art.json` 场景/道具或角色卡姓名的图片；不会自动打包未知图片。

检查项目是否已经有预演交付。存在 `grid-input.json`、`grid-prompt.txt` 时，通过 `--previz <目录>` 一起导入，不要只导出四份 JSON 而遗漏已经完成的预演。接受普通宫格和带 `planning` 的站位宫格；格式、匹配和参考图片规则见 [预演导入](references/previz-import.md)。没有预演交付时，仍从 storyboard 中导入已有的空间与拍摄字段，不自行补写缺失站位。

## 导出

```bash
node {baseDir}/scripts/export-infinite-canvas.mjs export \
  --storyboard <剧名>-storyboard.json \
  --script <剧名>-script.json \
  --art <剧名>-art.json \
  --cast <剧名>-cast.json \
  --outline <剧名>-outline.json \
  --images <场景与道具图片目录> \
  --character-images <角色裁图目录> \
  --out <输出目录>/<剧名>-分镜画布.zip \
  --title "<剧名> · 分镜投产画布"
```

图片文件名遵循 `novel-art` 的导出约定时可自动匹配：

- 场景光照：`<场景名>-L<序号>-<光照状态>.png`，或 `<场景编号>-<两位序号>-<光照状态>.png`
- 道具状态：`<道具名>-S<序号>-<状态>.png`，或 `<道具编号>-<两位序号>-<状态>.png`
- 设定图：`<场景或道具名>-sheet.png`
- 全局色卡：`palette-sheet.png`
- 角色设定图：`<角色名>-sheet.png`
- 角色主参考：`<角色名>-正面全身.png`
- 角色视图：`<角色名>-正面头像.png`、`<角色名>-侧面90度.png`、`<角色名>-背面全身.png`

缺少角色主参考裁图时回退到 `<角色名>-sheet.png`；缺少某张视图时保留该视图节点，等待后续生成。角色设定图会作为独立的 `角色设定图` 节点嵌入并连到主参考，不直接连到关键帧。场景或道具缺少具体光照/状态图时，关键帧回退到对应设定图。

可选参数：

- `--constraints <文本文件>`：每行一条 Seedance 全局约束。
- `--outline <outline.json>`：角色卡没有编号时提供姓名到大纲角色编号的映射；已有编号的角色卡可以省略。
- `--previz <目录>`：导入该目录下与当前分镜匹配的预演宫格，包括原始提示词、站位说明、逐镜拍摄安排和明确指定的参考图片。
- `--character-images <目录>`：提供已经裁好的人物主参考与独立视图；目录会递归读取。
- `--character-sheets-only`：只嵌入完整人物设定图，并直接作为角色参考连接到关键帧；跳过正面全身主参考和全部独立视图。
- `--project-id <标识>`：指定画布项目及本地图片存储键前缀。
- `--no-character-views`：只创建角色主参考图节点，不创建多视角和局部锚点节点。

## 固定导出规则

- 每一格关键帧创建生图组合节点（画布原生 `config` 类型，界面显示「生成配置」），生成时另建图片结果节点。组合节点使用 `composerContent` 保存可编辑提示词，末尾将每个已连接参考图的节点名称与 `@[node:<节点 ID>]` 一一对应；只连接参考图而没有正文引用，不能保证图片被提交。
- 每一格关键帧提示词以未经改写的最终 `cut.frame` 开头，末尾仅增加参考图对应关系与职责说明。空间、表情和动作修订必须已进入 `frame`；不再追加整段开场站位、摄影字段或从 `note` 提取起始状态，避免过期站位或复核文字覆盖当前切点。
- 每段创建 `站位与拍摄说明` 文本节点，保存完整站位、逐镜拍摄、动作和承接原文。导入预演只保存已有安排，不代表已验证空间几何，也不静默改写上游冲突。
- 提供预演交付的段落另建 `预演宫格提示词` 文本节点和可点击的 `预演宫格生图` 配置节点。原始宫格提示词逐字保留；纯文字交付不自动连接场景、角色或色卡图片。仅将 `panel.reference` 明确指定的图片嵌入并连接到对应宫格，同时标明镜号。
- 场景、角色、道具的一致性通过画布连线传递。场景映射必须是 `segment.sceneIndex -> script scene.sceneId -> art scene.id`，不得用数组位置猜测。
- art.json 带 `palette` 时创建全局色卡节点并连到每个关键帧组合节点；组合提示词通过 `@` 引用色卡图片，不追加色卡文案。没有 `palette` 就不建这个节点。
- 每个分段同时创建 H3 与豆包 Seedance 的原文提示词文本和视频组合节点。视频组合节点使用原生 `config` 类型，设置视频生成模式、本段时长、分镜正式画幅与多图参考模式，`composerContent` 保存完整提示词；生成后另建视频结果节点，每个视频组合节点右侧留出结果的位置。关键帧及两类视频统一遵守 `storyboard.aspectRatio`（`16:9` 或 `9:16`）；场景设定图与宫格说明页保持各自画幅。
- 每段附上 `关键帧操作说明` 和 `视频操作说明`，逐镜列明图片编号与正文引用顺序。两类视频最终使用同一批选定的关键帧结果图片；导出时结果尚未生成，不创建空图片占位或引用生图配置节点。图片生成后，连接到视频组合节点并在正文中通过 `@` 引用。
- `blocking` 进入站位说明和豆包提示词的 `【人物关系与构图逻辑】`；逐镜 `shot`、摄影、局部光影、音效及段级音景、配乐进入 Seedance。完整 `note` 仅留在说明节点，不作为生图或视频动作指令。H3 提示词逐字保留上游原文，不根据 `shot` 自动重写。预演安排只补充正式分镜的空缺；非空内容冲突时先同步上游。
- 每个角色创建一张正面全身主参考与 8 张独立多视角/局部锚点节点。人物图不做拼接大图；提供 `--character-images` 时，主参考和匹配的独立视图直接嵌入对应节点，缺少的视图保留为待生成节点。完整角色设定图另建 `角色设定图` 节点并连到主参考，不直接连到关键帧；关键帧组合节点始终连接角色主参考，导出器根据切镜的景别、构图、焦点和画面描述，额外连接并引用匹配的正面、侧面、背面或服装局部视图。使用 `--character-sheets-only` 时跳过主参考与独立视图，关键帧直接连接人物设定图。
- 手机等独立道具保持在道具节点中；角色主参考不会把英文 `phone`、`smartphone`、`mobile` 或 `black rectangular slab` 识别锚点带入画面。

导入画布后，在视频组合节点中选择对应模型或通道：`H3 视频` 使用 H3 通道，`豆包 Seedance 视频` 使用豆包通道。

## 关键帧生成与修改

1. 先生成或上传场景、角色、道具及色卡参考图片，再打开关键帧组合节点的「组装提示词」。添加、移除或更换参考图时，同步调整正文中的 `@` 引用；替换同一图片节点的内容时，原有引用继续指向该节点。
2. 点击组合节点的「开始生成」。结果另存为图片节点，原有组合提示词和参考图连接继续保留。需要调整时，在组合节点中将修改融入对应原句，替换过期状态、合并重复说明，再次生成可比较的新结果；基于已有结果修改时，将该结果连接到组合节点并在正文中引用，集中说明本次调整。
3. 每镜选定一张结果，按 `关键帧操作说明` 的顺序连接到本段 H3 与豆包 Seedance 视频组合节点，再按下面的视频流程设置正文引用。更换结果时同步移除旧连线并替换原引用位置的图片。

图片结果工具栏的「重新生成」会复用该结果保存的提示词和参考图。调整组合节点的参考图后，应在组合节点点击「开始生成」。既有画布不会随技能更新自动转换；需要重新导出并导入新包。

需要从宫格细化关键帧时，先生成并确认宫格，再将每镜电影画面单独裁剪，连接到对应关键帧组合节点并在正文中引用，作为构图参考。人物设定负责身份、脸部和服装，裁图负责位置、透视和遮挡；需要替换临时人物时明确写出替换要求。参考职责在本次输入中说明一次，围绕本镜主体与切点状态保留必要例外，不再逐项重复整幅构图。整张带标注宫格不直接连接到关键帧或视频。当前导出器不自动裁图或判定人物一致性。

整理提示词时保留实际参考图的 `@` 绑定与编号对应，清除其他镜头的模板内容；制作依据和待核实项留在说明节点。每个独立生成节点仍须携带必要画面事实与参考，不依赖其他节点或此前生成的记忆。导出器继续保存最终 `frame` 原文；需要压缩或修正该原文时先同步正式分镜，不在导出阶段自动截断或删句。

## 视频生成与修改

1. 把每镜选定的关键帧结果连接到本段两个视频组合节点。在「组装提示词」正文最前面按镜号依次插入 `@` 图片引用，并注明 `Picture 1 / 图片1` 等编号与实际关键帧的对应关系。画布按引用首次出现的顺序编号，连线顺序不能代替正文引用顺序。
2. 确认正文引用覆盖全部关键帧，选择正确的视频模型或通道，再点击组合节点的「开始生成」。H3 原文中的 `<Picture N>`、Seedance 原文中的图片编号，应与提交的图片顺序一致。只连接图片但不插入正文引用时，视频组合节点不会提交这些参考图。
3. 需要更换某镜参考图时，移除旧连线，并在正文原引用的位置选择新图片。新增辅助参考图放在所有关键帧引用之后，保持原有镜号编号不变；修改提示词或参考后继续在视频组合节点生成，新结果另存为视频节点，旧结果保留。

导出时视频组合提示词保存原文，未来图片结果的节点 ID 尚不存在，因此正文没有预填图片 `@` 引用。需要先生成图片再完成这一步，不把关键帧生图组合节点直接连接到视频组合节点。

## 验证

```bash
node {baseDir}/scripts/export-infinite-canvas.mjs validate \
  --zip <输出目录>/<剧名>-分镜画布.zip \
  --storyboard <剧名>-storyboard.json
```

验证面向刚导出的投产包：检查关键帧组合节点的最终画面原文、正式画幅、生图配置、参考图连线及正文引用，逐镜操作说明，以及站位说明、宫格原始提示词、预演参考连线和嵌入图片路径。视频部分检查组合节点类型、视频模式、时长、画幅、多图参考模式、完整提示词与操作说明，并使用归档剧本和全局约束重新核对 Seedance 提示词。新包的视频入口应等待选定图片结果；生成、修改和连接结果后的画布不属于这项导出验证的范围。

新包采用导出规则第 4 版，默认读取 ZIP 内归档的源数据；提供 `--storyboard` 时还会与当前分镜对账。第 1–3 版包继续按原版本验证，包括曾追加空间背景与承接备注的旧提示词；没有空间交接索引的旧包仍按 `cut.frame` 规则验证。既有包不会自动转换，使用最终分镜重新导出才能采用新规则。

修改脚本后运行自包含回归测试：`node --test {baseDir}/scripts/export-infinite-canvas.test.mjs`。
