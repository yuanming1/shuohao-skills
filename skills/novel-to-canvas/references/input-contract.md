# 最终分镜与资产交接

本约定整理自本仓库的分镜结构、空间安排、表现增强、动作修订及角色/剧本/美术数据合同。运行时只读取项目文件与本目录脚本，不导入其他技能代码，也不要求安装前置技能。

## 输入选择

`--storyboard` 指向本次确认的完整最终分镜副本，层级保持 `episodes[] → segments[] → cuts[]`。空间安排、表现增强和动作修订都更新既有字段，不能通过文件名猜测哪份最新，也不能拿对比报告替代分镜。没有执行可选修订时，直接使用已经确认的初稿。

`plan.json` 是空间工作的编排材料，`staging.json` 是开场站位依据，增强及动作对比报告用于人工复核。这些内容应先同步到正式分镜；导出器不接收它们作为新的生成指令。输入未知字段原样归档，不自动翻译成提示词。

| 正式数据 | 画布消费方式 |
| --- | --- |
| `cut.frame` | 关键帧组合提示词的原文主体，仅追加实际资产节点的引用与职责 |
| `cut.shot` | Seedance 的逐镜画面动作；空间与表演锚点应已经写在其中 |
| `cut.note` | 站位与拍摄说明保存完整复核原文，包含起始、动作、结束、接镜及增强依据；不进入生成正文 |
| `segment.blocking` | 说明节点与 Seedance 段级开场空间，不能覆盖后续镜头的当前状态 |
| 摄影字段与 `cut.lighting/sfx` | Seedance 对应镜头的摄影、局部受光与动作声 |
| `segment.soundscape/music` | Seedance 段级音景与配乐 |
| `segment.h3Prompt` | 两个 H3 节点逐字保存；保持原来的中文或英文协议、切点、图片和台词 |
| `cut.beats` 与剧本 `scene.flow` | 台词按该镜认领节拍逐字提取，`VO` 保持画外音标记 |

分镜只修改 `shot` 不会自动修复 H3；导出通过不证明两份动作语义一致。已有关键帧、宫格及视频不会随 JSON 自动更新，应在上游明确重出范围。

## 画幅与镜头词表

正式 `aspectRatio` 只接受 `16:9` 或 `9:16`，同时控制关键帧与两类视频。省略时依次兼容旧 `_meta.orientation`、各 `frame` 末尾画幅标签的多数结果，最后默认 `16:9`。显式非法画幅会报错，不静默回退。场景及道具设定图、色卡和宫格说明页保持 16:9，人物视图保持各自比例。

景别接受 `extreme-wide`、`wide`、`medium`、`close`、`extreme-close`，兼容旧 `extreme_close`。Seedance 摄影映射覆盖分镜现有的 20 个 H3 运镜词，包括环绕、横移、升降、变焦、晃动、主观视角及旋转；不要求改写上游枚举。

## 角色与资产绑定

分镜和剧本的 `C01` 等编号来自大纲，角色卡通常只有姓名与别名。提供 `--outline` 后，导出器先精确匹配大纲姓名与角色卡 `name`，没有精确匹配时再检查 `aliases`；必须唯一匹配，且同一卡不能对应多个大纲编号。角色卡已有 `id` 时沿用它，并核对大纲映射有无冲突。没有可靠映射时停止，不通过角色卡顺序补编号。大纲文件随包归档，角色卡输入不被改写。

场景继续按 `sceneIndex → 剧本场次.sceneId → 美术场景.id` 连接，光照按剧本状态名选择，缺省使用该场景设定图。`art.props` 可以省略，`palette` 也是可选块。道具按 `P` 编号连接，角色主参考与适用局部视图按当前切镜的角色编号连接；`characters: []` 表示空镜，不借用整场人物。

图片目录会递归读取。场景光照先匹配 `<场景名>-L<序号>-<状态>`，再匹配 `<场景编号>-<两位序号>-<状态>`；道具状态同理。人物图片通过 `--character-images` 指定，主参考使用 `<角色名>-正面全身`，独立视图使用 `<角色名>-<视图名>`，主参考缺失时才回退 `<角色名>-sheet`。完整 `<角色名>-sheet` 另建角色设定图节点并连到主参考，不直接连关键帧。使用 `--character-sheets-only` 时不创建主参考与独立视图，关键帧直接连接角色设定图。缺少具体光照或状态图时，关键帧直接连接对应设定图，不连接空节点。

有预演交付时，继续读取 [预演导入](previz-import.md)，核对它与最终分镜是否同版。正式生成不需要对比报告、旧分镜或外部技能安装目录。
