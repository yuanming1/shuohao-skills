# 大招系统资料索引

> 目的：让修仙玄幻大招 skill 在资料扩展后，仍能优先按索引定位属性文件，而不是每次全文扫描。
> 当前版本：v1

---

## 0. 推荐读取顺序

```text
1. 先看本索引文件
2. 根据用户的属性选择定位属性专项
3. 在属性专项中读取细分类、招式池、反馈方式、结局模板
4. 最后回到 ../SKILL.md 组合正式输出
```

## 3. 输入字段对照

| 字段 | 含义 | 说明 |
|---|---|---|
| 攻击人员 | 释放大招的人 | 不做复杂人物绑定 |
| 被击人员 | 承受或对抗大招的人 | 必须有反馈 |
| 场景 | 战斗发生地 | 可选或自定义 |
| 风格 | 画面与镜头风格 | 成品中单独输出，不再默认并入特殊要求 |
| 技能属性 | 火 / 雷 / 冰 / 剑仙飞剑 / 风 / 土岩 / 水 / 暗魔 / 光神圣 | 第一层选择 |
| 属性细分 | 大属性下的小流派 | 第二层选择 |
| 中段招式 | 控场、压制、破防、铺垫招式 | 第三层选择，可选 1-3 个 |
| 后段大招 | 最终终结、处刑、镇压招式 | 第四层选择，通常选 1 个 |
| 战斗节奏 | 主要描述被击方状态 | 压制、闪避、格挡、破防等 |
| 结局 | 终结结果 | 轰杀、贯穿、冰封、镇压等 |
| 特殊要求 | 额外偏好 | 风格、镜头、尺度、环境反馈等 |

## 4. 输出约束

每次正式成品，默认输出两条：

1. `大招提示词一`：标准完整版
2. `大招提示词二`：强化升级版

两条提示词共享同一输入，但必须在以下至少两项上拉开差异：

- 起势方式
- 异象规模
- 技能主体形态
- 被击反馈层级
- 终结画面的凶狠度
- 镜头路径

正式成品固定结构：

- 人物
- 场景
- 风格
- 分镜
- 细节强化
- 负面提示词约束

分镜硬规则：

- 任意单个分镜时长不得超过4秒
- 分镜必须按“时间 → 分镜内容总结 → 景别 → 分镜内容”的顺序写

生成加严规则：

- 可参考 `大招模版参考.md` 的结构密度，但不得机械复写
- 用户要求国漫级时，优先补读 `国漫级大招设计语言库.md`
- 同一模板下必须至少变化起势、异象、主体形态、清场方式、终结方式中的三项以上

## 5. 首批维护原则

1. 新增属性时，先在本索引登记，再建专项文件。
2. 新增招式时，优先放入对应属性专项文件，不要直接堆到 `../SKILL.md`。
3. `../SKILL.md` 只保留主规则和组合逻辑，不承载完整招式池。
