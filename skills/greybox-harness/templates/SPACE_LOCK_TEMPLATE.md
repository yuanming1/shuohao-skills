# 空间锁骨架

一个场景要拆成好几条生成时用。**这份文件是这些条之间保持同一个空间的唯一保证。**

用法:下面每一块**逐字复制**进每一条 prompt，不改写、不缩写、不「用自己的话再说一遍」。
一改写，两条之间就开始漂。

---

## 一、这一场的资产表

| 条 | 时长 | 白模(送模) | 图片槽位(顺序 = @图片1/2/3…) |
|---|---|---|---|
| S1 … | 16s | `xxx_送模.mp4` | ①定妆板 ②店外空镜 ③店内空镜 ④物件 ⑤礼袋 |
| S2 … | 8s | … | … |

**没有资产图、只能靠文字的**:〔逐条列出来。这是最容易在出片后才发现的坑。〕
**已停用的图**:〔为什么停用，一句话。别让人再挂回去。〕
**音色**:〔谁有音色参考，谁没有。有台词却没有音色参考的角色要点名。〕

## 二、〔容易混的两样东西〕辨析块 —— 逐字复制

```
【画面里有两个〔什么〕,是两样东西，不许混、不许换、不许合并】
**A**:〔物理特征逐条〕。**它全程在〔哪里〕,永远不进〔哪里〕。**
**B**:〔物理特征逐条〕。
两者**从不同时出现在同一只手上**;〔各自在本场的活动范围〕。
```

## 三、服化道 —— 逐字复制

```
〔逐项写到能被否定的粒度。〕
从第 0 秒到最后一帧不增减、不换装、不换发型、不改妆。
```

## 四、画质与质感 —— 逐字复制(放在参考图分工之后)

```
【画质与质感 · 最高优先级 · 先满足这一条】
〔见 PROMPT_TEMPLATE.md〕
```

## 五、品牌字样 / 文字底线 —— 逐字复制到每条的硬约束

```
**参考图上的所有品牌字样一律不要生成。** 〔逐个点名哪张图的哪个位置有字〕——
全部留成**无字的空白压印区或空白标签**,形状、位置、深浅照做，**字不要**。
同样不出现任何店招、价签、界面文字、楼层数字、中文、英文、数字、乱码、假字。
```

> 光靠这段挡不住参考图里已经有的字。有效的办法是**把那块区域从参考图里裁掉**。
> 这段只是兜底。

## 六、方向锁

```
本场全场 **左→右**〔或别的方向〕。
所有机位都正对〔哪面墙〕(视线沿画面纵深方向),`+X` 在画面上就是右。
**任何一条都不许出现反向行进、不许越轴。**
〔道具〕**全程在〔哪只手〕、〔哪一面〕朝外**,从〔哪一镜〕建立，贯穿〔到哪一镜〕。
```

> 方向是**机位轴向**定的，不是人物走向定的。机位一斜，
> 沿纵深更远的东西会绕到画面另一边去。摆完用 `project.report()` 核 x 的正负号。
