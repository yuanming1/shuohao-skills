# Prompt 骨架

复制下面 ``` 里的内容到一个 `.txt`,从上往下填。
`〔…〕` 是给你看的说明，填完删掉。写完跑:

```bash
python3 tools/check_prompt.py your_prompt.txt your_scene.py
```

规范和每一节的写法见 [`../docs/03-prompt-spec.md`](../docs/03-prompt-spec.md)。

---

```
【最先满足这 N 条 · 其余全部让位】
〔最多 6 条。选进来的标准:这条崩了整段素材就废。每条都要给出可被否定的判据。〕
一、**X 个镜头、X 次硬切，严格按 @视频1 的机位与切点走。每一段都是固定机位**——不推进、不拉远、不横摇、不升降、不跟拍、不环绕、不变焦。〔哪一段过程不拍，写在这里〕
二、〔时序锁:某个道具在第几秒之前不许动，触发条件是什么，只发生几次〕
三、〔辨析锁:画面里有两个容易混的东西，它们是两样〕
四、〔文字底线〕**全片不出现任何可读的文字、数字或界面。**
五、**成片是实拍电影素材，不是 CG、不是 3D 渲染。画面里不许出现任何灰色几何体、圆柱、方块、色块人形、描边或白模感。**

【参考素材分工 · 三层，不许互相越界】
@视频1 是**白模(灰模预演)**:画面里只有灰色的体块和抽象人形，**它不是画面内容，而是这个空间的平面图纸和机位表**。
　**只从它身上取四样:①物件的位置与左右关系　②每一段的机位、景别与角度　③每一次硬切发生的时刻　④每个人站在哪、面朝哪、手放在什么上面。**
　**它的造型、材质、光影、颜色一律不要参考。** 白模里所有东西都是没有造型的方块，那是占位不是设计;白模的光是无方向的平光，那是图纸不是效果图。
　白模里**橙色的人形是〔主角〕**,**蓝色的人形是〔配角〕**,**红色的方块是这一镜要拍的那件东西**〔逐个点名〕。
　**白模和空镜冲突时:位置与朝向听白模的，长相与光听空镜的。**〔一张图只管一段时间的话，写清管哪一段〕
@图片2 是〔空间〕的**实拍空镜**(画面里没有人):**造型、材质、颜色与光线全部以它为准**,不要复制它的机位。
@图片3 是〔物件〕的**实物图**:轮廓、颜色、材质、五金位置以它为准。**只取物件本身，不要背景、不要图上的字。**
@图片1 是〔角色〕的**定妆板**:**只用来锁脸、发型与服化道**,不要复制背景、姿势或排版。

【画质与质感 · 最高优先级 · 先满足这一条】
〔必须在这个位置。往后挪权重就被稀释。每一条写成「它是什么 + 它不是什么」。〕
**这是实拍电影素材的质感，不是 CG、不是 3D 渲染、不是游戏引擎画面、不是广告片。**
- **皮肤**:哑光，有真实的毛孔、细纹、面部汗毛与轻微不均匀的肤色;鼻翼、额头有自然皮脂微反光，但不是油光、不是高光块。**严禁磨皮、美颜、塑料感、蜡像感。**
- **头发**:能看出单根发丝层次与飞散碎发，不是一整块色团。
- **织物**:〔逐种写〕
- 〔本条出现的每一种关键材质各写一条〕
- 画面保留极轻微的胶片颗粒，焦外是柔和的光学虚化。
**严禁过度锐化、HDR 感、油画感、统一镜面高光、广告式高光。**

【〔A〕和〔B〕是两样东西，不许混、不许换、不许合并】
〔只在有歧义时写。列出区分它们的物理特征，写死不许互相变形。没歧义就删掉这一节。〕

【〔角色〕的服化道 · 以 @图片1 为准，逐项照做】
〔逐项写到能被否定的粒度。「白衬衫」不够，要「白色宽松长袖衬衫，大翻领、袖口挽起、圆下摆过臀」。〕
从第 0 秒到最后一帧不增减、不换装、不换发型、不改妆。

【〔配角〕· 没有定妆板，按这里生成】
〔从零描述。顺便写死不要什么:没有工牌、没有胸针、没有任何带字的挂牌。〕

【这个空间实际长什么样 · 位置听白模，长相听这里和 @图片2】
〔逐条写死:墙/天花/地面各是什么材质、家具的尺寸与摆法、台面上有哪几样东西。
  每一句都要能被否定。空镜盖不到的东西，明确写「它不在空镜里，位置以白模为准，材质按空镜」。〕

【光】
〔主光从哪来、什么光质、色温、冷暖在哪交汇。〕
**白模是无方向的平光，那只是图纸，光完全按这里和 @图片2 来。** 整体低饱和写实，亮部不过曝，暗部保留细节不死黑。

【身份锁定】全片恰好 N 个清晰人物:〔点名〕,身份固定、不互换、不融合，**X 秒里不出现第 N+1 张清晰人脸**。
maintain face identity strictly from @图片1;**no identity drift, no face morphing between shots, no aging, no hairstyle change across the whole X seconds**。

【本条的表演弧线 · 〔一句话概括基调〕】
〔按时间段写情绪的走向，不是动作清单。每段配一句「不是什么」。〕
**0.0–X.X 秒**:……
全片**禁止**:〔一串具体的表演动作 —— 模型对短剧的默认想象是夸张的，不写就会捂嘴、握拳、雀跃〕

【内容合规】原创普通人，非名人、非影视角色，着装保守得体，无品牌 LOGO、无版权图案、无可读文字，健康正向的〔什么〕情境。

【本条剧本 · 〔镜号范围〕　成片 X.X 秒】
画幅 16:9,24fps,〔风格〕,全片平视，**不越轴**。
**X 个镜头，硬切串联。以下每一段的机位都对应 @视频1 的同一时刻。**
〔时间码从场景文件的 SHOTS 表抄，不要手打。格式:全角空格 + 起–止 + 全角空格。
  「硬切」的次数必须等于镜头数 − 1。最后一段结尾写死「不要在结尾再切一刀」。〕

**〔一 · 小标题〕**
　0.0–X.X　**〔景别与角度〕**:〔谁在画面哪一侧，背景是什么〕。〔动作〕。**硬切。**

【声音／台词／旁白】
〔环境声、动作音效。〕

**全片台词只有这些，逐字保留，不删、不改、不合并、不换同义词、不新增语气词:**
〔角色〕:**"……"**
〔没有台词的角色要明说没有，否则模型会自己加。〕
**全片无旁白、无音乐、无鼓点。**

【转场或后期说明】
〔硬切靠什么做声桥;哪些内容留给后期叠加;参考图上的品牌字怎么处理。〕

【负面约束】
**结构类**:……
**白模类**:**禁止成片里出现任何灰色几何体、圆柱、方块、色块人形、描边、线框或 3D 预演感。禁止把家具做成方盒子。禁止照抄白模的平光。**
**空间类**:……
**道具类**:……
**表演类**:……
**文字类**:**禁止画面出现任何可读的中文、英文、数字、乱码、假字、伪字符、品牌字样;禁止任何形式的字幕、水印或 Logo。**
**画质类**:禁止塑料皮肤、磨皮、蜡像感、CG 渲染感、过度锐化、HDR 感;禁止人物脸部漂移、变形、变老或换发型。
```
