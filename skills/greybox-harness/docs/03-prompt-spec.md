# Prompt 规范

白模管**位置和时间**,prompt 管**其余全部**。这份规范定的是「其余全部」怎么组织。

空白骨架在 [`../templates/PROMPT_TEMPLATE.md`](../templates/PROMPT_TEMPLATE.md),
写完用 `tools/check_prompt.py` 对着场景文件自检。

---

## 章节顺序(不许换)

```
1  【最先满足这 N 条 · 其余全部让位】     ← 硬约束，最多 6 条
2  【参考素材分工 · 三层，不许互相越界】
3  【画质与质感 · 最高优先级】            ← 必须在这个位置
4  【道具/角色的辨析块】(有歧义才写)
5  【某某的服化道 · 以 @图片N 为准】
6  【没有定妆板的角色 · 按这里生成】
7  【这个空间实际长什么样】
8  【光】
9  【身份锁定】
10 【本条的表演弧线】
11 【内容合规】
12 【本条剧本 · 分镜】                    ← 时间码从场景文件抄
13 【声音／台词／旁白】
14 【转场或后期说明】
15 【负面约束】                          ← 按类分组
```

**为什么【画质与质感】必须排第 3。** 实测:prompt 从 3870 字涨到 4617 字时，
质感段被挤到中后段，权重被稀释，皮肤直接塑料化。它要紧跟在参考图分工之后、空间描述之前。

---

## 逐节怎么写

### 1. 硬约束

**最多 6 条。** 这是「如果只能守住几件事，守哪几件」的清单，多了就不是硬约束了。

选进来的标准:**这条崩了整段素材就废**。典型的四类:

- 结构:几个镜头、几次硬切、哪些运镜、哪一段过程不拍
- 时序:某个道具在第几秒之前不许动
- 辨析:画面里有两个容易混的东西，它们是两样
- 底线:不出现文字 / 不出现白模感

写法上要给出**可被否定的判据**。「保持空间一致」不是硬约束，
「3.2 秒推门那一刀之后，5.0 秒她已经站在柜台外侧，中间的路不拍」才是。

### 2. 参考素材分工

三层，各管各的，明确写出**冲突时听谁的**:

```
@视频1 是白模(灰模预演):画面里只有灰色的体块和抽象人形，
  它不是画面内容，而是这个空间的平面图纸和机位表。
  只取四样:①物件的位置与左右关系 ②每一段的机位、景别与角度
          ③每一次硬切发生的时刻 ④每个人站在哪、面朝哪、手放在什么上面。
  它的造型、材质、光影、颜色一律不要参考。
  白模里橙色的人形是主角，蓝色的人形是配角，红色的方块是这一镜要拍的那件东西。
  白模和空镜冲突时:位置与朝向听白模的，长相与光听空镜的。
禁止成片里出现任何灰色几何体、胶囊、方块、色块人形、描边、白模感。
```

一条参考图管一段时间的话，**写清管哪一段**:「@图片2 只管 0.0–5.0 秒这两镜」。

定妆板要写「**只用来锁脸、发型与服化道，不要复制背景、姿势或排版**」——
不写这句，模型会把定妆板的白背景和站姿一起搬过来。

### 3. 画质与质感

按材质分条列。每一条的模式是「**它是什么** + **它不是什么**」:

> 麂皮是短绒的——有绒毛倒伏方向、有手抚过的深浅痕、边角有轻微磨色，
> **不是光面皮、不是塑料、不是漆皮**。

只写「质感真实」等于没写。

### 4. 辨析块

画面里有两个容易混的东西时(两只同色的包、两台一样的电脑、两个同龄配角)，
单开一块，把**区分它们的物理特征**逐条列出来，并写死「不许互相变形、不许换手、不许合并」。

### 5–6. 服化道

有定妆板的:逐项照做，**写到能被否定的粒度**。
「白衬衫」不够 —— 要「白色宽松长袖衬衫，大翻领、袖口挽起、圆下摆过臀」。

没有定妆板的角色:在这里从零生成，同样写到可否定。顺便写死不要什么
(「没有工牌、没有胸针、没有任何带字的挂牌」)。

### 7. 空间

**位置听白模，长相听这里和空镜。** 空镜盖不到的部分(比如空镜里没有的那张柜台)，
明确写「它不在空镜里，位置以白模为准，材质按空镜」。

这一段最容易写成散文。判据还是那个:**每一句都要能被否定**。

### 8. 光

主光从哪来、什么光质、色温、冷暖在哪交汇。结尾固定加一句:
**「白模是无方向的平光，那只是图纸，光完全按这里和空镜来。」**

### 9. 身份锁定

人数写死、不出现第 N 张清晰人脸、服装从第 0 秒到最后一帧不变。
加一句英文 —— 实测对身份漂移有帮助:

```
maintain face identity strictly from @图片1;
no identity drift, no face morphing between shots, no aging,
no hairstyle change across the whole N seconds
```

### 10. 表演弧线

按时间段写**情绪的走向**,不是动作清单(动作在分镜里)。
每一段都配一句「不是什么」:「这个停顿是『这钱不小』，不是『我买不起』」。

段末列一串**禁止的表演**——模型对短剧的默认想象是夸张的，不写就会捂嘴、握拳、雀跃。

### 12. 分镜

**时间码从场景文件的 SHOTS 表抄，不要手打。**

格式:

```
　0.0–3.2　**平视橱窗中景**:(空间描述,谁在画面哪一侧)。(动作)。**硬切。**
```

- 每一段开头是全角空格 + 起止秒 + 全角空格 —— `check_prompt.py` 靠这个识别
- 「硬切」只写在真正换镜的地方，**次数必须等于镜头数 − 1**
- 同一个镜头里的几个分拍要写明「同一机位」,否则模型会当成新镜头切一刀
- 最后一段结尾写死「**本条到此结束，不要在结尾再切一刀**」

### 13. 声音／台词

台词**逐字保留**,并显式写「不删、不改、不合并、不换同义词、不新增语气词」。

**语速上限约 5 字/秒。** 实测 5.8 字/秒有三段物理上念不完，模型会自己加速或吞字。
`check_prompt.py` 会按分镜段时长算这个。

没有台词的角色要**明说没有**:「主角全片没有任何台词、没有旁白、没有心声。
她不说『谢谢』、不说『好』、不发出任何语气词。」不写的话模型会自己加。

> **心声/内心独白会被打成字幕。** 要在硬约束里写死「只有声音、没有字」,
> 埋在负面约束末尾不管用。

### 15. 负面约束

**按类分组**,不要堆成一段:结构类 / 白模类 / 空间类 / 道具类 / 表演类 / 文字类 / 画质类。

分组的作用是让你在写的时候能自查「这一类我漏了吗」。

## 长度

| 字数 | 状态 |
|---|---|
| < 5000 | 舒服 |
| 5000–7000 | 实测可用 |
| 7000–8000 | 靠前的章节开始被稀释，能拆就拆 |
| > 8000 | `check_prompt.py` 会警告 |

拆条的切法:**在白模的某一刀上拆**,两条各自带完整的空间锁和质感段。

---

## 三个反复出现的教训

**禁令挡不住参考图里已经存在的东西。** 参考图上有品牌字，
你在 prompt 里写十遍「不要出现文字」,它还是会出现。有效的办法是**物理回避**——
把那块区域从参考图里裁掉，或者在白模里把屏幕转开 25 度让任何机位都拍不到正面。

**长镜头会自己长出切点。** 一镜超过 6 秒，模型倾向于自己加一刀。
要么把这一镜拆短，要么在硬约束里点名「这一段是一个连续镜头，中间不许切」。

**「不要 X」不如「要 Y」。** 「不要让她面向镜头」不如「她面朝画面左前方的橱窗」。
凡是能写成正向指令的，都别写成禁令 —— 禁令留给负面约束段兜底。

# 出门前的两道检查

写完的 prompt 有两种死法,人眼都很难抓:**写得不够密**,和**三层互相打架**。
这两件事应该由工具查,不该靠通读。

```bash
blender -b --python scene.py -- export facts.json          # 先把白模事实导出来
python3 tools/check_prompt.py prompt.txt scene.py --facts facts.json
```

## 一、颗粒度够不够密

### 判据:每一句都要**能被否定**

这是唯一的标准。「墙面质感高级」没法判断对错,所以模型爱怎么画怎么画;
「墙是蓝灰色的竖向褶皱织物帷幕,不是刷漆墙、不是木饰面」可以被指着说「你画错了」。

工具查这几项:

| 查什么 | 怎么判 | 为什么 |
|---|---|---|
| 每一镜有没有**景别** | 分镜行里有没有 特写/近景/中景/全景/过肩… | 没有的话模型自己定,同一场戏景别会乱跳 |
| 每一镜有没有**画面方位** | 有没有 画面左/画面右/前景/后景… | 这是白模已经算好的东西,不抄进 prompt 等于白建 |
| 每一镜的**信息量** | 中文实字 < 40 就报 | 一句话带过的镜头,出来一定不是你想的那样 |
| **不可证伪的形容词** | 高级/精致/氛围感/大片感/唯美… 命中就警告 | 写了等于没写。`「」` 引号里的反例会自动跳过 |
| **负面约束的类别覆盖** | 结构/白模/空间/道具/表演/文字/画质 七类缺哪类 | 分组不是为了好看,是为了让你写的时候自查漏了哪一类 |
| **服化道条目数** | 少于 6 项警告 | 锁一个人通常需要:上衣、下装、鞋、配饰、发型、随身物 |
| **自相矛盾** | 声明了「固定机位」,分镜里又写「横移/推进/跟」 | 我自己犯过:硬约束写死不许运镜,分镜里又要了一次短横移 |

### 工具查不了、只能自己过的

- **每一镜的结束状态写了没有。** 「末帧停在什么状态上」决定了下一镜能不能接。
- **动作有没有触发条件。** 「店员把袋子推过来」不够,要写「**确认付款成功之后**才推」。
- **禁止清单是不是这一条真会犯的错。** 抄一份通用禁令没用,要针对这一条的具体风险。

## 二、三层有没有打架

三层是 **白模 / prompt / 资产图**。它们各管一摊,但边界处极容易互相矛盾,
而且**矛盾的时候模型不会报错,它只会挑一个听**。

### 工具能对账的

**白模 ↔ prompt 的景别。** 这是最有价值的一条,因为人眼对不了。
`-- export` 把每一镜里每个元素的画面坐标、占宽、占高导成 JSON,
`check_prompt.py` 拿主体人物的**占高**反推景别:

```
人整个装进画面 ≤115%  → 全景
115% ~ 260%          → 中景
260% ~ 500%          → 近景
> 500%               → 特写
```

分镜写的景别和算出来的差**两档以上**就报错,差一档提醒。
道具占宽超过 18% 的镜头判定为插镜,跳过人体核对(主体是道具不是人)。

> 这个阶梯是按**人在画幅里的高度**定的。第一版我拿「画面里最大的元素」去算,
> 结果门洞占高 220% 被判成「特写」,整列全是假警报。**景别只能按人算。**

它同时会把**白模事实**打印在每一镜旁边:

```
✓ S1 景别「中景」与白模一致(LEAD(窗) 占高 173%)
     白模事实 S1: 入口门洞→画面右 / LEAD(窗)→画面右 / 橱窗洞口→画面中
```

分镜里写「她在画面左侧」而白模事实说「→画面右」,一眼就看出来了。

**prompt ↔ 资产图的边界声明。** 每一个 `@图片N` 都必须写清楚**只取什么、不取什么**。
不写的话,定妆板的白背景和站姿会被一起搬进成片。工具会逐个槽位查这句话在不在。

**冲突规则在不在。** 三层打架时模型听谁的,必须在 prompt 里写死:

> 位置与朝向听白模的 · 长相与光听资产图的 · 其余听 prompt 的

### 工具对不了、必须人看的三类

**1. 资产图和剧本设定打架。**
剧本写「商场里的店铺」,而空镜是「街边旗舰店夜景」—— 这种矛盾工具看不出来,
但它会让下一条(出门走进商场通道)接不上。**拉完资产图第一件事是逐张对剧本的场景描述。**

**2. prompt 描述的材质和空镜不是一回事。**
prompt 写「米白色墙面 + 浅木陈列面」,空镜里是「蓝灰色竖向褶皱织物帷幕」。
模型会各取一半,出来一个四不像。**空镜盖得到的部分,prompt 就不要再描述一遍**,
只写空镜盖不到的(比如空镜里没有的那张柜台)。

**3. 资产图身上的字。**
这是最隐蔽的一层冲突:prompt 里写死「不出现任何文字」,而资产图上有品牌压印。
**禁令挡不住图里已经有的东西。** 实测:纸袋下半部那片重复字母压印,
被模型当成了「这个品牌的墙面纹理」,在店内墙上生成了一整排乱码。
处理办法是**把那块区域从资产图里裁掉**,不是加一条禁令。

## 三、示例的自检输出

`examples/boutique` 跑出来是这样,可以拿它当基准:

```
── 结构 ──        章节齐全、7 段对 7 镜、硬切 6 次、语速 2.5 字/秒、槽位连号
── 颗粒度 ──      七镜全部有景别+方位+动作、无不可证伪形容词、负面约束七类齐全
── 三层一致 ──    冲突规则在、五个槽位都声明了取舍边界、景别与白模逐镜对上
→ 0 项不通过，2 项提醒
```

**提醒可以留着,不通过必须清零再出片。**
