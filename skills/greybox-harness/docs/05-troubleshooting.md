# 症状 → 诊断 → 修法

按「我第一次遇到时误诊了多久」排序。

---

## 白模渲出来是一片平灰，看不见主体

**别先改机位。** 大概率是几何把主体吃了:

- 主体被放进了一个实心的壁龛/柜体方块里
- 前面挡了一块「玻璃」—— Workbench 里没有透明，玻璃就是一堵墙
- 主体和背景的材质明度太近

查法:`blender -b --python scene.py -- blockers`,再 `project` 看主体的占幅比例。
数字会告诉你它在不在画面里、有多大。

> 我在这上面改了两轮机位才发现是壁龛做成了实心方块。

## 审片静帧里有两个一样的人

`render_stills` 没传 `figs` 和 `shots`。不传的话所有人物组同时渲染。
几何是对的，只是可见性没切。

## `blockers` 每一镜都报「挡住了」

两种情况:

1. **被主体自己触发** —— 这一镜要拍的那件道具当然在视线上。用 `ignore=("手机","礼袋",…)` 排掉。
2. **细长物件的假警报** —— 旧版用外接球半径，一根 0.14m 粗的门柱算出半径 1.7m。
   现在横竖分开量，已修。如果你改过 `project.py`,检查这一点。

## 审片版好好的，送模版糊成一整片惨白

明度撞车了。审片版靠描边和语义配色分层，送模版只有明度 ——
两个用同一份材质的物件在送模版里就是一片。

```bash
blender -b --python scene.py -- audit
```

墙上的凸出物用 `P["RELIEF"]`,家具用 `P["WOOD"]`/`P["DARK"]`,别都用 `P["WALL"]`。
详见铁律 15。

## 成片里出现了灰方块 / 抽象雕塑 / 方盒子家具

白模的占位块被当成家具设计抄走了。两个动作:

1. 白模里**别给小道具造型** —— 它只是位置标记。
2. prompt 的负面约束里点名:「禁止把家具做成方盒子:柜台要有真实的石材体量与边缘倒角」。

## 成片的光是平的 / 窗死白 / 天花发暗

白模的平光被抄走了。prompt 里必须有那句:
**「白模是无方向的平光，那只是图纸，光完全按【光】这一段和空镜来。」**

## 切点对不上

先分清是**没检测到**还是**真没切**:

```bash
python3 tools/verify_cuts.py 成片.mp4 scene.py            # 实拍片，默认阈值 0.28
python3 tools/verify_cuts.py 白模.mp4  scene.py --thr 0.15 # 灰模帧间差小，要降阈值
```

工具会在检测数不足时自动降阈值并提示。**注意方向**:
低阈值用在实拍片上会把摇晃、光变、快速动作全判成切点。

真没切的话，按频率排:

- **某一镜超过 6 秒** → 模型自己在中间加了一刀。拆短，或在硬约束里点名不许切。
- **prompt 里「硬切」的次数不对** → `check_prompt.py` 会查。
- **`--dur` 和白模时长不一致** → 整条时间轴都会错位。

## 道具在成片里提前动了 / 换手了

时序类的约束**必须进硬约束前三条**,埋在负面约束末尾无效。而且要写出**触发条件**:

> 只有在支付提示音响过之后，店员才把它推过柜台中线。这个移动全片只发生一次。

在白模里也要体现:道具在那一镜之前的位置固定不动。

## 插镜拍出来是「灰底上一个红方块」

白模里那一镜只有道具，**没有手**。模型不知道这一镜在演什么动作。

修法:把角色的手摆到道具上(`stand_reach_r` 之类)，
再用 `human.hand(tag, "R")` 读手的实际坐标去放道具。

## 屏幕上出现文字 / 乱码

**禁令无效，要靠物理回避。**

- 屏幕:在白模里把它**转开 25 度**,任何机位都拍不到正面。
- 参考图上的品牌字:**把那块区域从参考图里裁掉**。
  在 prompt 里写十遍「不要出现文字」不管用 —— 图里有，它就会漏。

实测:参考图里那只纸袋下半部有一片重复排列的镂空字母压印，
成片在店内墙面上生成了一整排破碎重复的字母。
**是纸袋上的图案被当成了「这个品牌的墙面纹理」。**

> 我试过直接在参考图上涂掉 logo。目测估坐标偏了八十像素，
> 在包身上糊出几块假五金，比原图更糟。要涂就精确裁剪，别凭感觉 inpaint。

## 人物面向镜头，角色之间的关系不对

人体代理没有朝向。用 `human.mannequin()`(带鼻锥和肩板)，不要用裸圆柱。
朝向公式是 **α + 90**,写成 α − 90 的话人会背对目标，前倾反而把头往后送。

## 坐着的人浮在半空 / 陷进桌子里

`mannequin(..., seat_z=椅面高度)` 没传。只转大腿骨，骨架原点还在地面。

手够不到桌面的话，不是改姿势 —— 是**把椅面抬高**(实测 0.46 → 0.52 解决)。

## 走位看着假,像被拖着平移

用了站姿 `stand` 而不是迈步姿势。换 `walk_r` / `walk_bag_r`,
并且把人和道具一起挂到 `rig.group()` 的手柄上再平移。

## 运镜是「跳」过去的，不是滑过去的

关键帧插值被设成了 CONSTANT。`render_anim` 里现在是 LINEAR ——
布尔属性(`hide_render`)天生 CONSTANT，不吃这个设置，所以人物切换仍然是硬切。

## 通道/门厅拍出来纵深全无

空墙在透视里是一整片灰。在墙上排一列**等间距竖肋**当刻度尺。
参考图里的浮雕墙、瓷砖缝、幕墙波纹本来就有，照抄。

## 审片版有一大块近黑的斜楔

Workbench 的 `shadow_intensity` 太高。空旷房间里 0.35 会投出一整块阴影，看着像凭空多一堵墙。
现在默认 0.22。

## 接触表看起来像逆光剪影

**别给接触表加 autocontrast。** 白模原图反差本来就小(实测人物 171 / 墙 185)，
拉完会变成黑白对立。我因此两次把正常曝光误判成剪影。

## `占宽` 的数字看着不对

`project.report()` 打印的是**占全画幅宽的百分比**。
早期版本误打成一半的值(`w*50` 应为 `w*100`)——如果你 fork 的是旧版，检查这一行。
拿旧数字反推过的焦距会偏保守一倍。

## 资产图从哪来

这套 harness **不管资产图怎么存**。每个团队的做法都不一样 —— 网盘、多维表格、
Git LFS、本地文件夹都行,换个地方不影响这里任何一行代码。

它只关心落到本地之后的两件事:

1. **文件名顺序 = prompt 里的 `@图片N` 顺序。** 建议直接用序号前缀命名
   (`1-人物定妆板.png`、`2-空镜.png`…),避免调用时数错槽位。
2. **每张图都要在 prompt 里声明「只取什么、不取什么」。**
   `check_prompt.py` 会逐个槽位查这句话在不在。

`prompt.txt` 里的 `@图片N` 就是这些槽位。
