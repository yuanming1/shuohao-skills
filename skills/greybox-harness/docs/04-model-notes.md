# 生成模型侧的实测记录

这套管线本身**不绑定任何具体模型**。它只要求生成端有两个通道:

1. **参考视频通道** —— 能吃一段视频，从里面拿构图/运动/时序
2. **参考图通道** —— 能吃若干张图，用来锁长相

下面是我在 **Seedance 2.5** 上的实测数据。换模型的话，这一页要重测，
但**测什么**是通用的:先测边界，再测计费，最后才测效果。

> ⚠ 数据采集于 2026 年 8 月，服务商随时可能改。当成「该测哪些项」的清单，别当成事实。

---

## 硬边界

| 项 | 实测 |
|---|---|
| 参考视频时长 | **必须 2–30 秒**。超了直接 `ret=2` 打回，不扣积分 |
| 输出时长 | 4–180 秒(画布端);但参考视频卡在 30 秒，所以一条实际最长 30 秒 |
| 参考图张数 | ≤ 9 |
| 参考视频条数 | ≤ 3 |
| 音频 | ≤ 3 条，只吃 `.mp3` / `.wav` |
| 1080p | **只有 2.0 系列支持**。2.5 传 1080p → `ret=2 模型参数配置不合法` |

## 计费

- **按秒线性，没有起步价。** 2.5 / 720p ≈ 26 积分每秒。
- **参考视频通道不打折，反而略贵** ≈ 28.2 积分每秒(宣传的折扣在 API 上没生效)。
- **被打回的请求不扣费**;**被接受然后失败的会先扣后退**。

> 探针要用**必然被拒**的值。我用 `duration=9999` 探边界，
> 结果这个值被接受了 → 扣 780 积分 → 任务失败 → 退款。
> 探针的意义就是不该产生副作用，用一个可能被接受的值去试是自相矛盾的。用 `0` 或 `-1`。

## 效果侧

- **参考图不要用成片抽帧**(二代复制)。模型输出本身偏软、微反差被压平;
  把它喂回去当参考，模型会把这套渲染指纹当成目标质感，再往那个方向走一步。
  而且抽帧分辨率通常低于定妆板，会压住整组参考图的上限。
- **多个不同真人脸的参考图放同一条 prompt** → 高概率 face-mixing。
  多人镜头要么只挂一张脸 + 文字描述其他人，要么拆条。
- **内容审核是概率性的。** 纯文生真人对话戏偶发误杀(报版权，实为真人脸)。
  加一段「原创普通人、非名人、着装保守、无品牌 LOGO、健康正向」+ 自动重试即可。
- 出片耗时约 200–500 秒。轮询要留够超时，我按 900 秒还超过一次。

## 换模型时该测什么

按这个顺序，前两组都不花钱或只花很少:

1. **边界**(免费):参考视频时长上下界、分辨率组合、参考图张数上限。用必然被拒的值探。
2. **计费**(1 条最短片):单价、有没有起步价、参考视频通道是否另算。
3. **切点复现**(1 条):用 `examples/boutique` 的白模发一条，
   `verify_cuts.py` 量偏差。**这是这套管线能不能用的判据。**
   偏差 < 0.15 秒且无多余切点 = 可用。
4. **几何污染**(同一条):看成片里有没有灰方块、描边、色块人形。
5. **参考图 vs 参考视频谁优先**:故意让两者冲突(白模把人放左边、参考图里人在右边)，看听谁的。

## 我这边的复现数据

用 `examples/boutique` 同构的一条 16 秒 7 镜白模，实拍风格 prompt，5–6 张资产图:

```
白模应切   成片实切    偏差
   3.2      3.17    0.03s
   5.0      4.96    0.04s
   7.4      7.38    0.02s
   9.2      9.17    0.03s
  11.6     11.54    0.06s
  13.2     13.13    0.07s
多余切点:无
```

**6/6 命中，最大偏差 0.07 秒，零多余切点。** 七个机位逐个复现，无几何污染。

同期的失败面:
- 一条 28 秒、含一个 7.5 秒长镜的片子，**漏 3 个切点、自己加了 4 个** —— 长镜头会自己长出切点。
- 参考图上有品牌字的那两条，**字漏进成片了**,其中一处还是乱码 —— 见 `05-troubleshooting.md`。
