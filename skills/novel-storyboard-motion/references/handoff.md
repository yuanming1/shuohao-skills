# 输入与提示词同步约定

## 输入读取

已有分镜的数据层级为 `episodes[] → segments[] → cuts[]`。每段以 `id` 标识，`sceneIndex` 指向剧本场次；每切的编号由段内顺序确定。
这是输入适配说明，不定义或扩展分镜 schema。原稿里的其他字段、顺序和引用一律保留；不新增动作专属 JSON 字段。
对应剧本或用户说明负责确定动作目的、先后和结果，场景与道具资料只补充已确认的外观、位置和材质。

## 可修订范围

随附对比工具允许修订逐切的 `note`、`frame`、`shot`、`sfx`，以及段级 `h3Prompt`、`soundscape`。
`note`、`sfx` 和 `soundscape` 可以在原来缺失时补充；其他必要正文原来缺失时应作为输入缺口报告。
时长、节拍、镜号、机位、景别、人物和道具引用、段级开场 `blocking`、配乐及未知字段都受保护。
需要这些修改时写入编排说明，交由相应镜头或空间安排修订，不能绕过检查或扩大允许列表。

## 关键帧与 Seedance

`frame` 描述切点当下的单一状态，沿用中文景别与角色名，用既有设定图锁身份。
`shot` 沿用中文与通用身份，从该切点向后写；不新增镜头标题、秒数、图片编号或台词包装符号。
Seedance 导出消费 `shot`、现有构图、段级走位与声音字段，不读取 `note` 作为动作指令。保留原有构图与引用合同，动作必须进入正文。
声音随动作同步：放稳后才撤手，就不能保留半空碰撞声；动作删除后也要检查旧音效。
跨镜持续状态按动作规则写入消费端：`note` 记录画内与画外的必要承接，`frame` 呈现切点可见状态，`shot` 开头交代与本镜动作有关的持续关系再推进变化，H3 对应镜头同步。段级声景延续已有环境或运转声，具体接触声音对应镜头内实际阶段；不把每次切镜当作声源重启。

每切核对实际光源及光色、画内身份、相对场景锚点的位置、朝向或视线、机位侧。共同设定可在本次实际提交的生成输入中统一说明，逐镜正文写变化及理解动作所需的局部关系；不机械重复全部锚点。
按各消费端分别核对输入：Seedance 可以使用实际导入的段级与摄影字段；H3 不会自动读取这些字段，需要在自身现有协议结构中明确必要事实。独立关键帧、独立视频段各自保留必要说明与真实参考，不能依赖其他节点或上次生成的记忆，也不能以“同上”代替缺失输入。`frame` 只呈现切点可见事实，不为锚点说明增加画外人物或环境。
锚点必须与原有 `blocking`、构图字段、角色和光照设定相容。发现矛盾时列为未解决或提出调整，不能只改文字就宣称机位和图片已经修正。

修订时重整受影响的原句，合并同义说明、替换过期状态；完整编排与复核依据保存在 `note`。按动作需要控制细节，不自动截断或删去接触、承重、释放及终态。整理后连读起始画面、视频过程和下一镜，确认简化没有改变动作含义或造成跳步。

字面表达检查同时覆盖 `frame`、`shot` 和 H3 动作正文。保持既定情绪或实际特效，不把比喻意外转成新物品、肤色或灯光变化。
对白表演的声音与视线说明沿用剧本 `delivery`，在 `shot` 和 H3 的台词外描述；Seedance 的台词仍由原程序提取，`shot` 不复制台词。
说完后的行为与配角活动写进相应镜头正文。没有相关声音变化时不为凑齐表演检查改写声景；没有授权也不修改上游 `delivery` 或新增表演字段。

## H3

`h3Prompt` 是单独保存的整段提示词，不能以 Seedance 正文已修改来宣称 H3 已同步。
只修订对应镜头的动作和相关声音，沿用输入的语言与结构：

- 保留第一行对齐指令、各镜头顺序及切点；`[Shot k]` 或 `[镜头 k]` 的编号保持不变。
- 保留 `<Picture k>` 等现有图片绑定，不能改变参考图片数或顺序。
- 台词 `<d>…</d>` 逐字保留在原镜头，保留说话人 `(S1)` 等标记及原有的画外音安排。
- 保留描述、声景、配乐三个字段的顺序和配乐正文；只修订与动作相关的声景。
- 中文段落和英文段落分别保持原模式。其他原始协议问题列为未解决，不凭空更换协议。

工具检查修订稿的 H3 基本结构，并比较原对齐首行、镜头块、切点、图片标记、台词与说话人标记、字段标题和配乐。即使两稿相同，缺失的 H3 或可检查的结构错误也会报告。它不能证明动作、说话人身份描述和台词内容的语义对应，需要逐镜复核。
英文或中文提示词的完整格式校验由项目现有入口负责；项目没有校验器时，注明只完成本目录提供的保护性对比。

## 原稿、修订稿与实际结果

在原稿旁另存修订稿，保留原稿。两个 JSON 文件应在同一目录，保持相对图片和素材路径的基准；若项目使用另一套路径约定，则先明确处理方式。
工具不会复制或修复素材路径。报告列出关键帧提示词变动及前后镜头复核范围；`shot` 或 H3 改动后，相关视频导出包同样需要更新。
已经生成的图和视频不会因为文本修改自动更新。确认旧图是否仍能承载新的切点状态，再决定重出范围。
同场续接优先依据接受的实际成片状态。计划尾态、真实尾帧、完整视频和用户转述分别记录，不能互相冒充。

## 工具执行

```bash
node {baseDir}/scripts/motion.mjs review --before <原稿.json> --after <修订稿.json> --out <motion-review.md>
```

`--out` 可省略，将报告写到标准输出。指定输出时拒绝覆盖已有文件；需要重新生成时选择另一个文件名。
工具会检查完整分镜的保护范围，因此选段修订也应提交完整副本，避免遗漏其他段落。报告按具体字段路径定位改动。
程序门的具体范围与失败处理见 [gates.md](gates.md)。修改切的 note 应保留起始、动作、结束、接镜四段说明和原有备注；标签齐全不代表动作连贯。
对比通过只表示受保护结构与可检查的协议内容未变，仍需执行技能入口的动作语义复核。
