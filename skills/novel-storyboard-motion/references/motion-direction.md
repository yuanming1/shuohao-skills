# 动作编排与物理连续性

## 编排精度

只展开决定因果、观众理解和跨镜承接的过程。写“乙接住重量后甲松手”通常比逐根指定手指位置有用。
常见动作仍需要正确顺序；复杂动作可以拆解、简化或借助参考，但没有“几秒内必定安全”的保证。
质量、角度和速度没有依据时使用相对描述，不编造测量值。以下写法是编排方法，不是物理模拟或生成成功保证。

## 物品交接与操作

普通递交先确认：谁持有、哪只手在关键时刻接触、怎样到达接收位置、怎样接住重量、原持有人何时松开、物品最终在哪里。
手别仅在影响可读性和承接时明确；一旦锁定，就沿动作保持。双方短暂共同持有是同一个物体，不能画成各持一件。

| 情形 | 必须交代的变化 | 常见缺口 |
|---|---|---|
| 普通递交 | 原持有者送出 → 对方接触并承重 → 原持有者释放 | 对方未接稳就松手，下一镜突然已持有 |
| 放到台面 | 托持移动 → 底部接触支撑面 → 放稳后撤手 | 无支撑悬停、撤手后仍粘在掌心 |
| 从台面拿起 | 接触并握稳 → 承重后离开台面 → 保持持握 | 物体先升起，手才追上 |
| 拒接或撤回 | 是否发生接触 → 谁继续持有 → 怎样收回 | 为了符合普通交接模板擅自完成递交 |
| 抛接或掉落 | 释放 → 飞行或下落 → 接住、碰撞或落地 | 空中换持有人、缺少放手就瞬移 |
| 换握 | 原支撑 → 新接触建立 → 支撑转移 → 原接触解除 | 握持手和朝向在切镜时无故变化 |

倾倒要明确容器的开口、倾斜方向和液体去处；恢复竖直后流动停止。翻转要明确转轴或手腕动作及最后朝向。
不要把倾倒和放置、换握和转身各自复杂化后又挤在同一短镜头里。必要时分开主要动作，保持因果关系。
空中运动不要求全程有支撑；需区分主动抛出、失手掉落和无解释悬浮。

## 身体接触与承重

扶住、搀起、拉拽和推开，先明确接触部位、施力方向与被作用者的支撑。
例如，受伤者原本靠墙站立，辅助者扶住上臂后逐步接过部分重量；不能只改成“扶住”，就让墙、脚和原支撑关系消失。
接触不是自动成功：抗拒、脱手或推不动要按故事结果编排。双方存在作用关系时，将回应写进同一个动作过程。

起身、下蹲、失衡与回稳应有可见变化：脚下支撑、身体倾向、必要的蹬伸或扶持、结束时是否站稳。
无需给普通站起逐关节分解；当一只手已拿物品时，不应又让同一只手同时承担不相容的支撑或操作。

## 施力、运动与反馈

按“作用原因 → 路径与方向 → 可见反馈 → 终态”写出需要的事实。

- 重量：提起时的身体准备、承重变化、放下时的缓冲；不要仅用“沉重”代替表演。
- 惯性：释放、刹停或碰撞前后的动势，必要的减速、越过目标或回稳。不是每个物体都要滑行或反弹。
- 摩擦：区分滑动、滚动、拖拽与被卡住，声音与接触面相容。没有依据时不写精确距离。
- 碰撞：先到达接触位置，再发生形变、震动、偏转或停止；反馈依据材料与故事，不默认爆炸或碎裂。
- 铰接物：门、柜盖沿既有铰链转动，保留开合方向和通行空间；不是整块平移。
- 风和液体：说明作用对象与流向，选择一两项画面可见的反馈，避免添加整套环境事件。

动作成功与事故要分清。故事里的意外可以保留，但要交代导致意外的过程；不能为了省事把被动结果改成角色主动实施。

## 连续状态与跨镜继承

从最近一次明确建立的状态向后追踪，而不是每切回到段落开场。重点记录正在影响动作的持有者、数量、手别、接触与支撑、朝向、动势和启用或损坏状态；只保留当前因果和后续承接需要的信息。
在既有 `note` 的起始、结束和接镜中记录这些状态，不新增独立状态卡或 JSON 字段。缺少状态来源时向前查阅；仍无法确认的部分列为待补。

- **复合状态同时保持**：物体一端被手握住、另一端仍接触支撑面时，两种关系同时成立。不能只写“手持”就默认整体离开支撑；只有抬起、释放或支撑改变后，才更新对应关系。
- **双手占用逐次核对**：每次拿取、按键、扶持或推门前，先检查需要的手是否可用。已占用时，按既定事件补齐释放、换握或放置；不擅自新增收纳位置或悬浮能力。操作完成后也要交代是否仍在接触，不能默认手已经空闲。
- **持续接触先继承再变化**：在下一镜 `shot` 及 H3 对应镜头开头，用简短语句交代与本镜有关的持握、支撑或拉拽仍在持续，再推进新增动作。`frame` 只描述切点可见部分；画外状态留在备注及必要的视频承接文字中，不强行把物品写入画内。
- **变化逐项更新**：按键开启只改变启用状态，不顺带改变持物手；反打只改变观察方向，不重置接触关系。湿润、破损、受伤或持续施力等已建立状态，保持到出现合理改变原因；不要为保持状态而冻结人物全部动作。
- **声音对应动作阶段**：区分接触、承重、释放、碰撞及持续运转。声音随声源实际开始、持续和停止；碰撞声对应碰撞，播放声对应已经开启的设备。已有画外声音可以连续，不能因声源暂时不入画就删除，也不能凭声音补造未发生的接触。

连续镜头之间允许有故事依据的时间省略或换场，说明省略了什么及状态依据，不要求重演整个动作。
关键结束状态需要当前构图能证明；不强制每段停留固定秒数。已有成片按实际接受的结果继承，未观察到的手别、支撑或动势保持未知。

## 镜头密度与可见性

一镜围绕一个主要动作和明确终点。递交需要两个人协同，仍可作为一个主动作；动词多不等于必须多切。
接触处或终点被裁出画面时，先判断它是否承载观众必须理解的信息。需要看清的过程应调整拍法建议或切分；不必让所有手部操作一律变成大特写。
动接动只在阶段明确、方向与状态可以继承时使用。允许可理解的剪辑省略；关键归属变化和因果不能靠省略掩盖。

结束画面要说明当前构图最后留下什么。“镜头没有跟随”只排除了一个动作，没有交代观众看见的终点。
人物跨越场景锚点时核对到达过程：从门边直接切到柜台上的手，若会使人物显得瞬移，应提出补足走近过程或明确省略的建议。
需要新增走位、运镜或切镜时列为合同调整；不能在固定机位正文中暗加下摇，也不能在原稿没有移动时自行编一段行走。

## 逐镜连续性锚点

每切开始编排前，核对下面五类已确认事实。检查覆盖完整，输出按当前镜头需要取舍：共同设定在本次实际提交的生成输入中统一说明，逐镜正文写变化及容易歧义的局部关系；同义内容合并，不把五类锚点逐镜机械复述。
确认说明确实进入对应消费端：`note` 不作为生成输入，H3 不会自动读取 Seedance 的段级与摄影字段。独立生图或独立视频段仍应携带必要事实与真实参考；不以“同上”或其他节点的内容代替，也不增加协议外字段或包装。

| 维度 | 逐镜核对的内容 | 延续方式 |
|---|---|---|
| 光照 | 已确认的实际光源、光色和方向，当前是否仍亮着 | 同段共同设定统一说明；开关、变暗或换场有依据时写入对应镜头，不反复复制过期灯光 |
| 画内人物身份 | 能区分当前人物的年龄段、发型、服装或标志物 | 沿用角色资料与原指代，保持简短稳定；空镜不添加人物，画外人物不因锁定句进入画面 |
| 位置 | 人物相对门、柜台等固定场景锚点在哪里 | 从最近终态继续；走到新位置后更新，不能把已经离开门口的人再次锁回门口 |
| 朝向与视线 | 身体面向什么、眼睛此刻看向哪个对象 | 对照站坐高度与对象位置；反打改变画面左右，不自动改变场景关系 |
| 机位侧 | 当前摄影机位于哪个场景锚点的一侧 | 与原 `cameraPosition` 和构图一致；“平视正面”不能替代场景中的机位位置 |

例如，已确认柜台上方暖白吊灯持续亮着，年轻修理师穿浅灰围裙在柜台内侧，深蓝夹克司机在外侧，摄影机在东端。
在首次建立关系或独立生成该双人镜头时，可写：“柜台上方暖白吊灯持续照明；浅灰围裙修理师在柜台内侧，深蓝夹克司机在外侧，两人相向；机位在柜台东端。”同一生成输入的后续手部镜头若只改变交接阶段，明确双方持握与承重变化即可；换到独立输入时重新携带必要设定。
这个例子只说明写法，不能把其中的灯具、服装或方位套到未提供这些设定的项目。

反应镜头先查被注视对象的真实位置，再核对现有机位能否形成相容的视线。反打常从被注视对象一侧拍摄，视线可掠过镜头指向对象，不能默认看镜头就是看对方。
对象在人物身后时，正面近景里直视前方不能表达“正看着身后对象”，除非已有转头或其他可见依据；有意直视镜头则按故事保留。
只重申既定安排，不重设计灯光、身份、站位或机位。缺少锚点信息时列为待补；需要空间调整时提出建议，不能让正文和受保护字段各说各话。

## 字面表达与表演依据

把故事含义翻译成摄像机能够记录的行为。遇到可能被理解成画面变化的比喻、成语或情绪颜色词，先确认原意，再用明确表演方向和一项可见依据表达。
这是逐句判断，不是禁词表；故事确实需要变色、僵直或直视镜头时，不应机械删除。光色、材质、脸部颜色变化要有实际场景或剧情依据。

| 风险表达 | 可能偏离的方向 | 按已确认故事改写的方向 |
|---|---|---|
| 他被这个消息钉在原地 | 把比喻当成实体束缚 | 震惊地停住脚步，目光留在消息来源处 |
| 她的脸一下变黑 | 把不悦演成肤色或照明变化 | 若原意是不悦，写清不悦及视线或动作，保持已确认肤色和光源 |
| 他的眼神像利刃 | 把目光画成武器或特效 | 明确警惕或敌意，视线持续落在既定对象身上 |
| 眉头皱紧、嘴角压下、下颌收紧 | 肌肉清单不足以区分惊讶、愤怒和失落 | 先按剧情明确反应方向，再保留一项最能看懂的身体依据 |
| 冷意在房间里蔓延 | 无依据地增加雾气或冷色灯光 | 用原有角色的停顿、目光或声音变化承载气氛，不重设光色 |


采用“明确表演方向＋可见动作依据”，例如“迟疑，伸出的手停在袋子旁”；情绪词和身体细节都应服务故事，不把表演写成肌肉清单。
原表演意图不明确时列明疑问，不为修辞检查擅自选定新的情绪或人物动机。

## 对白与配角的延续

对白逐字保留，表演说明放在台词外，沿用原 `delivery`、角色声音设定与画外音安排。针对当前镜头核对三个阶段：

- 开口时：按照故事明确音量、语速、清晰度或表达目的中实际有用的一两项；“平静”可以保留，但不能用它替代所有声音和行为指令。
- 说话时：明确看向谁或什么，视线与当前机位及位置相容，必要动作仍按接触和承重安排继续。
- 最后一句之后：在镜头剩余时间内承接原有视线或动作，例如收回已经松开的手、继续注视或维持倾听；不要让角色一说完就自动冻结。

不要求每句话都新增反应，不为了填满尾部强加流泪、转身或剧情事件。保持当前表演也可成立，但要写清持续的是哪项行为。
画外说话人仍是画外说话人；镜头中听者的反应不能把对白转给听者，也不能因为写表演而改变原说话人标记。

已有配角在后续仍入画时，明确延续哪项已建立的活动、注意对象或自然呼吸；空间和身份不变不等于全身不动。
普通背景活动只需一条短句，与主动作相容。不要为了让背景活动而新增群演、道具或抢戏动作。
配角开始承担关键动作时，明确其身份、当前位置和动作结果，再检查本镜负荷；不能一边仍把他当作静态背景，一边要求他完成新的主要事件。

## 逐镜反例

| 表面描述 | 实际问题 | 修订方向 |
|---|---|---|
| 甲递给乙，乙接过 | 谁何时松手、重量如何转移不明 | 写关键接触与释放，不堆手指细节 |
| 关键帧已由乙持有；正文重新递交 | 同一交接重演 | 关键帧退回起点，或正文从已完成状态继续 |
| 甲停住，重箱也瞬间停住 | 原动势和停止原因缺失 | 按实际材质、地面和施力交代减速或阻挡 |
| 受伤者失衡；下一镜稳站 | 稳定姿态没有动作依据 | 落实扶住或回稳过程，装不下则提出切分 |
| 门向外开，人物却挡在门扇路径 | 既定空间与动作冲突 | 保留故事，提出站位或机位调整建议 |
| 道具暂时不入画，所以删除持有状态 | 把画外等同于消失 | 备注承接，只有画内道具进入画内引用清单 |
| 手握物体上端；下一镜写整体悬空 | 省略了下端离开原支撑的过程 | 同时继承握持与原支撑，拍清抬离后再更新 |
| 左手提物、右手按键；下一镜直接推门 | 未确认操作手是否已离开按键 | 保持左手承重，右手离开开关后再接触门 |
| 开启收音机后切人物脸部，播放声停止 | 切镜错误重置设备启用状态 | 保持已开启和画外持有状态，按故事延续声音 |
| 人物已到柜台，下一镜仍写站在门口 | 重复了过期位置锚点 | 从最近终态更新位置，同时同步 shot 与 H3 |
| 对方在身后，反应近景却直视前方 | 机位与视线无法表达所称关系 | 按真实位置核对转头或反打依据，必要调整列为建议 |
| 固定人物近景结尾要求看清门边地面 | 终点超出当前构图 | 明确本镜实际可见终点，所需运镜或下一镜另提调整 |
| 平静说完，其他人全部不动 | 表演与背景延续没有执行内容 | 衔接声音、视线、说完后的既有行为及配角活动 |
