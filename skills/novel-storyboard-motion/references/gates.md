# 检测门与交付条件

程序检查材料、结构和可确定的协议内容；Agent 负责叙事、情绪、表演和身体动作的联合承接、动作语义与素材观察。两类结果分别记录，不能互相代替。

## 六道程序门

| 编号 | 检测内容 | 失败后的处理 |
|---|---|---|
| G01 输入与镜头骨架 | 两份 JSON 可读取；集、段、镜头非空；段号唯一；时长为正数；节拍区间合法 | 停止比较，定位输入问题，退出码 1；不生成成功报告 |
| G02 镜头合同保护 | 除允许的动作相关文字外，镜号、顺序、时长、节拍、机位、引用、开场走位及未知字段都保持 | 恢复误改；确实需要改合同则列出建议，由对应安排处理 |
| G03 修改字段合法性 | 修订文字为非空字符串；缺失字段只允许补充 note、sfx、soundscape | 补齐合法内容；原稿缺少其他必要正文时报告输入缺口 |
| G04 正文与逐切编排材料 | 修订稿的每切有 frame、shot；受本次修改影响的切有起始、动作、结束、接镜四段非空说明 | 补齐并写入实际消费端；只检查标签和内容存在，不证明内容成立 |
| G05 H3 结构与绑定保护 | 修订稿每段有 H3；三字段各出现一次且顺序一致；镜头数和编号、逐镜图片、累计切点、台词标签位置与闭合合法；改写时原对齐首行、图片、台词、说话人标记和配乐保持 | 修复本次误改；既有协议缺口不通过动作技能擅自补造，列为待补 |
| G06 单边修改与同步提醒 | frame、shot、sfx 或段级 soundscape 改变但 H3 未变时，标为待核对 | 判断是否漏同步；需要时修订。只是措辞变化时可以解释，但保留提醒和逐项依据 |

默认 `apply --file storyboard.json` 从标准输入读取 `{before, after}`，先核对磁盘文件与 `before` 一致。G02–G05 失败或 G06 有待核对项时返回 2，原文件保持不变；全部程序检查通过才将 `after` 写回同一路径并返回 0，仍不表示动作正确。
错误路径、JSON 解析失败、版本冲突和命令错误返回 1。默认报告写到标准输出；`apply --out` 更新指定报告。兼容的 `review` 命令保持只读，报告仍拒绝覆盖。

G04 的检查范围：逐切文字变动影响该切；段级 H3 或 soundscape 变动影响该段全部切；两份数据相同时作为只读体检检查全部切的四段说明。未改动的其他切不强制重写旧备注。
frame、shot 和 H3 的基本完整性检查覆盖整个修订稿；其他段的原始缺项也会报告。选段工作应区分“本次修改”和“范围外既有缺项”，不能将整份报告宣称为通过。
这套工具不核对剧本原文、不验证全部 H3 语法、不验证提示词语言和人物指代，也不执行几何或物理模拟；项目已有完整分镜校验入口时仍要执行。

## 动作语义复核

在编排说明里按具体镜号列出判断和依据；下面七项都要有结论，可以是通过、不适用或未解决，并说明原因。跨镜、跨段按 [四项联合承接](motion-direction.md#四项联合承接) 对每个受影响边界分别记录叙事、情绪、表演和身体动作结论，同时说明连续时间、时间省略或换场及其依据。

1. **故事与结果**：动作实现既定事件、对白和交接结果，没有把拒接改成接住、把事故改成故意或提前演后续事件。上下镜的已知信息、目标与时间地点相容；省略发生了什么、落点如何让观众理解都有依据。
2. **接触与支撑**：持有者、持握手、物品数量、承重转移和释放顺序相容；复合接触同时成立，每次操作所需的手有空闲或转移依据；允许有原因的抛掷、掉落和画外持有。
3. **运动与反馈**：施力、路径、材料反馈和终态相容；重量、惯性和摩擦只按已知条件编排。
4. **可见性、锚点与承接**：关键过程和终点在当前机位可读，起始到结束能由镜头正文推出；相邻切和连续段从最近终态继承持续关系、启用及损坏状态，省略有故事依据，时长可行。逐镜核对光照、画内身份、当前位置朝向和机位侧在各自实际生成输入中有明确依据；共同设定可以统一说明，变化与局部歧义落实到对应镜头。反应视线与对象位置相容，没有使用过期位置或暗改机位；合并正文后关键接触与承接仍然清楚。
5. **提示词与素材**：备注、frame、shot、H3、声音和真实参考材料表达同一安排；接触、释放和持续声源对应实际动作阶段，画外声源有状态依据；明确哪些图片、宫格及导出包需要更新。
6. **情绪与表演依据**：人物意图、情绪方向与强度从最近状态继续，变化有既定触发或合理时间经过；不因反打或新段重置情绪、重演反应或提前改变关系。比喻、成语、情绪颜色词和肌肉清单表达既定含义，不引入未经设定的物体、肤色或光照变化；表演方向有当前景别可见的依据，不把修辞一律视为错误。
7. **表演阶段、对白与配角延续**：注意对象、视线、反应与发声阶段承接上一镜，原对白、说话人、声音设定和画外音保持；根据需要交代声音表达及说完后的行为，听者反应不能提前于触发。原有配角延续合理活动或注意对象，不全身冻结，也没有新增抢戏情节；没有对白或配角时仅将对应子项记录为不适用。

四段标签齐备、提示词都被改过、对比报告返回 0，都不能代替以上七项判断。
连续状态问题应列出前后镜号、继承关系和变化依据；情绪与表演变化、双手占用、复合支撑及声源阶段由 Agent 按正文和实际素材判断，六道程序门不自动认定这些语义成立。只有静态首尾帧时，不能宣称表演节奏、连续运动和声音已验证。
逐镜锚点、字面表达、对白表演与配角活动也属于语义判断；程序不凭关键词判定通过，不因此增加新的程序门。

## 交付前检查

- 记录实际读取的分镜、剧本或故事说明、相关设定和素材范围，区分确认事实、用户转述与待核实假设；无需输出新的 JSON 清单。
- 每个受影响的跨镜、跨段边界都有四项承接的具体结论；需要新增剧情、走位、机位或切点时，列出上游调整并在完成后复核，不通过动作文字绕过保护范围。
- 校验通过后原位更新正式分镜，在回复或已有报告中提供对比和动作语义说明，不新增分镜版本；保留程序失败、待核对和项目校验的真实结果。
- 有未解决材料、必要镜头调整、未解释同步提醒或未通过检查时，状态明确写为部分完成或待补。
- 图片、视频尚未生成或未实际查看时，说明只完成文字编排；不得写成成片通过。
