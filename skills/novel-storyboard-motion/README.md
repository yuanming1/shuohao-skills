# novel-storyboard-motion-04 · 动作与连续状态 · v4.0.1

**本组第 04 步，调用使用 `$novel-storyboard-motion`。** 推荐顺序为 01 分镜初稿 → 02 站位与空间 → 03 情绪与镜头增强 → 04 动作与连续状态；02–04 按需执行，本步接收最新分镜。编号只用于显示与使用指引，不要求安装其他技能。

对已有分镜联合复核跨镜、跨段的**叙事、情绪、表演和身体动作承接**，补齐物品交接、承重、接触与物理运动过程，并同步关键帧、Seedance 镜头正文和 H3 提示词。
跨段连读上一段结尾与下一段开头的表演过程，先区分连续时间、时间省略和换场，再核对意图与情绪、视线和反应、姿态与道具状态。已有成片按已接受的实际结果复核；单张尾帧不能证明表演节奏和动势。
逐镜核对光照、身份、位置朝向和机位侧，同时检查字面表达、对白表演与配角活动延续；方法已内化到本目录，无需另行安装来源技能。

使用位置：01 分镜初稿 → 02 空间安排（按需）→ 03 表现增强（按需）→ **04 动作编排与连续状态复核** → 最终宫格、关键帧和视频导出。
需要空间或切镜调整时返回对应安排，完成后再复核动作；这一步按需执行，不会自动插入原有流程。

向 Agent 提供本目录 [SKILL.md](SKILL.md)、分镜原稿和对应剧本或故事说明，例如：

> 使用 novel-storyboard-motion 检查这份分镜里的收音机交接。保持剧情、对白、镜号和时长，补齐接触、承重与松手，同步关键帧和两套视频正文，校验通过后写回同一份 storyboard.json，并列出未解决项。

跨段承接也可以这样提出：

> 使用 novel-storyboard-motion 联合复核相邻两段的叙事、情绪、表演和身体动作。连读前段结尾与后段开头，说明时间关系、继承状态和变化依据；有实际视频时一并查看，保留镜头合同，把必要承接写进关键帧与两套视频正文，并逐项列出结论和待补内容。

直接更新传入的正式分镜，不新增 `-motion.json` 等版本文件。对比结果与编排说明可在回复中交付或更新已有报告。入口已列明分镜、剧本、设定与实际素材的读取顺序和缺项处理。
随附工具有 6 道程序门，覆盖骨架、合同、字段、正文与编排材料、H3 结构及单边修改提醒；语义另做七项复核，每个受影响边界分别记录四项承接结论。详细范围见 [检测门说明](references/gates.md)。工具不自动编写动作，也不验证叙事、情绪、物理语义或生成效果。

```bash
node skills/novel-storyboard-motion/scripts/motion.mjs apply --file 项目-storyboard.json
node skills/novel-storyboard-motion/scripts/selftest.mjs
```

标准输入传入内存中的 `{before, after}` 两个完整对象：修改前内容与完成语义复核后的修订内容。工具先检查当前文件没有变化，保护门通过才写回同一路径；失败时不改分镜。默认向终端打印报告，`--out` 更新已有报告。旧 `review --before --after` 保留给已有历史文件做只读比较，不是默认制作流程。
Node.js 18 以上即可，无依赖安装、API key 或生成费用。返回码 0 表示程序门通过，2 表示合同、材料或 H3 检查未通过，或者同步待核对，1 表示输入错误。

整个目录可单独复制，安装脚本能够自动发现含 `SKILL.md` 的新目录；也可以直接让 Agent 读取本入口。
