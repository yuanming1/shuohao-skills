# novel-storyboard-motion-04 · 动作与连续状态

**本组第 04 步，调用使用 `$novel-storyboard-motion`。** 推荐顺序为 01 分镜初稿 → 02 站位与空间 → 03 情绪与镜头增强 → 04 动作与连续状态；02–04 按需执行，本步接收最新分镜。编号只用于显示与使用指引，不要求安装其他技能。

给已有分镜补齐物品交接、承重、接触与物理运动过程，沿镜头继承复合支撑、双手占用和设备启用等连续状态，并同步关键帧、Seedance 镜头正文和 H3 提示词。
逐镜核对光照、身份、位置朝向和机位侧，同时检查字面表达、对白表演与配角活动延续；方法已内化到本目录，无需另行安装来源技能。

使用位置：01 分镜初稿 → 02 空间安排（按需）→ 03 表现增强（按需）→ **04 动作编排与连续状态复核** → 最终宫格、关键帧和视频导出。
需要空间或切镜调整时返回对应安排，完成后再复核动作；这一步按需执行，不会自动插入原有流程。

向 Agent 提供本目录 [SKILL.md](SKILL.md)、分镜原稿和对应剧本或故事说明，例如：

> 使用 novel-storyboard-motion 检查这份分镜里的收音机交接。保持剧情、对白、镜号和时长，补齐接触、承重与松手，同步关键帧和两套视频正文，另存修订稿并列出未解决项。

交付包含修订分镜副本、Markdown 对比报告和编排说明。入口已列明分镜、剧本、设定与实际素材的读取顺序和缺项处理。
随附工具有 6 道程序门，覆盖骨架、合同、字段、正文与编排材料、H3 结构及单边修改提醒；动作和表演语义另做七项复核。详细范围见 [检测门说明](references/gates.md)。工具不自动编写动作，也不验证物理语义或生成效果。

```bash
node skills/novel-storyboard-motion/scripts/motion.mjs review --before 项目-storyboard.json --after 项目-motion-storyboard.json --out motion-review.md
node skills/novel-storyboard-motion/scripts/selftest.mjs
```

两份分镜放在同一目录以沿用素材相对路径，原稿不会被改写；报告输出拒绝覆盖已有文件。
Node.js 18 以上即可，无依赖安装、API key 或生成费用。返回码 0 表示程序门通过，2 表示合同、材料或 H3 检查未通过，或者同步待核对，1 表示输入错误。

自有文字样例从 [末班修理铺的故事](examples/末班修理铺-story.md) 开始，再阅读 [动作修订](examples/末班修理铺-motion.md)。
整个目录可单独复制，安装脚本能够自动发现含 `SKILL.md` 的新目录；也可以直接让 Agent 读取本入口。
