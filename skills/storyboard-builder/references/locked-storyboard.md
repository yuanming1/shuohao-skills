# 锁定现有分镜模式

本模式用于已有正式分镜的宫格预演，实际参考图片可选。它是原 Storyboard Builder 的输入适配，
不是再次拆镜，也不重复生成独立关键帧。单独复制本技能即可使用，不依赖预演技能。

## 输入

**必需的是分镜中的画面描述、景别、原镜号和时长，不是视频提示词。**
只有关键帧提示词、尚未生成实际图片时，也能交付完整宫格图提示词。
直接接收既有分镜，或读取调用方提供的 `grid-input.json`；角色图、场景图和关键帧图片均为可选补充。

- 顶层：`mode`、`segment`、`layout`、`panels`，共四项。
- `mode` 必须为 `locked-storyboard`。
- `layout` 包含 `columns`、`rows`、`aspect`；`source` 在有图时表示沿用参考画幅与方向，无图时不声称已知原图尺寸，仅要求画幅一致。
- 每个 `panels` 对象包含 `shot`、`time`、`size`、`frame`、`reference`，共五项。
- `time` 是原镜头起止秒数的十进制字符串数组，不是均分后的新时长。
- `frame` 是必需的原切点画面描述。`reference` 为可选的已有关键帧路径；无图时是 `null`。路径本身不会上传图片。

缺少原镜头画面描述、景别或时长时说明缺项，不编造。**没有图片不属于缺项**：可以只有部分镜头有图，
其余依据各自文字描述，不能要求先生成一套关键帧，也不能假装已经看过图片。
图片已明确提供但存在多个版本、为空或无法读取时说明问题，不随意挑选。

## 锁定规则

1. 保留原镜号、顺序、景别、时间范围和切点状态。图格默认对应原切点，不把结尾动作提前画进起始帧。
2. 格数由输入镜头数量决定，不强制十五格；不平均重分秒数、不强制景别交替。
3. 以原分镜文字为依据；有参考图时复用其明确的人物身份、服装、道具持有与场景外观。无图时保持文字描述的一致性，未指定外观属于生成选择，不声称已经匹配正式资产。
4. 有图时默认保留参考画幅，不能因原模板写有 16:9 就裁剪竖屏分镜。无图时遵循明确的项目画幅；未指定则要求统一，不虚构原图尺寸。
5. 保留「布局在先、每格内容、角色一致性、画面内部风格、明确渲染整页」结构；部分图格无图时，不能把其他镜头参考图复制过去充数。
6. 镜号、时间码和说明放在图格外；原剧情中的文字，例如凭条编号，不应因「无标注」规则而被删除。

## 交付

使用 `locked-grid-template.txt` 组织一份完整的宫格图生成提示词。
调用方已经生成 `grid-prompt.txt` 时可以直接使用；需要润色时只调整表达，不改变锁定字段。
输出一个可复制的提示词代码块，并附三至四行说明：依据文字还是参考图片、易失真的细节、
分辨率建议，以及本次没有自动出图。

- 无图时明确标注文字输入，不要求上传不存在的图片；提示词仍然应当完整。
- 有图时一并提交实际参考文件，不能把路径当作已经上传的图片；部分有图时逐镜标明范围。
- 调用方的 `export-grid --frames` 仅匹配按原镜号命名的关键帧；角色图或场景图可在图像工具中另行附加，不假定脚本已经解析这些资产。
- 模板插槽必须填完，不能把未填写的占位符作为完整提示词。

宫格生成不保证逐像素复现已有帧；要完全保留像素应使用拼图工具。
不要把宫格直接替代正式独立关键帧，除非下游接口已经验证支持这种输入。
