## 3. 角色核心铁律

### 3.1 540°方向铁律

540°必须写成：

```text
水平旋身 / 如陀螺横转 / 水平面旋转
```

禁止写成：

```text
竖向翻腾 / 后空翻式旋转 / 垂直翻转
```

### 3.2 凛羽70/30法则

凛羽不是纯柔术家。

```text
形意拳+八卦掌 = 主旋律70%
擒拿/柔道/合气道/柔术 = 破招插入30%
控制是中间态，不是终招。
```

凛羽正确逻辑：

```text
形意/八卦打进去 → 对攻中抓机会破招 → 破招后立刻衔接形意/八卦继续攻击
```

### 3.3 铁律29·招式复用规则

```text
对战双方变了 → 招式可以复用。
对战双方没变 → 招式禁止重复。
```

判断标准：

```text
"角色A VS 角色B"中A和B完全一致 = 同一对战，必须零重复。
A或B任一不同 = 不同对战，允许复用。
```

同组合新版生成前，先查《对战组合招式记录表.md》。

### 3.4 冰女 vs 凛羽冰系区分

```text
凛羽 = 霜雾弥漫型：雾、薄霜、寒气微粒、渗透。
冰女 = 硬冰冻结型：冰晶、冰刺、冰壁、冰甲、冰锁。
```

简记：

```text
凛羽=雾，冰女=冰。
```

### 3.5 芭乐核心逻辑

芭乐是灵巧降服型，不是旧版玫红火焰全能型。

```text
形意直线爆破 + 蔡拳密集手法 + 跆拳道高位踢技 + 巴西战舞翻转换位 + 柔术地面降服
```

战斗维度：

```text
站立 → 翻转 → 地面
```

特效性格：

```text
浅粉 → 深粉，越打越深，越打越烈。
轻时浅粉飘散如花瓣，重时深粉炸裂如花开。
```

### 3.6 芭乐 vs 红茶核心差异

```text
红茶 = 火焰灼烧型，一上来就全力炸裂。
芭乐 = 花瓣绽放型，越打越深越打越烈。
```

## 4. 镜头系统核心规则

### 4.1 铁律30·镜头规格强制法则

每次镜头描述必须包含：

```text
[景别] + [拍摄视角+角度] + [运镜方式] + [跟随目标]
```

景别四选一：

```text
全景 / 中景 / 近景 / 特写
```

视角五选一：

```text
正 / 侧 / 斜 / 俯 / 仰
```

角度必须具体：

```text
45°斜拍平视 / 30°仰视 / 60°俯视 / 侧面90°平视
```

跟随类运镜必须写明跟随目标：

```text
跟随芭乐腰部横向平移
跟随白鸽右腿旋风踢弧线
推进至红茶拳面命中点
```

### 4.2 镜头目的性四原则

| 场景 | 镜头原则 | 目的 |
|---|---|---|
| 正常速度对招 | 中近景/近景，侧面，带移动感 | 聚焦手部招式变化 |
| 蓄力大前摇 | 仰视、慢推、合理构图 | 突出威力，让观众感到"大事要发生" |
| 快速攻防 | 带角度斜拍+方向性移动 | 手部看不清时，用全身和镜头移动显速度 |
| 特写 | 抓破绽、转折点、命中瞬间 | 作为情绪标点，0.2-0.5秒后立即切走 |

总纲：

```text
景别、镜头、运镜都要有目的。
先问这个分镜要表达什么，再决定镜头怎么写。
```

### 4.3 空间感铁律

```text
中景及以上，只要看到两个人完整身子，禁止侧面90°正拍。
```

原因：

```text
中景/全景侧面90°正拍非常像格斗游戏，没有空间纵深和对决压迫感。
```

正确规则：

```text
中景/全景必须用30-60°斜角。
只有近景/中近景/特写才允许侧面90°。
```

### 4.4 精品镜头8种黄金模式

| 模式 | 名称 | 适用场景 | 核心 |
|---|---|---|---|
| A | 低仰蓄力 | 终结技前摇/压迫感 | 15-30°仰视，攻击方占画面2/3 |
| B | 轨迹拖尾 | 踢技/腾空/大幅攻击 | 拖尾长度≥角色身高1.5倍 |
| C | 接触点双色咬合穿透 | 关键命中/破绽 | 进攻方特效刺入防守方特效体内 |
| D | 全景冲击波 | 大招对撞/终结命中 | 以碰撞点为圆心，地面裂纹辐射 |
| E | 不对称特效压迫 | 展示力量差距 | 一方特效铺满半屏以上 |
| F | 翻摔全肢展开 | 过肩摔/过胯摔 | 被摔者身体成连续弧线 |
| G | 元素对称对峙 | 力量对等悬念 | 双方特效面积/亮度/密度接近 |
| H | 角色签名地面 | 地面降服/终结收束 | 地面被胜者特效染色 |

### 4.5 冷暖色彩对抗铁律

```text
同色系特效打架，不如互补色/冷暖对比好看。
```

例子：

```text
白鸽紫 vs 冰女蓝白 都是冷色，容易打不起来。
可以把白鸽紫加深到偏暖品红边缘，让暖紫刺入冷青蓝。
```

```text
深马步 + 拳收后腰 + 五指逐根捏合音爆 + 血色蒸汽 + 脚下蛛网碎裂
```

## 6. 新角色创建流程

当用户说"创建角色 / 新增人物 / 绑定技法 / 我要做一个新角色 / 帮我设定角色"时，必须先进入创建角色引导流程，不能直接拍脑袋生成角色。

### 6.1 第一步：展示技法-招式总览

提示用户从技法库选择3-6个技法，推荐4-5个。

### 6.2 第二步：询问角色信息

询问模板：

```text
你要创建的新角色，想绑定哪些技法？建议选4-5个。
你可以直接回复：角色名 + 技法组合 + 特效颜色/形态 + 胜负倾向。
例如：创建角色青岚，绑定八卦掌、形意拳、柔道、风系青绿色气焰，定位灵动破招型。
```

### 6.3 第三步：按层级分配技法

| 分配项 | 规则 |
|---|---|
| 主战技法 | 1-2个，约70%，负责多数对攻画面 |
| 破招技法 | 1-2个，约20%-30%，用于破防/摔投/锁控 |
| 终结技法 | 1个，选择视觉爆点最强的技法 |
| 距离覆盖 | 至少覆盖近身/中距/空间变化中的2类 |
| 动作维度 | 尽量覆盖站立/腾空翻转/地面控制中的2-3类 |
| 特效性格 | 颜色只是基础，必须定义动态性格 |

## 9. 迭代闭环原则

不要把这套系统当成固定模板，要按闭环迭代：

```text
生成提示词 → Seedance生成视频 → 喂截图/数据 → 分析问题 → 提炼规律 → 更新铁律/SKILL/记忆 → 下一轮生成
```

任何新发现都沉淀到三处之一：

1. **SKILL.md**：可执行规则、模板、技法、镜头系统。
2. **MEMORY.md**：浓缩后的长期核心记忆（本文件）。
3. **精品词库.md / 对战组合招式记录表.md**：数据验证和案例复盘。
