# 人物微表情 01–50

本库整理用户文件《运镜+微表情+法阵指令.txt》第 7 节，保留原来的 01–50 编号，使用 M 前缀便于与其他库区分。表演过程与已标出的适用场景来自原文件；缺失场景、歧义处理和使用条件另行标注。来源见 [sources.md](sources.md)。

## 检索与使用

| 需要的反应类型 | 优先检索 |
|---|---|
| 委屈、伪装、被揭穿、压住怒意 | M01–M03、M05–M06、M08、M19、M22、M25 |
| 心动、关心、吃醋、重逢、克制 | M04、M07、M14–M17、M31、M36–M37、M39、M43–M46 |
| 反击、识破、审视、布局、失控 | M09–M10、M13、M21、M23–M30 |
| 迟疑、噩耗、悔意、放下、告别 | M11–M12、M18、M20、M38、M41、M49–M50 |
| 病弱、强者威压、记忆、忍痛、脱险 | M32–M35、M40、M42、M47–M48 |

先读 [表演规则](performance.md)，需要单个情绪特征时读 [情绪与表情库](expression-library.md)。本库的价值是反应顺序，不是要求每镜做完一整套动作。由剧情确定触发，按当前景别选择可见的一两项变化，在原时长内安排起始、转折和终态。

“适合某场景”不是对剧情的补充授权。条目里的衣袖、杯子、戒指、剑、伞、披风、旧物、伤口和第三人，只能引用故事已存在的内容；没有相应条件就舍弃该细节，不能临时创造替代物。躲闪、转身、退半步、触摸、放下、站起等动作也要保持既定站位、持物和行动结果。

## 与镜头、连续状态配合

微表情不自动要求急推。固定近景能读清变化时保留固定观察；需要摄影帮助时读取 [镜头库](camera-library.md)，例如 C19 提供慢推观察过程，C22 提供急停后的错愕，但反应仍以本镜剧情为准。

切点前已完成的哭泣、微笑、视线转移不能在本切正文重新起步；下一切继承最近终态。说话期间避免紧抿、咬唇、捂嘴与完整发声冲突，吞咽和停顿也要落在可容纳的位置。手部细节即使只发生在画外，也不能丢弃持物、解除支撑或改变归属。

在既有 `note` 的“增强依据”中注明选取的 M 编号、实际保留的表现与舍弃原因；所选反应进入 `shot` 和对应视频正文，切点状态进入 `frame`。这是追溯写法，不要求增加 JSON 字段。完成后按 [检测门](gates.md) 复核实际可见性、口型、手部、反应顺序与前后镜连续状态。
