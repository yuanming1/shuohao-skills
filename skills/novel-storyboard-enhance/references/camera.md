# 有目的的镜头表达

## 先判断整组表达

按照入口确定镜头组后，连读故事与组内镜头，先判断下列关系，再为每镜选择摄影方式。这里的成组判断包含表演观察任务，情绪发展与反应承接按 [表演规则](performance.md) 复核。

| 评估内容 | 判断依据 |
|---|---|
| 信息推进 | 各镜让观众理解什么；重复观察是否承担等待、强调或确认结果的作用，有无没有收益的重复展示。 |
| 注意力安排 | 此刻应观察行动者、说话者、听者或事件结果；既有构图是否呈现重点，前景或运动是否抢走注意力。 |
| 摄影配合 | 景别、构图、固定与运动如何帮助既定变化；相似构图可以持续观察，不机械交替远近或动静。 |
| 镜间衔接 | 现有切换承接什么信息或反应；关键过程是否在可读之前被切走，下一镜是否无依据地重复上一镜的发现。 |

每镜可以保持原安排，也可以在已有字段内作最小调整。连续急推、环绕或表情特写需要分别有收益；不将每镜都处理成情绪高潮。已有固定观察足够时，不为制造节奏差异而增加运动。

在决定逐镜修改前，把整组观看过程对应到镜号：从什么已知信息出发，依次观察谁或什么，在哪一镜看见触发后的反应或持续状态，最后确认什么。检查现有镜头之间怎样配合这个过程；“提问—回答—操作”这样的剧情摘要，还没有说明摄影选择。镜号覆盖完整也不证明各镜的表达作用已判断。

结合故事核对人物为什么采取下一步行动、应对或暂不反应，以及观众能从哪处既有画面或声音读出这些原因。必要依据已经存在时，调整观察范围与声画呈现；依据缺失、需要新增事件或改变知情状态时，列明剧本缺口。不要仅因动作顺序和站位连续，就认定行动因果已被观众理解。

遇到重复展示、观察对象不明确或关键过程难以看清时，对相关镜头比较可行的选择。例如，两次同景别说话者特写可以保留，以持续观察越来越具体的施压；也可能需要改变其中一镜的取景、关系前景或焦点，让观众读出对方受到的影响。说明哪种安排更能呈现本组事实，以及舍弃另一选择的具体原因。无需每组列多个方案，也不预设“必须改变”或“固定就应保留”。

组合调整可以发生在已有镜头内，也可以根据缺失的观察阶段拆并镜头、重新分段和重分时长。双人关系构图、带对方局部前景的观察、独立反应和结果全景按表达配合。逐镜人物与道具引用随实际画面更新，只引用原场已有身份；对白随原剧情节拍绑定，原文、说话人和画内或画外归属保持。

连续行动可按已有事件区分准备、作用、承受与结果，检查各镜提供的证据。例如操作前的决定、操作本身和环境结果可以由不同观察范围承担，也可以在一镜内连续呈现；不是每场都需要四个阶段或四个机位。从行动者切到承受者附近时，说明新增了什么感受或信息，不能仅靠更换角度重复同一次动作。靠近人物的位置属于观察选择，不自动等于该人物第一人称视角。

保留依据要指出具体可见内容及镜间作用。例如：“前镜已建立双方站位，本镜固定看持碗者说完仍承重，下一镜才确认接收者接稳”，比“固定镜头便于观察”更能支持选择。连续镜头只呈现同一接触、姿态或停点时，比较保持连续观察、调整取景与合并镜头的收益，说明单独切换是否增加必要信息、关系变化或持续等待的感受；更换景别本身不足以支持保留。脚本可以排版既有判断，不能从未改动字段或原动作文字推导出保留结论；未经判断的项保持待评估。

## 需要重新编排时

动作或空间修订改变了任务分配时，重新判断受影响镜头组。例如某项动作已提前完成，后一镜仅剩维持终态，就需要说明继续观察的具体收益；不能仅因原稿有这一镜而维持原时长。必要反应、原因或结果也可能超出现有切数和时长，不能通过增添微表情或运镜代替缺失的观察阶段。

在现有增强说明中写清遗漏过程及依据、补演与拆并镜头如何解决它、调整后的观看顺序，以及对白、节拍认领、切点与段总时长的影响。将方案落实到同一份正式分镜，记录新旧镜号对应；更新关键帧、人物/道具引用和视频提示词。时长只能初估时注明依据与待核实部分，不另建 JSON 或新版本分镜。

原有取景与表演调整足以解决时直接完成；确需改变镜数、时长、引用或续段站位时，同样在本次完成编排与空间同步。不要求调用其他技能。场景真正开场的事实、故事结果和用户明确锁定的约束保持；缺少必要事实或项目预算无法容纳时才留下具体未解决项。黑场属于有明确时长与声音的剪辑停顿，不能作为通用运镜写入 `camera`。

## 对话镜头的成组选择（按需）

先判断该处需要看清双方关系、说话内容还是听者反应，再考虑以下构图；不要求对话逐句切换，也不要求固定采用某一种正反打。

- 外反打：前景保留对方的肩部或头部局部，观察主体的面部或行动。需要持续呈现双方关系时可以考虑；明确前景位于哪一侧、占据多少画面，避免遮挡关键反应或道具。
- 内反打：画面集中呈现一方，移除对方的前景形体，便于观察已有反应。仍需说明该人物看向谁，并与反向镜头的机位、视线及关系轴对应；不能只以“画面只有一个人”认定对话关系已经成立。
- 双人固定观察：双方与关键动作可以在同一构图中读清时，可以持续观察提醒、回应或等待，不因轮流说话而强制增加切换。

选择说话者或听者作为观察重点时，保留对白原文、说话人及画外音安排，重排后随原节拍更新镜头绑定。正反向镜头成对核对景别关系、视线方向与高度、前景位置和遮挡，保持世界站位可理解，不要求构图机械对称。人物可见范围变化时同步已有资产引用，不能凭空增添角色。

## 读取具体条目

摄影是每次必选的评估方向。按观察任务读取 [镜头与运镜条目库](camera-library.md) 的相应章节：C01–C10 为景别、视角与基础表现，C11–C18 为情绪化运镜，C19–C24 为人物表情特写，C25–C32 为复合运镜配方。读取描述及落地条件，不能只套名称。
先说明要看清什么，再选择条目；选定编号与取舍写入原有增强依据，运动过程进入实际摄影字段、分镜正文和视频正文。人物表情需要新增细化时，结合本次必选的表演评估与相关条目，不借摄影模板改写人物动机。

## 先明确观察任务

选择摄影方式前，说明这一镜要让观众发现哪项信息、靠近谁的反应，或理解哪段空间关系。固定观察已能完成任务时保留固定机位，并在增强说明中按镜号记录理由；摄影字段没有变化不代表可以省略评估。
每个切镜保留一个主运镜，写清观察对象、起点与终点，以及必要的相对速度和幅度。人物移动与摄影机移动分别描述，不把“角色后退”误写成“镜头后拉”。

运动中的关系按需写进已有摄影字段及正文：从主体哪一侧、什么高度观察，维持哪个部位和取景范围，哪些既有环境参照发生相对位移，终点留下什么信息。不要只把“跟拍”改成“高速跟拍”。固定摄影中的主体掠过、距离缩短和遮挡变化也可以提供动势；跟拍使主体相对稳定时，环境位移可以提供速度参照，不需要同时附加急推与强烈抖动。

视向小幅修正若只为持续观察同一对象，可以作为一个主运动的辅助描述；新增观察对象或明显改变主路径时，应按新的阶段处理。所有阶段须进入修订后的镜数、时长和实际正文，不能借“辅助动作”暗加第二套运镜。

| 任务 | 可考虑的处理 | 需要避免 |
|---|---|---|
| 让既有反应更可见 | 小幅推进或调整已有焦点 | 没有叙事理由就冲向眼睛 |
| 揭示已经存在的环境结果 | 后拉让主体与结果同时可读 | 运镜后凭空出现新建筑、群众或道具 |
| 跟随既定移动 | 沿清楚路径跟随，结束于既定位置 | 为跟拍临时让角色走动 |
| 表现等待或不愿回应 | 固定观察、保持视线与留白 | 为“丰富”增加摇晃、环绕和无关空镜 |

这些是选择依据，不是情绪与摄影的固定对应表。上升不自动意味着光线变亮，后拉不自动意味着人物悲伤。
相对幅度足以表达时不编造米每秒、圈每秒、抽帧比例或成功率；已有实测参考需要精确参数时核对参数是否彼此相容。

同镜后拉逐渐揭示结果，与切到固定全景立即呈现结果，按所需观看时间分别选择。前者起始帧保留较近构图，后者切点直接使用全景；不能把切换景别描述成已发生的连续后拉。镜头长度服务于信息与表演可读性，需要短切、停顿或延长揭示时落实到时长和切点，并说明变化及预算依据。

## 摄影字段与空间核对

摄影模式可以修改已有 `size`、`camera`、`lens`、`cameraPosition`、`composition`、`eyeline`、`focus`、`stability`，并同步 `frame`、`shot` 和 H3。保留原字段取值体系，程序只接受已有适配词表；不适配的协议列为输入限制。
焦点只承诺当前构图可兼容的清晰范围，不同时要求极浅景深下不同深度的多个对象全部清楚。

沿用已确认的场景锚点和开场站位，检查：

- 新机位在什么锚点一侧、朝向谁，是否穿入墙体、人体或已有遮挡？
- 正反打的关系轴和视线是否仍可理解；画面左右变化是否被误当成世界位置变化？
- 起始画面及运动终点是否能同时容纳本镜已绑定的人物、道具和关键动作？
- 近景改远景后，原本依赖细节的表演是否仍可读？远景改特写后，必须证明的接触或结果是否被裁掉？

人物移动须服务于已有行动和性格表达，按既定空间安排路径并同步续段站位；不能为摄影便利凭空改变世界位置、添加空间或创造资产。
长路径、复杂绕行或组合运镜先判断哪些过程值得呈现，再决定连续观察、关键阶段切换和重复路程压缩；所需镜数与时长在本次修订，仍遵守项目预算。
复合运镜按库中的阶段使用：只有现有相邻镜头能够承接时，才将不同主运动分配进去，并分别写明镜号。移动变焦这类整体摄影效果按一个明确的观察目标处理；不把八种组合全部压进单切，也不隐含新增剪切或改变时长。

## 素材与反向复核

文字机位改变后，旧关键帧可能不再适用。查看实际图片，明确仍可使用或需要重出的范围，不能只修改字段就宣称旧画面同步。
摄影参考只指导已指定的镜头方式，不引入参考中的角色外貌、场景或动作。没有实际查看参考时说明依据来自文字。
分析成片时，分别记录可观察的主体运动、视向或取景变化、前后景相对位移与切点，再判断摄影方式。字幕名称和作者提示词属于待核对的说明；单凭“盘旋、升空、微距”等标签不能确认摄影机环绕、上升或真实光学参数。抽帧观察可以支持阶段与构图比较，无法支持的精确加速度、碰撞瞬间和声画效果保持未核实。
从本镜终点反向检查关键过程，再连读整组及必要的相邻镜头：注意对象是否按既定表达转移，保留或修改的构图是否有收益，关键反应与结果是否在原时长内可读，有无各镜成立但整组重复强调或抢走重点的情况。记录组范围、表达收益或保留依据，以及尚未解决的切换或时长问题。
复核时对照修改前后的观看过程，说明哪处注意力转移、人物关系或情绪发展变得更清楚。局部修正可以有价值，但仅改措辞、焦距或单镜运动不自动证明整组组合获得改善；全组保留也须能说明现有各镜怎样相互配合。
构图、轴线、运动和整组表达是否成立由 Agent 判断，字段枚举通过不能代替空间验证或整组复核。只读文字时结论限于文字安排，实际速度、剪辑节奏和观看效果仍需成片支持。
