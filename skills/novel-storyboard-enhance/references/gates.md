# 检测门与交付

## 六道程序门

| 编号 | 检查范围 | 失败处理 |
|---|---|---|
| G01 输入与骨架 | JSON 可读，集段镜非空，段号唯一，时长和节拍基本合法；范围参数必须同时包含 performance、camera，effects 可选 | 停止比较，退出码 1 |
| G02 保护范围 | 顺序、镜号、时长、节拍、引用、开场站位、场次、配乐和未知字段不变 | 恢复误改；确需改变则列为未解决建议 |
| G03 字段与增强方向 | 只改允许的非空文字；表演与摄影为必选范围；光影限必要摄影说明或已选择的特效；枚举合法，程序不判断特效语义 | 修正字段或范围；不能通过扩大方向掩盖非必要修改 |
| G04 正文与依据 | 每切 frame、shot 非空；受切级文字或 H3 镜头改动影响的切有起始、动作、结束、接镜、增强依据；摄影改动具备摄影资料 | 补齐并同步实际正文；标签存在不证明内容正确 |
| G05 H3 协议保护 | 三字段顺序、镜头数量与编号、图片及累计切点基本合法；原对齐首行、逐镜台词/说话人/绑定和配乐保持 | 修复误改；既有协议缺口列为待补，不擅自补造 |
| G06 逐镜同步提醒 | 画面或摄影改动但对应 H3 镜头未变；H3 镜头改动但另一端未变；声景或音效单边改动 | 核对是否漏同步；等义措辞可解释，但保留提醒与判断依据 |

G02–G05 失败或 G06 待核对返回 2，程序门通过返回 0，均不代表语义或成片通过。
只改另一切的 H3 不能消除当前切的同步提醒。两端文字都改过也不能证明语义一致。
未改动镜头无需为了增强补造备注；frame、shot 和 H3 基本完整性仍覆盖整份增强稿。区分本次修改与范围外既有缺项，不能将部分通过说成整份通过。
工具只比较分镜，不读取剧本来证明剧情一致，不识别实际图片，不模拟摄影路径、物理或人物表情，也不验证全部 H3/Seedance 语法、语言、身份指代及台词容量。

## 五项 Agent 语义复核

按镜头组及具体镜号填写通过、不适用或未解决及其依据，不能把程序生成的待复核清单当成已完成结论。组范围以入口的连续表达单元为准，区分评估镜号与仅供上下文读取的镜号；程序列出的相邻镜头只是修改影响提示，不代表整组范围或已完成评估。
先核对整组观看过程是否落实到镜号，再核对逐镜选择是否来自该判断。有疑点的组合应说明具体选择与取舍；原组合保留时也需说明各镜怎样配合。程序或报告生成脚本只能整理已有判断，不得把“未修改”自动判为“保留成立”；复述原动作加通用理由、镜号覆盖或行数齐全，均不构成评估证据。缺少实质判断的镜头标为待评估。

1. **剧情与收益**：原问题是什么，改动使什么信息或反应更清楚；对白、人物意图、能力、顺序和结果是否保持。
2. **表演与可见性**：先说明整组起始状态、已有触发与既定变化，复核跨镜发展是否承接、有无重复反应或无依据重置；再覆盖评估范围内每镜，说明增强收益或保留理由。触发在反应之前，景别、焦点、时长能呈现变化，嘴部与对白相容，未叠加无意义细节；选用 E/X/J/A/N/M 条目时核对完整描述，说明哪些特征实际采用，没有随模板新增关系、道具、伤势、回忆或动作。
3. **摄影与空间**：先说明整组表达目标、注意力安排与现有切换的作用，复核构图和动静变化的收益、重复观察的理由及关键反应是否可读；再覆盖评估范围内每镜，说明观察任务、增强收益或保留理由。主运镜、机位、轴线、遮挡与路径相容；关键过程和终点可见，没有移动人物或新增资产替摄影解围；选用 C 条目时区分景别、机位、路径与光学，复合配方各阶段对应已有切数与时长，升降不自动改光，环绕不造成无解释跨轴。对话镜头按需复核说话者与听者的观察选择、内外反打关系及原对白绑定，必要切点或时长调整列为未解决建议。
4. **特效与连续状态**：已有来源、变化与结果相接，持续或消散有依据；双手占用、支撑、数量及声源阶段没有重置。
5. **消费端与素材**：备注、frame、shot、摄影、局部受光、H3 和声音一致；实际图片与成片按已观察范围判断，列出需更新的材料。

只有未选择的特效增强可按方向标不适用，连续状态仍须复核。表演与摄影不得整项标为“未选择”或以字段未改代替评估；无人镜头可注明表演不适用的具体原因，摄影仍需说明观察任务。相同的保留理由可合并列出镜号，未改动镜头无需补造备注。整组结论与逐镜依据相互关联，可引用而不必重复；全组未改也需说明整组保留依据。缺少整组评估、整组复核或任一必选方向的逐镜评估时为部分完成；程序通过不证明评估已完成。
摄影变化需要空间复核，表演或特效变化需要动作与连续状态复核；本目录提供必要规则，不依赖其他技能才能给出判断。
条目读取与语义适配由 Agent 实际完成，不能把库编号存在、条目数量完整或程序门通过当成适配证明。增强依据应能指出所读条目、采用的可见变化、收益及未采用部分的理由；本次自行编写的表现说明依据即可，不伪称出自资料。

## 完成条件

- 记录实际读取的故事、分镜、相关设定和素材范围，区分确认事实、计划、观察和待核实部分。
- 提供独立增强副本、程序对比和五项语义结论；增强说明包含各组范围、对应镜号的观看过程、原组合判断、选定调整及前后表达差别，表演与摄影各有逐镜增强或具体保留依据。全组保留时说明现有组合如何完成观看过程；局部改善如实限定收益。报告中的程序结果保持真实。
- 尚有待评估镜头、仅有剧情摘要或模板保留理由时，表达评估尚未完成，交付状态为部分完成或待补。没有修改数量或运镜比例要求，不为了报告好看制造改动。
- 没有未解决材料、必要合同调整、程序失败或未解释同步提醒后，才声明本次文字增强完成。
- 修改 frame 或摄影后核对关键帧，修改镜头正文、H3 或声景后更新相关视频导出包。无法查看或重新生成时列为待更新。
- 尚未实际查看生成结果时，不写“效果已验证”“视频验收通过”。
