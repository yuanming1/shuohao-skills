# 镜头与运镜条目库

本库整理用户文件《运镜+微表情+法阵指令.txt》第 1–4 节，共 32 条。原条目名称保留，描述清除了错字、注释和冲突参数；适用任务、字段映射与使用限制为本技能补充。来源与调整见 [sources.md](sources.md)。

## 检索与选择

| 需要解决的问题 | 读取章节 | 编号 |
|---|---|---|
| 确定观察范围、观察角度或细节尺度 | 景别、视角与基础表现 | C01–C10 |
| 让运镜服务于注意力与情绪变化 | 情绪化运镜 | C11–C18 |
| 让面部反应与摄影过程配合 | 人物表情特写 | C19–C24 |
| 需要跨阶段的环绕、推进或转场 | 复合运镜配方 | C25–C32 |

先读 [摄影规则](camera.md)，再按任务读取本库相应章节。选择条目后写清观察目标、起点、终点和与人物动作的关系，把实际描述写入分镜正文及视频正文；编号只在既有 `note` 的“增强依据”中作为追溯信息，不要求新增字段。一个镜头不必移动，也不必同时套用全部修饰。

## 景别、视角与基础表现

原文件把景别、机位、光学和运动混列在“镜头视角层级”中，这里保留 10 个入口，分别映射到实际摄影字段。

| 编号 | 原条目 | 整理后的镜头描述 | 适用任务（整理建议） | 落地注意（补充规则） |
|---|---|---|---|---|
| C01 | 远景 | 广阔环境中的主体保持可辨识尺度，前中后景有层次，可借已有雾气或大气透视体现距离。 | 建立地点、孤独感或人物与环境的尺度关系。 | 主要写入 `size`、`lens`、`composition`；没有雾气设定时不凭空增加。 |
| C02 | 全景 | 完整容纳人物与周围环境，人物动作及其与环境的光影关系可读；有既定移动时可平稳跟随。 | 看清全身动作、站位及环境反馈。 | 全景是景别，跟随是可选运动；动态模糊不能遮住关键接触。 |
| C03 | 中景 | 以主体动作和上半身关系为重点，背景适度分层，突出手势、姿态和互动细节。 | 同时交代人物反应与主要行动。 | 背景虚化不自动发生；必须看清的道具与手部仍需处于可读范围。 |
| C04 | 近景 | 收近人物，突出视线、面部或画内手势；背景光斑与浅景深可形成情绪上的集中。 | 对话反应、迟疑、态度转变。 | 眼睛与手势深度不同，不能无依据地同时要求极浅景深与全清晰。 |
| C05 | 特写 | 集中呈现面部或物体局部，强调已有皮肤、材质与细小变化；原文件的轻微镜头颤动为可选表现。 | 强调决定性反应或道具证据。 | 特写不等于微距；保留当前画风，不为细节改变人物外貌或强制手持。 |
| C06 | 俯拍 | 从高于主体的位置向下观察，让环境布局、主体尺度和投影关系清楚；原文件附带的小幅旋转按需选择。 | 交代空间关系、脆弱处境或范围。 | 写入 `cameraPosition`；俯拍不等于必须升空，也不自动追加旋转。 |
| C07 | 仰拍 | 从低于主体的位置向上观察，可用广角透视强化主体体量与高低关系。 | 权力关系、压迫感或主体与高处的联系。 | 机位与焦段分别描述；不照搬原文件的云层变化，不扭曲人物身份特征。 |
| C08 | 微距 | 以极近距离观察眼部、指尖或物体纹理，有限清晰范围内的细节变化成为主体；有任务时才做焦点转移。 | 微小证据、触感或已经建立的细腻反应。 | 当前素材与光学条件须支持细节；不把“显微级”当作可保证的模型能力。 |
| C09 | 爆发式急推 | 摄影机迅速逼近既定观察对象，短暂运动模糊后落到清楚的反应或证据。 | 突发发现、情绪爆发、关键变化。 | `camera` 使用既有推进类别，速度写入正文；终点需停稳可读，畸变不是必需。 |
| C10 | 纪实式手持抖动 | 以轻微、不完全规律的手持晃动伴随观察，幅度随当前紧张程度控制。 | 现场感、危险感、贴身观察。 | 主要写入 `stability`；不把抖动当成新的主体移动，不遮蔽脸部与动作结果。 |

## 情绪化运镜

这些是表达候选，不是“某种情绪必配某种运镜”的规则。人物情绪来自故事；镜头改变观众的观察方式。

| 编号 | 原条目 | 整理后的镜头描述 | 适用任务（整理建议） | 落地注意（补充规则） |
|---|---|---|---|---|
| C11 | 聚焦式推进 | 镜头逐步靠近已选对象，焦点随距离保持在反应上，背景逐渐弱化，注意力向主体集中。 | 发现细微反应、进入人物的感受。 | 交代由什么范围推到什么细节；背景虚化随条件选择。 |
| C12 | 抽离式后拉 | 镜头从人物或细节向后退开，逐步容纳更多既有环境，人物与空间关系变得更清楚。 | 疏离、留白或揭示已有事件的环境结果。 | 后拉不使人物自动后退；景深扩展可选，场景光线不自动渐变。 |
| C13 | 探索式横摇 | 镜头围绕既定机位水平转向，搜索已有空间，找到目标后放缓或停止，轻微速度变化可表现迟疑。 | 寻找声源、寻找人或发现线索。 | 写清搜索方向与落点；横摇不是横向移动摄影机。 |
| C14 | 陪伴式平移 | 摄影机与主体沿明确方向平滑横移，维持相对观察关系，可有很轻的自然起伏。 | 陪伴既定行走、并行观察或维持交流关系。 | 主体必须原本就在移动，或镜头有独立观察理由；不为平移添加走路。 |
| C15 | 升华式上升 | 摄影机从当前高度上升，逐步打开视野，让主体与已有更广阔空间发生联系。 | 希望、解放或事件意义的展开。 | 原文的渐亮、云层和光晕仅在既有光照与设定支持时考虑，上升本身不改变天气。 |
| C16 | 压抑式下降 | 摄影机向较低高度移动，构图逐渐收紧或让既有遮挡进入关系，形成下沉的观察感。 | 压力、失落、被局势困住。 | 原文的变暗、景深压缩须另有光照和光学依据，不与下降强绑定。 |
| C17 | 迷幻式旋转 | 以受控旋转改变主观方向感，可配合适度运动模糊，终点仍保留必要方向线索。 | 已有眩晕、梦境、失衡或主观不安。 | 先说明绕主体环绕还是绕光轴滚转；色偏须符合既定风格，不能添加幻觉情节。 |
| C18 | 静动转换式运镜 | 先稳定观察，在已有触发出现时开始运动；或运动结束后停住，让节奏变化承接情绪转折。 | 信息落地、态度转变、突发反应。 | 写清触发与运动的先后，使用一个主运动；无需每次加入过渡模糊。 |

## 人物表情特写

先从 [情绪与表情库](expression-library.md) 或 [微表情库](microexpression-library.md) 确定反应，再决定摄影是否确有收益。下列情绪是原文件中的具体模板，只有故事已经支持时才使用。

| 编号 | 原条目 | 整理后的镜头描述 | 适用任务（整理建议） | 落地注意（补充规则） |
|---|---|---|---|---|
| C19 | 慢推式微表情定格 | 缓慢向面部推进，眼部或唇周保持清晰，观察平静或隐忍逐渐转为眼尾泛红、鼻尖轻颤，最后停在反应上。 | 既有悲意逐渐显露，或克制开始松动。 | “定格”默认理解为镜头停稳观察，不自动冻结视频；按景深选清晰重点。 |
| C20 | 急拉式情绪反差 | 从面部细节快速后拉到中景，显露错愕之后嘴角垮下、眼眶含泪及身体姿态的变化。 | 反应与整体处境形成反差，或已有情绪崩塌。 | 不能为了急拉新增哭泣；起点若不是特写，不直接套用整条。 |
| C21 | 跟拍式情绪爆发 | 低速跟随已在移动的人物面部，观察压抑逐渐显为牙关收紧、面部紧绷与眼眶泛红，保留轻微呼吸感。 | 移动中的克制或临近爆发。 | 人物须有既定路径；跟焦与可见性优先，不凭模板增加移动和抖动。 |
| C22 | 急停式情绪错愕 | 快速推进后停在面部，触发到来时视线凝住、嘴角僵住，呼吸短暂停顿，随后显露错愕。 | 突然听见或看见关键事实。 | 推进终点有停稳时间；瞳孔细节仅在画面尺度支持时保留。 |
| C23 | 低机位仰拍式情绪崩溃 | 从较低机位缓慢接近面部，观察强撑逐渐松动、轻咽、嘴角颤抖和泪水落下，焦点落在眼部或下颌变化。 | 已有无助、崩溃或强撑失败。 | 原文破损句按情绪顺序整理；不强制喉结特征与冷色光，低机位也不必表现强势。 |
| C24 | 急推式愤怒爆发 | 向面部迅速推进，隐忍在既定刺激后转为眉峰下压、牙关收紧和锐利凝视，终点清楚呈现怒意。 | 已有愤怒从克制转向显露。 | 青筋、径向模糊按画风与可读性选择；不新增吼叫、攻击或台词。 |

## 复合运镜配方

本节完整保留原文件的 8 种组合意图。箭头表示观察阶段的顺序，不表示允许新建镜头。每个切镜保持一个主运镜：先检查现有相邻镜头是否恰好能承接这些阶段，每切只承担其中一个主运动，主体与道具状态连续；需要新增切点、延长时间或改变引用才能成立时，只交付具体调整建议。没有这些条件时，选择最有收益的一段，不把组合强塞进短镜头。

| 编号 | 原条目 | 整理后的阶段描述 | 适用任务（整理建议） | 落地注意（补充规则） |
|---|---|---|---|---|
| C25 | 变速环绕＋急推 | 围绕既定主体缓慢建立关系 → 环绕节奏加快 → 推近眼睛、手部或已有核心道具，落在发现点。 | 从局势观察集中到决定性细节。 | 环绕角度、加速和推进分配到已有切；不沿用互相冲突的圈数与速度。 |
| C26 | 偏心环绕＋急推 | 以主体肩部附近的已定空间点为参照偏心环绕，保持面部可读 → 从明确方向推近面部。 | 让视差或遮挡显露已有反应。 | 肩部是路径参照，不是摄影机穿过人体的许可；低角度、广角为可选条件。 |
| C27 | 180°半环绕＋急推 | 在空间可支持时完成半环绕，交代新观察侧 → 停在可理解的位置后推近面部反应。 | 从人物另一侧揭示态度或已有信息。 | 半环绕可能跨轴，须有可追踪的关系建立；不照搬原文两秒完成的约束。 |
| C28 | 环绕＋急推＋急拉 | 环绕观察主体 → 推近决定性细节并留出辨认时间 → 后拉回中景看到结果，持续保持观察对象。 | 细节与整体结果的对照。 | 三个阶段需有现成承接位置，不机械保留原文 0.2 秒停留；不能后拉回未发生动作的旧状态。 |
| C29 | 环绕＋抽帧＋急推 | 环绕建立主观不稳定感 → 在已有节奏转折处用短暂跳动感 → 推近眼部或关键细节并恢复清楚观察。 | 已有主观失衡或强烈心理冲击。 | 抽帧属于剪辑效果，确有剪辑支持才作为执行项；生成正文可写节奏顿挫，不声称能精确控制抽帧比例。 |
| C30 | 环绕＋微希区柯克急推 | 环绕建立关系 → 在另一既有切中做受控移动变焦：摄影机接近、焦距反向补偿，使主体尺度近似稳定而背景透视变化。 | 已有认知冲击、局势骤变。 | 移动变焦是一个主摄影效果，先明确其主体尺度目标；若终点必须是眼睛特写，通常需另外的切，不能同时保证全程主体尺度不变。 |
| C31 | 环绕＋急推＋空镜 | 环绕观察主体 → 推近反应或证据 → 切到已经存在且有叙事关联的环境细节。 | 让人物反应与环境结果形成呼应。 | 空镜必须已有切位、节拍和资产；不为模板添加树叶、雨滴、火焰或改变声音。 |
| C32 | 急推＋环绕 | 先推近已有关键道具 → 由下一既有切从明确位置环绕观察该道具及周围关系。 | 强调道具后交代它与环境的联系。 | 近距离环绕不一定能容纳环境，须核对景别与路径；不照搬固定米每秒、圈每秒和焦段。 |

## 字段落地与读取收口

| 表达层 | 写入既有字段或正文 | 需要区分 |
|---|---|---|
| 观察范围 | `size`、`composition` | 远景、全景、中景、近景、特写不是运动枚举。 |
| 观察方向与高度 | `cameraPosition`、`eyeline` | 俯拍与仰拍描述机位，升降描述摄影机的运动。 |
| 摄影机路径 | `camera` 与 `shot`、H3 | 推进、后拉、横摇、平移、跟拍、环绕按输入既有类别表达。 |
| 细节与对焦 | `lens`、`focus` 与正文 | 特写与微距不同；焦点变化不等于人物视线变化。 |
| 稳定性与速度 | `stability` 与运动正文 | 手持、急停、加速是观察方式的修饰，不改人物的世界位置。 |

只修改当前输入已存在且模式允许的摄影字段，不将 C 编号、中文条目名或复合配方名直接塞进 `camera`。字段枚举适配、空间复核和同步要求以 [camera.md](camera.md)、[handoff.md](handoff.md) 与 [gates.md](gates.md) 为准。选用复合配方时，增强依据写明阶段落在哪些既有镜号，以及未采用部分的原因。
