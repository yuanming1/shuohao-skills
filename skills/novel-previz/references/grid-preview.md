# 宫格预演：完整提示词交付

学习来源：用户提供的 `storyboard-skill.md`，技能名称 `storyboard-builder`。
已经内化布局、逐格内容、角色一致性、画面内部风格和整页渲染要求；不需要读取下载目录。
已安装的宫格技能增加了「锁定现有分镜模式」，本技能通过模板与数据交接使用该模式，不自动启动 Agent。

## 用途与两条路径

宫格是一种连续画面的查看方式，不是另一套分镜拆解。检查相邻镜头的主体、景别、视线、持物状态和视觉变化，
但不能仅凭宫格证明动作衔接、实际节奏或空间关系已经正确。

- **白模抽帧宫格**：检查已经搭建的空间与机位。可以使用白模工具的 `contact_sheet.py` 从预演视频抽帧；没有成片外观。
- **有外观的宫格生成**：本次接入的 `export-grid` 分支。读取原分镜画面描述，生成可提交给图像工具的完整宫格提示词；实际参考图片可选。不是只给一句拼图建议，也不重新生产独立关键帧。

如果只需要像素不变地排列已有图片，应使用拼图工具，没必要再生成一次；当前导出命令没有实现拼图。
生成宫格可能改动人物或细节，因此属于可选评审材料，不代替原关键帧，也不能代替几何验证。

## 执行命令

在技能目录执行：

```bash
python3 scripts/storyboard_to_shots.py export-grid --storyboard 项目-storyboard.json --out ./previz
```

- 默认重新分析，只导出推荐宫格的段落；`--ep 1` 可筛选集数。
- 明确添加 `--segment E01-02` 可以覆盖方式建议，但单镜输出待补说明，不制作无意义的宫格。
- **分镜数据必需，图片可选**。消费 `cut.frame`、`size` 和 `seconds`，不需要视频提示词，也不要求提前生成独立关键帧。
- 有图片时才添加 `--frames ./frames`；没有图片或只有部分镜头有图，仍然导出完整提示词。无图镜头的 `reference` 为 `null`，逐格标明依据文字，没有凭空构造文件路径。
- 图片放在 `frames/E01-02-f1.png`，或 `frames/E01-02/E01-02-f1.png`。支持 PNG、JPG、JPEG、WebP，每镜只允许匹配一个非空文件。
- 默认 `--aspect source`：有图时沿用参考画幅与方向，无图时要求一致画幅但不声称原画幅已知。可以明确指定 `16:9`、`9:16` 或 `1:1`。脚本不识别图像像素或验证实际宽高比。
- 显式指定的 `--frames` 不存在或不是目录时报告输入错误，不把拼错路径当作无图模式；没有参考图片请省略该参数。
- 来源优先级：`--builder <目录>` → 仓库的 storyboard-builder → 已注册的 storyboard-builder → 本技能内化模板。显式目录缺文件时直接报错。模板插槽不兼容时也报错，不发布不完整提示词。

## 输出与缺项

```text
previz/_grid/index.json
previz/_grid/E01-02/grid-input.json
previz/_grid/E01-02/grid-prompt.txt
previz/_grid/E01-02/grid-brief.md
```

- `grid-input.json`：锁定模式的交接数据。顶层只有 `mode / segment / layout / panels`；每格只有 `shot / time / size / frame / reference`。`time` 为原起止秒数的十进制字符串数组，保证格式化时不自行取整。
- `grid-prompt.txt`：完整提示词，包含实际行列数、逐格镜号与时间、原画面描述、可选参考图片列表、风格一致性和整页渲染指令。外层模板为英文，原 `cut.frame` 不翻译改写。
- `grid-brief.md`：已锁定字段、参考图片、模板来源和交付边界。
- `index.json`：只列本次所选段的 `ready / pending / skipped`，记录实际模板路径和校验值。`ready` 只代表提示词准备完成，不代表出图或审核通过。

**没有图片不是待补项。** 图片为空或有多个版本、缺少 `cut.frame`、无有效景别时才输出 `grid.todo`，不给出完整提示词。
文字优先的模式允许从未生成过图片；提示词和交接说明必须明确无图事实，不要求上传不存在的图片。
退出码：0 为本次完成（可能包含全部跳过），2 为仍有待补项，3 为输入或模板错误。
重复导出先将所选段的旧交付改名为 `.stale`，保留最近一版；未选中的段落不改动。
重新分析后取消推荐的段落也会撤下旧交付，避免修改分镜后继续误使用旧提示词。

## 时间和格数

原技能自由创作默认 **30 秒、15 格、每格 2 秒**，另列 15 秒 15 格与 60 秒 30 格。
这些是自由构思时的预设，不是本项目强制的一秒或两秒一格规则。锁定模式按以下规则处理：

1. 每个原切点对应一格，按原切序排列，保留原景别与 `cut.frame`，不把镜头结尾动作提前画到切点。
2. 起止时间由原 `seconds` 累加，不为填满网格而均分时长，也不重写原分镜。
3. 每段单独交付，列数为镜头数量平方根向上取整、最多四列，行数据此向上取整；多余格子留白，不编造镜头。
4. 单格表示区间起点，不表示该区间内完整动作，也不能证明播放节奏。局部细节复核原画面描述及可用图片，不新增独立关键帧预演。

## 实际出图与检查

导出完成后，无图时直接提交 `grid-prompt.txt`；有图片时再一起提交所列参考图片，路径不会自动上传。
角色图、场景图也可在出图时另行附加；当前命令只自动匹配按镜号命名的关键帧，不自动解析角色图或场景图目录。
可以让已安装的 storyboard-builder 审阅或润色提示词，但不得改变镜号、顺序、时间、景别和画面状态；不是每次必需的步骤。

- 镜号、时间码、景别与说明放在每格图像外；不要烧进画面。原剧情中的文字，如凭条编号，仍须保留。
- 不允许擅自换画风、角色、道具持有者或裁掉细节；参考图之间有矛盾时提出复核，不默默重设计。
- 无图时从原画面描述组织一致的视觉表现；未指定的外观属于生成选择，不宣称它与未见过的资产一致。
- 出图后核对格数、顺序、原分镜与可用参考图的对应关系、人物和状态。模型可能漏格、重复或改写文字，提示词写过不代表图像必然正确。
- 静态导出与自测没有验证图像内容，也没有调用付费服务。

## 与正式投产的边界

原技能提出把整张宫格交给视频模型；**本项目不把这种做法作为通用保证**。
整张宫格不能直接替换正式的 `E01-02-f1.png` 等独立干净关键帧。
即使注释放在画面外，也不能保证生成模型绝不复制文字、边框或网格；正式投产仍按原输入协议处理。
