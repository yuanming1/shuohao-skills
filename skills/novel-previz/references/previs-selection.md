# 预演方式选择

先回答「这一段最需要检查什么」，再选择材料。不要默认所有段落都制作白模，也不要重复生产已经完成的关键帧。

## 选择依据

| 检查问题 | 处理方式 | 合适例子 | 不应承诺 |
|---|---|---|---|
| 人物、家具、门窗与摄影机的空间关系 | 白模 | 多人同框、门框遮挡、过肩关系、横移机位 | 自动还原复杂动作、微表情或真实外观 |
| 相邻镜头的主体变化、景别变化和画面承接 | 宫格 | 正反打、发现线索→反应→揭示、进场与切换 | 证明实际运动流畅、精确播放节奏或物理可行性 |
| 单个画面的细节、表情、身份或文字是否清楚 | 复核已有关键帧，不新增预演 | 编号、签名、印章、眼神、大特写 | 通过一帧证明动作过程完成 |
| 同时存在空间与多镜头衔接问题 | 白模 + 宫格 | 多人遮挡后切证据特写 | 同一张白模截图解决外观与表演 |
| 普通重复镜头、没有明确疑点 | 不额外预演 | 已确认的简单固定中景 | 初筛没有命中就代表完全没有问题 |

## 规则初筛的实际范围

`analyze` 读取现有分镜，不要求场景配置，也不要求 Blender：

1. 白模候选：三人及以上同框、横移/升降/环绕/跟拍/主观机位，或遮挡、穿过、绕过、过肩等空间线索。
2. 宫格候选：同段多个镜头有景别、角色组合、机位描述变化，或动作、反应、发现、揭示等顺序线索。普通重复镜头不因数量增加就强制宫格。
3. 复核提示：大特写、道具特写、文字或表情细节，列出已有关键帧供检查；单镜动作也只提示复核已有切点画面，并要求另行检查过程。发现问题退回分镜环节，不新建「关键帧预演」。
4. 可以同时推荐白模与宫格，细节复核也可以附带出现。报告使用原段号、原切序列出检查范围，不重新拆镜。
5. 没有额外预演需求则 `methods=[none]`，但仍可能有 `scope.review`；缺少景别或运镜时必须提示分析依据不足。

规则在 `scripts/previs_analysis.py`，运镜支持情况直接读取白模适配器的映射表，不另写一套能力表。
文字线索只支持有限中文关键词与简单否定。隐含动作、反讽、复杂否定、多语言和跨段承接可能漏判。
**不要把规则初筛说成模型已经理解并验证整段剧情。** 用户有更明确的检查目标时，按上表复核建议；
常规重复转换由脚本执行，不需要 Agent 每次重新计算镜号和时间。

## 推荐白模与能够执行是两件事

- 推荐白模表示有空间检查价值，不表示完整场景配置已经存在。
- Tracking、Arc、POV 等运镜会依据当前适配器降级或近似，报告必须提示。
- 走到、起身、交接、拿起、放下、打斗等动作，不会由当前转换器生成完整动作。
- 若白模无法表达待检查的问题，不要以静态人形代替并宣称检查通过；列为需要额外配置或专项复核。
- 仅检查节奏且没有空间疑点时，可以播放已有关键帧形成的动态分镜；当前工具没有自动生成该分支。

## 选择之后

- **白模**：进入 `init-config → export → 静帧审查 → 视频预演`。导出仍以整段为单位，`scope.greybox` 是重点检查范围，不是删镜或修改时长的指令。
- **宫格**：运行 `export-grid --storyboard ... --out ...`，依据原分镜画面描述输出完整宫格提示词与交接包；实际图片可选，有图时添加 `--frames ...`，不要求先生成关键帧。默认只处理本次重新分析推荐宫格的段，明确指定 `--segment` 可以覆盖建议；单镜仍不制作宫格。细节见 [grid-preview.md](grid-preview.md)。
- **已有关键帧复核**：只检查 `scope.review` 列出的原画面，有问题退回原分镜修正，不重复生成独立画面。
- **不额外预演**：继续原分镜流程，不新增材料。

分析只给出执行依据；宫格导出把依据落实为可提交的完整提示词，但两者都不自动出图、调用付费服务或覆盖正式分镜。
有参考图片时需要在图像工具中实际上传；无图也能直接提交提示词，脚本不会启动另一个 Agent。宫格内化模板允许技能独立使用。

## 报告契约

`_analysis/analysis.json` 顶层只有 `segments` 与 `limitations`。每段固定五项：

| 字段 | 下游消费 |
|---|---|
| `segment` | 关联原分镜段号 |
| `methods` | Markdown 标题及后续流程选择 |
| `reasons` | 展示选择的结构和文字线索 |
| `scope` | 列出 `greybox`、`grid` 或 `review` 的原镜号 |
| `limits` | 展示降级、未支持动作和其他复核要求 |

方式标识只有 `greybox / grid / none`；组合以数组表达。`review` 只属于检查范围，不是预演方式。
改变分镜后重新运行分析。分析、白模和宫格交付分目录存放，旧版直接 `export` 命令保持兼容。
